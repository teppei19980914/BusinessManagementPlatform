## 1. 1 行サマリ

> **AI 機能には 2 種類あります。**
> - **LLM 機能** (プロジェクト作成・更新の AI 自動タグ付け / 「なぜ?」機能): プラン別単価で課金 (Expert ¥10、Pro ¥15、「なぜ?」は Pro のみ ¥15)。Beginner は月 50 回まで無料。
> - **Embedding 機能** (資産入力・チャット意味検索・CSV インポート・添付ファイル索引化): Expert / Pro は **¥5 / 業務操作**、Beginner は **月 100 件まで無料**。
>
> 🦉 **たすきフクロウ AI ヘルプチャット (使い方・FAQ への自然言語質問) は全プラン完全無料** (テナント月 100 回まで)。FAQ・ガイドが増えても 1 質問あたりの処理は固定です。

> 🆕 **Beginner プランの容量制限**: DB 50MB / ファイル 100MB の無料枠を超えると新規作成・更新が停止します (削除のみ可)。**超過課金は発生しません** — 削除後は自動的に再集計され、再び書込み可能になります。Expert / Pro へアップグレードすると容量上限なく従量課金 (DB ¥50/GB tier、ファイル ¥10/GB tier) で継続利用できます。

| 区分 | 該当機能 | Beginner | Expert | Pro |
|---|---|---|---|---|
| **LLM 課金** | プロジェクトの新規作成・更新 (AI 自動タグ付け) | 月 50 回まで無料 / 超過は書込停止 | ¥10 / 回 | ¥15 / 回 |
| **LLM 課金** | 「なぜ?」機能 (Pro 限定: 提案候補の関連理由を AI で説明) | 利用不可 | 利用不可 | ¥15 / 回 |
| **Embedding 課金** | 資産の新規作成・更新 (ナレッジ / リスク・課題 / 振り返り / メモ) | **月 100 件まで無料** | **¥5 / 回** | **¥5 / 回** |
| **Embedding 課金** | チャット意味検索 (「たすきフクロウ」アイコンの自然言語検索) | **月 100 件まで無料** | **¥5 / 検索** | **¥5 / 検索** |
| **Embedding 課金** | CSV / XLSX インポート (= 一括資産取込、N 件取込でも 1 業務操作 = ¥5) | **月 100 件まで無料** | **¥5 / 取込** | **¥5 / 取込** |
| **Embedding 課金** | 添付ファイル本文の索引化 (PDF/Excel/Word/CSV/text、ファイル意味検索用) | **月 100 件まで無料** | **¥5 / 添付** | **¥5 / 添付** |
| **Embedding 課金** | アイデアツール (投票・ホワイトボード・匿名FAQ) クローズ時の索引化 | **月 100 件まで無料** | **¥5 / 回** | **¥5 / 回** |
| **完全無料** | 月初の失敗 embedding 自動リカバリ (= ユーザ非起動の修復処理) | **無料** | **無料** | **無料** |
| **完全無料** | たすきフクロウ AI ヘルプチャット (FAQ・使い方ガイドへの自然言語質問) | **無料・テナント月 100 回まで** | **無料・テナント月 100 回まで** | **無料・テナント月 100 回まで** |

> **注: 上記は AI 機能 (= API 利用) の料金です。** 保存容量は別建てで以下の従量課金が並行して発生します:
> - DB 容量: [50MB まで無料 / 1GB ごと ¥50](./db-capacity-billing-guide)
> - 添付ファイル容量: [100MB まで無料 / 1GB ごと ¥10](./file-storage-billing-guide)

## 2. 有料・無料 機能の早見表

### 2.1 LLM 機能 (= AI が文章を読んで解釈・生成する操作)

「AI が文章を読んで意味を解釈する / 説明文を生成する」操作のみが LLM 課金の対象です。

| 機能 | 何が起きるか | Beginner | Expert | Pro |
|---|---|---|---|---|
| **プロジェクト新規作成** | 目的・背景・スコープから AI がタグ (業務ドメイン / 技術スタック / 工程) を自動抽出 | 月 50 回まで無料 / 超過は書込停止 | **¥10 / 回** | **¥15 / 回** |
| **プロジェクト更新** (目的・背景・スコープの編集) | 上記と同じ AI タグ付けを再実行 | 月 50 回まで無料 / 超過は書込停止 | **¥10 / 回** | **¥15 / 回** |
| **「なぜ?」機能** | 提案候補と現プロジェクトの関連理由を AI が日本語で説明 (150〜200 字) | 利用不可 | 利用不可 | **¥15 / 回** |

各機能の詳細:
- プロジェクト作成: [プロジェクト作成手順](./project-creation-guide)
- 「なぜ?」機能: [「なぜ?」機能 ご利用ガイド](./why-feature-guide)

### 2.2 Embedding 機能 (= 意味検索のために文章をベクトル化する操作)

「過去資産と類似度を判定する」「自然言語クエリで検索する」操作は、文章を意味ベクトルに変換 (embedding) する処理を使います。

**Beginner は月 100 件まで無料**、Expert / Pro は **¥5 / 業務操作** の従量課金です。

| 機能 | 何が起きるか | Beginner | Expert | Pro |
|---|---|---|---|---|
| **ナレッジの作成・更新** | 内容をベクトル化 → 提案エンジンの索引に追加 | **月 100 件まで無料** | **¥5 / 回** | **¥5 / 回** |
| **リスク・課題の作成・更新** | 同上 | **月 100 件まで無料** | **¥5 / 回** | **¥5 / 回** |
| **振り返りの作成・更新** | 同上 | **月 100 件まで無料** | **¥5 / 回** | **¥5 / 回** |
| **メモの作成・更新** | 内容をベクトル化 → 検索可能に | **月 100 件まで無料** | **¥5 / 回** | **¥5 / 回** |
| **アイデアツール (投票・ホワイトボード・匿名FAQ) のクローズ時** | セッション/スレッドをクローズすると内容をベクトル化 → 「PJ内から探す」検索対象に追加 | **月 100 件まで無料** | **¥5 / 回** | **¥5 / 回** |
| **チャット意味検索** | クエリをベクトル化 → 過去資産との類似度上位を表示 | **月 100 件まで無料** | **¥5 / 検索** | **¥5 / 検索** |
| **CSV / XLSX インポート** | 一括取込時にまとめて索引化 (N 件取込でも 1 業務操作 = ¥5 に集約) | **月 100 件まで無料** | **¥5 / 取込** | **¥5 / 取込** |
| **添付ファイルの索引化** | PDF/Excel/Word/CSV/text をアップロード時に本文を抽出 → 索引化 (ファイル意味検索用) | **月 100 件まで無料** | **¥5 / 添付** | **¥5 / 添付** |
| **月初の索引自動リカバリ** | 失敗していた索引化を月初に再生成 (= ユーザ非起動の自動リカバリ) | **無料** | **無料** | **無料** |

> Beginner プランの「月 100 件まで無料」は **Embedding 系の合計** です (資産入力・チャット検索・インポート・添付索引化を合算)。CSV を 100 件取り込んでも **1 件** としてカウントされます。試用ユーザの通常利用 (月数十件) では十分な枠です。
>
> 添付ファイル **本体の保存容量** は別途従量課金 (100MB まで無料 / 1GB ¥10、[ファイルストレージ ご利用ガイド](./file-storage-billing-guide)) ですが、**索引化 (embedding 生成)** は Beginner 月 100 件無料 / Expert・Pro は ¥5/添付 です。

各機能の詳細:
- チャット検索: [チャットボット意味検索 使い方ガイド](./chat-semantic-search-guide)
- ファイルストレージ + 索引化: [ファイルストレージ ご利用ガイド](./file-storage-billing-guide)

### 2.3 たすきフクロウ AI ヘルプチャット (★全プラン完全無料★)

### 2.4 そもそも AI を呼ばない操作 (= 完全無料)

以下は AI を呼び出さない通常の操作なので、完全無料です。

- ✅ 画面の表示・再表示
- ✅ エンティティの削除・公開範囲変更・タグだけの変更
- ✅ ログイン / ログアウト / MFA / ユーザ招待 / テナント管理
- ✅ コメント・添付ファイルの追加・削除
- ✅ プロジェクトメンバーの追加・除外
- ✅ 通知の表示・既読化
- ✅ プラン変更・予算上限の設定

## 3. 1 回 (= 1 call) の数え方

「課金 1 回」の単位は、操作ごとに以下のように決まります。

### 3.1 プロジェクト作成 / 更新

| トリガー | カウント |
|---|---|
| プロジェクトを新規作成し、目的・背景・スコープのいずれかに本文を入れた | **+1 回** |
| 既存プロジェクトの目的・背景・スコープを編集して保存した | **+1 回** |
| プロジェクトのメタ情報 (名前 / 期間 / 状態 / 公開範囲) のみを変更した | **+0 回** |
| プロジェクトを削除した | **+0 回** |

> 1 回の保存操作 = 1 回にまとめられています (= AI タグ抽出と索引化の合計を 1 回として記録)。「タグ付けで 1 回、索引化で 1 回」の二重課金は **発生しません**。

### 3.2 「なぜ?」機能

| トリガー | カウント |
|---|---|
| 提案画面の「なぜ?」リンクを **初回クリック** → AI が説明文を新規生成 | **+1 回** |
| 同じ (プロジェクト × 候補) で **2 回目以降クリック** → キャッシュから表示 | **+0 回** |
| 別の (プロジェクト × 候補) で初回クリック | **+1 回** |
| 別ユーザが同じ (プロジェクト × 候補) を初回クリック (キャッシュヒット) | **+0 回** |

> キャッシュキーは「プロジェクト × 候補」の組合せ単位です。1 度生成された説明文はテナント内で永続的に共有されます (= 再課金なし)。

### 3.3 資産の作成 / 更新・チャット検索 (Embedding)

| トリガー | カウント |
|---|---|
| 資産 (ナレッジ / リスク・課題 / 振り返り / メモ) を作成・更新 | **+1 件** (Beginner は月 100 件まで無料 / Expert・Pro は ¥5) |
| 同じ資産を内容変更なしで再保存 | **+0 件** (索引の再生成なし) |
| チャットボットで 1 回検索 | **+1 件** |
| 1 回の CSV インポートで 100 件取込 | **+1 件** (= 1 業務操作に集約) |

## 4. 課金 0 円になるケース

有料機能を呼び出しても、以下の場合は **¥0** になります (= AI 呼び出し自体が走らないか、失敗扱いで課金対象外)。

### 4.1 プロジェクト作成 / 更新で ¥0 になる条件

- **目的・背景・スコープが全て空欄**: AI に渡す文章がないため呼出スキップ
- **公開範囲 = 自分のみ** で作成・更新: 提案エンジンの索引対象外のため呼出スキップ
- **公開範囲だけの変更** (本文未編集): AI 呼出不要
- **タグだけの変更** (本文未編集): AI 呼出不要
- **AI 呼び出しが失敗**: 外部 AI サービスのエラー時は課金されません
- **テナントが縮退モード中**: 呼出自体が拒否される

### 4.2 「なぜ?」機能で ¥0 になる条件

- **キャッシュヒット**: 同じ (プロジェクト × 候補) で過去に生成済 → キャッシュから無料表示
- **AI 呼び出しが失敗**: 説明文が表示されなかった場合
- **テナントが縮退モード中**

### 4.3 容量課金も ¥0 になるケース

- 当月ピーク使用量が **DB 50MB 未満 / ファイル 100MB 未満**: 無料枠内
- 詳細は [データ容量 ご利用ガイド](./db-capacity-billing-guide) / [ファイルストレージ ご利用ガイド](./file-storage-billing-guide) 参照

**Embedding 課金の重要な考え方**:
- **「1 業務操作 = ¥5」集約**: CSV 100 件取込でも ¥5、複数の索引化を 1 操作で行っても 1 回 (= ¥5) です。
- **月初の索引自動リカバリは全プラン無料**: 失敗していた索引化を月初に再生成する処理は、ユーザが起動していない修復処理のため Expert/Pro でも ¥0 です (= 不当請求の回避)。
- **Beginner の月 50 回上限は LLM (プロジェクト作成/更新) のみ**、Embedding は別枠で **月 100 件まで無料**です。

### 5.2 使用 AI モデル

| プラン | プロジェクト作成 / 更新 | 「なぜ?」機能 | チャット検索 / 資産索引化 |
|---|---|---|---|
| **Beginner** | 軽量・高速モデル | (利用不可) | 意味検索用モデル |
| **Expert** | 軽量・高速モデル | (利用不可) | 意味検索用モデル |
| **Pro** | **高品質モデル** | **高品質モデル** | 意味検索用モデル |

Pro プランは高品質モデル (= 深い推論モデル) を使うため、Beginner / Expert の軽量モデルよりも一段階品質の高い AI タグ付け・説明文が得られます。

### 5.3 単価変更のお知らせルール

将来の単価変更は、**効力発生日の 30 日以上前** にメール + 利用規約への掲示でお知らせします ([料金プラン ご利用ガイド §8](./plan-guide#8-料金変更時のお知らせルール))。

## 6. 呼出回数の上限と防御層

「想定外の高額請求」を防ぐため、たすきば には複数の防御層が組み込まれています。

### 6.1 ユーザ単位のレート制限 (全プラン共通)

連続クリックや bot 級の連打を防ぐため、AI 呼出にはユーザ単位の短期上限があります。

| 単位 | 上限 |
|---|---|
| 1 ユーザ / 1 分あたり | **10 回** |
| 1 ユーザ / 1 時間あたり | **60 回** |

通常操作 (= 画面で AI 機能を意図的に使う) では到達しません。連打したり、複数タブで同時に AI を呼んだりすると一時的に「現在ご利用いただけません」と表示されることがあります (= 数分待てば自動復帰)。

### 6.2 Beginner プランの月次上限

Beginner プランには 2 つの無料枠があります:

| 対象 | 上限 | 到達時の挙動 |
|---|---|---|
| **LLM** (プロジェクト作成 / 更新) | **月 50 回** | 縮退モードに移行 (= プロジェクト作成 / 更新が書込停止) |
| **Embedding** (資産入力・チャット検索・インポート・添付索引化) | **月 100 件** | 新規の索引化のみ停止 (既存の索引を使ったチャット検索・提案エンジンは継続利用可) |

- いずれも月初 1 日に自動リセット
- 上限を継続的に超える場合は Expert / Pro へのアップグレードをご検討ください

> ⚠️ **たすきフクロウ AI ヘルプチャット (使い方の質問) は、この Embedding 月 100 件には含まれません。** 全プラン無料の **別枠** で、Beginner の Embedding 枠を一切消費しません (暴走防止のため「テナント月 100 回」のガードはありますが、料金は全プラン無料です)。「月 100 件 (Embedding)」と「月 100 回 (ヘルプチャット)」は別のカウンタです。

### 6.3 Expert / Pro の月次予算上限 (任意設定、LLM 用 + Embedding 用の 2 系統)

Expert / Pro プランでは、テナント管理者がテナント設定画面 (設定 → テナント設定 → 使用量タブ) から **月次予算上限を円単位で自由設定** できます (デフォルト無制限)。**LLM 用と Embedding 用は独立した 2 つの上限** として管理します。

**LLM 用月次予算上限** (= プロジェクト作成/更新・「なぜ?」機能):
- 80% 到達: 黄色警告表示
- 100% 到達: 縮退モード (= LLM 呼出停止、プロジェクト作成/更新・「なぜ?」機能が利用不可)
- 月初 1 日に消化額リセット

**Embedding 用月次予算上限** (= 資産入力・チャット意味検索・インポート・添付索引化):
- 80% 到達: 黄色警告表示
- 100% 到達: 縮退モード (= **新規の索引化のみ停止**、既存の索引を使ったチャット検索や提案エンジンは継続利用可能)
- 月初 1 日に消化額リセット
- 上限到達時に索引化できなかった分は、月初の自動リカバリで翌月補完されます

### 6.4 「今月請求金額」セクション (請求タブ)

テナント管理者画面の「請求」タブ先頭に **「今月請求金額」セクション** を表示します。当月の請求額を 4 内訳 (LLM 費用 / Embedding 費用 / DB 容量超過の想定 / ファイルストレージ超過の想定) + 合計で確認できます。DB / ファイルストレージは月中ピークベースの想定額で、月末に確定します。表示額と月末請求書 (クレジットカード / 銀行振込) は完全一致します (請求一致保証)。

## 8. 使用量の確認方法

### 8.1 テナント管理者の方

テナント設定画面 (設定 → テナント設定) で **当月の利用状況をリアルタイム** で確認できます:

- 当月のプロジェクト作成・更新 **回数 + 費用** / Embedding **回数 + 費用**
- (Pro のみ) 「なぜ?」機能 **回数 + 費用**
- 月次予算上限 (LLM 用 / Embedding 用) と現在の消化率 (80% で黄色、100% で赤色)
- 縮退モード状態 (= 予算到達 / Beginner 上限到達時に表示)
- データ容量・ファイルストレージの現在値とピーク値
- 「今月請求金額」(請求タブ先頭)

### 8.2 一般ユーザの方

一般ユーザは個別の利用状況画面はありませんが、AI 機能利用時に以下の表示で課金有無を判別できます:

- プロジェクト作成・更新時の **「課金 0 回 / 1 回」表示**
- 「なぜ?」ダイアログの **「キャッシュから取得」表示** (= 課金なし) / 表示なし (= 今回課金)

### 8.3 請求の透明性

すべての AI 呼出は利用ログに記録され (= 無料分も記録)、テナント管理者は当月の利用明細を CSV でエクスポートできます。**ダッシュボードの表示金額・請求書・決済プラットフォームへの送信額はすべて同じ数値を参照する設計** (請求一致保証) のため、「表示は安いのに請求書だけ高い」という事故は構造的に発生しません。

## 9. 失敗時の取り扱い

AI 呼び出しが失敗した場合の挙動:

| 失敗パターン | 課金 | UI 表示 |
|---|---|---|
| 外部 AI サービスの一時障害 | **¥0 (課金されない)** | 「AI 機能が一時利用できません」エラー、操作は完了せず |
| ユーザ単位レート制限超過 (§6.1) | **¥0** | 「現在ご利用いただけません」、数分後に再試行可 |
| Beginner LLM 月次上限到達 (§6.2) | **¥0** | 「Beginner の月次上限 50 回に到達しました」、アップグレード誘導 |
| Beginner Embedding 月次上限到達 (§6.2) | **¥0** | 「Embedding の試用上限 (月 100 件) に到達しました」、既存索引での検索は継続 |
| 月次予算上限到達 (§6.3) | **¥0** | 「月次予算上限に到達しました (縮退モード)」、予算引上 or 月初リセット待ち |
| 「なぜ?」を Pro 以外で呼んだ場合 | **¥0** | UI ではボタン自体非表示 |

**「課金されたが、結果が表示されない」状況は仕様上発生しません**。表示成功 = 課金記録、失敗 = 課金なしの 1 対 1 の関係が維持されています。

## 11. FAQ

### Q1. AI を呼び出さない通常の操作 (画面表示・削除・タグ変更) は無料ですか?

**A.** **はい、完全無料です**。AI を呼び出さない操作は課金対象外です。

### Q2. ナレッジを大量に登録しても無料ですか?

**A.** **プランによります**:

- **Beginner プラン**: 資産入力・チャット検索などの Embedding は **月 100 件まで無料**。それを超えた分は新規の索引化が一時停止します (既存の索引を使った検索は継続)。
- **Expert / Pro プラン**: **¥5 / 件**。1,000 件登録なら ¥5,000。

ただし、**保存容量は別建てで従量課金** されます (DB 50MB 無料 + 1GB ¥50)。詳細は [データ容量 ご利用ガイド](./db-capacity-billing-guide) 参照。

### Q3. チャット検索は何回まで無料ですか?

**A.** **プランによります**:

- **Beginner プラン**: Embedding 月 100 件の枠内で無料 (資産入力等と合算)。
- **Expert / Pro プラン**: **¥5 / 検索**。月 2,000 回検索なら ¥10,000。テナント設定で Embedding 月次予算上限を設定できます。

検索を多用される場合は Expert / Pro + 予算上限の設定をご検討ください。

### Q4. プロジェクトの公開範囲を「自分のみ」にすれば、AI タグ付け課金は発生しませんか?

**A.** **はい、課金されません**。公開範囲が「自分のみ (下書き)」のプロジェクトは提案エンジンの索引対象外のため、AI 呼出自体がスキップされます。

ただし、提案エンジン (= 過去類似プロジェクトの自動レコメンド) も働かないため、業務利用では通常「公開」を推奨します。

### Q5. 「なぜ?」機能はなぜ Pro 限定なのですか?

**A.** Pro プラン唯一の **AI 品質差別化ポイント** だからです。

「なぜ?」機能は高品質モデルを使い、150〜200 字の自然言語で「なぜ関連するか」を説明します。Beginner / Expert は軽量モデルを使い、提案候補の一覧表示までは無料で提供しています。「説明文が必要 = Pro」「一覧で十分 = Expert / Beginner」という線引きです。

### Q6. プロジェクト作成時、AI 自動タグ付けを毎回スキップする方法はありますか?

**A.** **目的・背景・スコープを空欄のままにする** と AI 呼出はスキップされます (¥0)。

ただし、空欄のプロジェクトは提案エンジンの索引対象にもならないため、後段の提案レコメンド精度が落ちます。業務利用では本文を入力していただくことを推奨します。

### Q7. CSV インポートで 10,000 件登録した場合、課金されますか?

**A.** **プランによります**:

- **Beginner プラン**: CSV 一括取込は **1 回の取込 = Embedding 1 件** としてカウントされます (月 100 件の枠内)。
- **Expert / Pro プラン**: **1 取込操作 = ¥5**。10,000 件を 1 回の取込で実行 → ¥5。100 回に分けて取込 → ¥500 (= 取込回数で課金、件数ではない)。

**プロジェクト** を CSV インポートする場合は別途、1 件ごとに AI タグ付けが走るため Expert/Pro では 1 件あたり ¥10/¥15 が発生します。

### Q8. 課金された金額と請求書の金額がズレることはありますか?

**A.** **ありません**。利用ログの金額合計 = テナント設定画面の表示金額 = 請求書 = 決済プラットフォームへの送信額が **完全一致** するよう設計されています (請求一致保証)。利用者様側で「請求書だけ高額」のような事故は構造的に発生しません。

### Q9. 外部 AI サービスが障害でダウンした場合、利用料はどうなりますか?

**A.** **失敗した呼出は課金されません**。AI が一時障害でレスポンスを返さなかった場合、UI には「AI 機能が一時利用できません」と表示され、課金記録も残りません。復旧後に再操作いただくと、その時点で改めて課金されます。

### Q10. 削除したプロジェクト / 資産の過去課金分は返金されますか?

**A.** **いいえ、過去課金分は返金されません**。AI 呼出時に発生した課金は、その時点での AI 処理に対する対価です。後でプロジェクトや資産を削除しても、当該時点の課金は遡及して取り消されません。ただし、削除以降は新規の課金が発生しません。
