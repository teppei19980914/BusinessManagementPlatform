## 1. 1 行サマリ

> **Beginner プランは「AI で検索/類似性判定する操作 (資産入力・チャット検索)」も完全無料、Expert/Pro プランは ¥1/業務操作 で従量課金 (ADR-0022 / 2026-06-01)。プロジェクト作成・「なぜ?」 機能は従来通り plan 別単価で課金。**

> 🆕 **Beginner プラン 容量制限 (ADR-0025 / 2026-05-29)**: DB 50MB / ファイル 100MB の無料枠を超えると新規作成 / 更新が停止します (削除のみ可)。**overage 課金は発生しません** — 削除後は自動的に再集計され、再び書込み可能になります。Expert / Pro プランへアップグレードすると 50GB まで継続利用可能 (DB ¥50/GB tier、ファイル ¥10/GB tier の従量課金)。

| 区分 | 該当機能 | Beginner | Expert | Pro |
|---|---|---|---|---|
| **LLM 課金** | プロジェクトの新規作成・更新 (AI 自動タグ付け) | 月 50 回まで無料 / 超過は書込停止 | ¥10 / 回 | ¥15 / 回 |
| **LLM 課金** | 「なぜ?」機能 (Pro 限定: 提案候補の関連理由を AI で説明) | 利用不可 | 利用不可 | ¥15 / 回 |
| **Embedding 課金** *(ADR-0022 / 2026-06-01)* | 資産の新規作成・更新 (Knowledge / RiskIssue / Retrospective / Memo) | **無料・無制限** | **¥1 / 回** | **¥1 / 回** |
| **Embedding 課金** *(ADR-0022)* | チャット意味検索 (「たすきフクロウ」アイコンの自然言語検索) | **無料・無制限** | **¥1 / 検索** | **¥1 / 検索** |
| **Embedding 課金** *(ADR-0022)* | CSV / XLSX インポート (= 一括資産取込、N 件取込でも 1 業務操作 = ¥1) | **無料・無制限** | **¥1 / 取込** | **¥1 / 取込** |
| **Embedding 課金** *(ADR-0022)* | 添付ファイル本文の embedding 生成 (PDF/Excel/Word/CSV/text、ファイル意味検索用) | **無料・無制限** | **¥1 / 添付** | **¥1 / 添付** |
| **完全無料** | 月初 cron による失敗 embedding の自動リカバリ (= ユーザ非起動の修復処理、ADR-0022) | **無料・無制限** | **無料・無制限** | **無料・無制限** |

> **注: 上記は AI 機能 (= API 利用) の料金です。** ストレージは別建てで以下の従量課金が並行して発生します:
> - DB 容量: [50MB まで無料 / 1GB ごと ¥50](./db-capacity-billing-guide.md)
> - **添付ファイル容量** *(ADR-0021 / 2026-05-26)*: [100MB まで無料 / 1GB ごと ¥10](./file-storage-billing-guide.md)

## 2. 有料・無料 機能の早見表

### 2.1 有料機能 (= LLM = Claude API を呼ぶ操作)

たすきば Knowledge Relay では「AI が文章を読んで意味を解釈する」操作 (= Anthropic 社の Claude モデル呼び出し) のみが有料です。

| 機能 | 何が起きるか | Beginner | Expert | Pro |
|---|---|---|---|---|
| **プロジェクト新規作成** | 目的・背景・スコープから AI がタグ (業務ドメイン / 技術スタック / 工程) を自動抽出 | 月 50 回まで無料 / 超過は書込停止 | **¥10 / 回** | **¥15 / 回** |
| **プロジェクト更新** (目的・背景・スコープの編集) | 上記と同じ AI タグ付けを再実行 | 月 50 回まで無料 / 超過は書込停止 | **¥10 / 回** | **¥15 / 回** |
| **「なぜ?」機能** | 提案候補と現プロジェクトの関連理由を AI が日本語で説明 (150〜200 字) | 利用不可 | 利用不可 | **¥15 / 回** |

各機能の詳細:
- プロジェクト作成: [プロジェクト作成手順](./project-creation-guide.md)
- 「なぜ?」機能: [「なぜ?」機能 ご利用ガイド](./why-feature-guide.md)

### 2.2 Embedding 機能 (= ベクトル検索のみ使う操作、ADR-0022 で課金構造改定)

「過去資産と類似度を判定する」「自然言語クエリで検索する」操作は、Voyage AI 社の embedding (= 文章をベクトル化) のみを使い、実コストが極小 (1 操作あたり ¥0.036 以下) です。

**ADR-0022 (2026-06-01) 改定後**: Beginner プランは引き続き **完全無料・無制限** (= 「90 日完全無料」訴求保全) ですが、Expert/Pro プランは **¥1 / 業務操作** の従量課金に変わりました。

| 機能 | 何が起きるか | Beginner | Expert | Pro |
|---|---|---|---|---|
| **ナレッジ (Knowledge) の作成・更新** | 内容を Voyage で embedding → 提案エンジンの索引に追加 | **無料・無制限** | **¥1 / 回** | **¥1 / 回** |
| **リスク・課題 (RiskIssue) の作成・更新** | 同上 | **無料・無制限** | **¥1 / 回** | **¥1 / 回** |
| **振り返り (Retrospective) の作成・更新** | 同上 | **無料・無制限** | **¥1 / 回** | **¥1 / 回** |
| **メモ (Memo) の作成・更新** | 内容を Voyage で embedding → 検索可能に | **無料・無制限** | **¥1 / 回** | **¥1 / 回** |
| **チャット意味検索** | クエリを Voyage で embedding → 過去資産との類似度上位を表示 | **無料・無制限** | **¥1 / 検索** | **¥1 / 検索** |
| **CSV / XLSX インポート** | 一括取込時に embedding を生成 (N 件取込でも 1 業務操作 = ¥1、ADR-0022 §2.1 bulk 集約) | **無料・無制限** | **¥1 / 取込** | **¥1 / 取込** |
| **添付ファイルの embedding 生成** *(ADR-0021 / 2026-05-26)* | PDF/Excel/Word/CSV/text/docx をアップロードした際、本文を抽出 → Voyage で embedding → ファイル意味検索の索引に追加 | **無料・無制限** | **¥1 / 添付** | **¥1 / 添付** |
| **月初の embedding 補完 cron** | 失敗していた embedding を月初に再生成 (= ユーザ非起動の自動リカバリ) | **無料・無制限** | **無料・無制限** | **無料・無制限** |

> ※ Beginner プランは月 10,000 calls/tenant の Fair Use Limit ([§6.3](#63-無料利用の-fair-use-limit-beginner-限定)) が適用されます。通常運用ではまず到達しません (典型値: 月 200 calls 程度)。
>
> ※ Expert/Pro プランは Fair Use Limit ではなく、自己設定の **月次予算上限 ([§6.4](#64-expert--pro-の月次予算上限-任意設定))** で防御されます。

> **添付ファイル embedding の補足** *(ADR-0021 / ADR-0022)*: ファイル本体の保存容量は **別途従量課金** (100MB まで無料 / 1GB ごと ¥10、詳細は [ファイルストレージ ご利用ガイド](./file-storage-billing-guide.md))。**Embedding 生成料** は Beginner 無料 / Expert・Pro は ¥1/添付 (= ファイル 1 件アップロード = 1 業務操作)。

> ※ ただし、**1 テナントあたり月 10,000 calls** の Fair Use Limit が適用されます ([§6.3](#63-無料機能の-fair-use-limit-暴走防止) 参照)。通常運用ではまず到達しません (典型値: 月 200 calls 程度)。

> **添付ファイル embedding の補足** *(ADR-0021)*: ファイル本体の保存容量は **別途従量課金** (100MB まで無料 / 1GB ごと ¥10、詳細は [ファイルストレージ ご利用ガイド](./file-storage-billing-guide.md)) ですが、**embedding 生成自体は無料** です。提案エンジンとチャット「ファイル」キーワード検索の精度向上のため、運営側で負担しています。

各機能の詳細:
- チャット検索: [チャットボット意味検索 使い方ガイド](./chat-semantic-search-guide.md)
- ファイルストレージ + embedding: [ファイルストレージ ご利用ガイド](./file-storage-billing-guide.md)

### 2.3 そもそも AI を呼ばない操作 (= 完全無料)

以下は AI を呼び出さない通常の DB 操作なので、上記のフロー外で完全無料です。

- ✅ 画面の表示・再表示
- ✅ エンティティの削除・公開範囲変更・タグだけの変更
- ✅ ログイン / ログアウト / MFA / ユーザ招待 / テナント管理
- ✅ コメント・添付ファイルの追加・削除
- ✅ プロジェクトメンバーの追加・除外
- ✅ 通知の表示・既読化
- ✅ プラン変更・予算上限の設定

## 3. 1 回 (= 1 call) の数え方

「課金 1 回」の単位は、操作ごとに以下のように決まります。

### 3.1 プロジェクト作成 / 更新 (`project-upsert`)

| トリガー | カウント |
|---|---|
| プロジェクトを新規作成し、目的・背景・スコープのいずれかに本文を入れた | **+1 call** |
| 既存プロジェクトの目的・背景・スコープを編集して保存した | **+1 call** |
| プロジェクトのメタ情報 (名前 / 期間 / 状態 / 公開範囲) のみを変更した | **+0 call** |
| プロジェクトを削除した | **+0 call** |

> 1 回の保存操作 = 1 call にまとめられています (= AI タグ抽出 + embedding の合計を 1 call として記録)。「AI タグ付けで 1 回、embedding で 1 回」の二重課金は **発生しません**。

### 3.2 「なぜ?」機能 (`suggestion-explanation`)

| トリガー | カウント |
|---|---|
| 提案画面の「なぜ?」リンクを **初回クリック** → AI が説明文を新規生成 | **+1 call** |
| 同じ (プロジェクト × 候補) で **2 回目以降クリック** → DB キャッシュから表示 | **+0 call** |
| 別の (プロジェクト × 候補) で初回クリック | **+1 call** |
| 別ユーザが同じ (プロジェクト × 候補) を初回クリック (キャッシュヒット) | **+0 call** |

> キャッシュキーは「プロジェクト × 候補」の組合せ単位です。1 度生成された説明文はテナント内で永続的に共有されます。

### 3.3 資産の作成 / 更新・チャット検索 (無料)

| トリガー | カウント |
|---|---|
| 資産 (Knowledge / RiskIssue / Retrospective / Memo) を作成・更新 | **+1 call (無料)** |
| 同じ資産を内容変更なしで再保存 | **+0 call** (embedding 再生成なし) |
| チャットボットで 1 回検索 | **+1 call (無料)** |
| 1 回の CSV インポートで 100 件取込 | **+100 calls (無料)** |

> 無料の call も `ApiCallLog` テーブルに記録されます (= 監査 / 利用分析目的)。Fair Use Limit のカウント対象になります ([§6.3](#63-無料機能の-fair-use-limit-暴走防止))。

## 4. 課金 0 円になるケース

有料機能を呼び出しても、以下の場合は **¥0** になります (= API 呼び出し自体が走らないか、失敗扱いで課金対象外)。

### 4.1 プロジェクト作成 / 更新で ¥0 になる条件

- **目的・背景・スコープが全て空欄**: AI に渡す文章がないため呼出スキップ
- **公開範囲 = 自分のみ** で作成・更新: 提案エンジンの索引対象外のため呼出スキップ
- **公開範囲だけの変更** (本文未編集): AI 呼出不要
- **タグだけの変更** (本文未編集): AI 呼出不要
- **API 呼び出しが失敗**: Anthropic / Voyage のエラー時は課金されません
- **テナントが縮退モード中**: 呼出自体が拒否される

### 4.2 「なぜ?」機能で ¥0 になる条件

- **キャッシュヒット**: 同じ (プロジェクト × 候補) で過去に生成済 → DB から無料表示
- **API 呼び出しが失敗**: 説明文が表示されなかった場合
- **テナントが縮退モード中**

### 4.3 ストレージ容量も ¥0 になるケース

- 当月ピーク使用量が **50MB 未満**: 無料枠内
- 詳細は [データ容量 ご利用ガイド §3](./db-capacity-billing-guide.md#3-何が課金対象になるか) 参照

## 5. プラン別の API 単価

### 5.1 単価表 ([ADR-0022](../adr/0022-embedding-usage-based-billing.md) 2026-06-01 改定後)

| 機能 (featureUnit) | Beginner | Expert | Pro |
|---|---|---|---|
| `project-upsert` (プロジェクト作成/更新) | 月 50 回まで無料 / 超過で書込停止 | **¥10 / 回** | **¥15 / 回** |
| `suggestion-explanation` (なぜ?機能) | 利用不可 | 利用不可 | **¥15 / 回** |
| `knowledge-embedding` / `risk-issue-embedding` / `retrospective-embedding` / `memo-embedding` (資産作成/更新 4 種、**ADR-0022**) | **無料** (= 90 日無料訴求保全) | **¥1 / 回** | **¥1 / 回** |
| `chat-semantic-search` (チャット検索、**ADR-0022**) | **無料** | **¥1 / 検索** | **¥1 / 検索** |
| `external-import-embedding` (CSV インポート、**ADR-0022**、N 件取込でも 1 業務操作 = ¥1 集約) | **無料** | **¥1 / 取込** | **¥1 / 取込** |
| `attachment-embedding` (添付ファイル本文 embedding、**ADR-0022**) | **無料** | **¥1 / 添付** | **¥1 / 添付** |
| `*-embedding-backfill` (月初 cron 自動リカバリ 5 種、**ADR-0022**) | **無料** | **無料** (= ユーザ非起動の修復処理、不当請求リスク回避) | **無料** |
| `db-capacity-overage` ([データ容量超過](./db-capacity-billing-guide.md)) | 月初 cron で 1 件記録 (1GB ごと ¥50) | 同左 | 同左 |
| `storage-file-overage` ([ファイルストレージ超過](./file-storage-billing-guide.md)) | 月初 cron で 1 件記録 (1GB ごと ¥10、ADR-0021) | 同左 | 同左 |

すべて税抜表示です。日本円建てで Stripe (将来対応) または銀行振込でお支払いいただきます。

**Embedding 課金の重要設計**:
- **「1 業務操作 = ¥1」集約**: CSV 100 件取込でも ¥1、複数 embedding を 1 操作で生成しても 1 ApiCallLog (= ¥1)。
- **embedding-backfill は明示的に全プラン無料**: 月初 cron が「失敗していた embedding を自動再生成」する処理は、ユーザが起動していない修復処理のため Expert/Pro でも ¥0 維持 (= 不当請求リスク回避)。
- **Beginner 50 件上限は LLM (project-upsert) のみカウント**: Embedding 課金 (Expert/Pro) は Beginner 上限の判定対象外 (= 既存上限ロジック不変)。
- **`monthlyBudgetCap` も Embedding は対象外**: Embedding はチャット検索/資産入力に必須の機能のため、予算上限で止まると業務継続に直接影響するため判定外。

### 5.2 使用 AI モデル

| プラン | プロジェクト作成 / 更新 | 「なぜ?」機能 | チャット検索 / 資産 embedding |
|---|---|---|---|
| **Beginner** | Claude Haiku 4.5 | (利用不可) | Voyage voyage-4-lite |
| **Expert** | Claude Haiku 4.5 | (利用不可) | Voyage voyage-4-lite |
| **Pro** | **Claude Sonnet 4.6** (高品質) | **Claude Sonnet 4.6** (高品質) | Voyage voyage-4-lite |

Pro プランは Claude Sonnet 4.6 (= 深い推論モデル) を使うため、Beginner / Expert の Haiku 4.5 (= 軽量・高速) よりも一段階品質の高い AI タグ付け・説明文が得られます。

## 6. 呼出回数の上限と防御層

「想定外の高額請求」を防ぐため、たすきば Knowledge Relay には **4 段階の防御層** が組み込まれています。

### 6.1 ユーザ単位のレート制限 (全プラン共通)

連続クリックや bot 級の連打を防ぐため、AI 呼出にはユーザ単位の短期上限があります。

| 単位 | 上限 |
|---|---|
| 1 ユーザ / 1 分あたり | **10 calls** |
| 1 ユーザ / 1 時間あたり | **60 calls** |

通常操作 (= 画面で AI 機能を意図的に使う) では到達しません。連打したり、複数タブで同時に AI を呼んだりすると一時的に「現在ご利用いただけません」と表示されることがあります (= 数分待てば自動復帰)。

### 6.2 Beginner プランの月次上限 (= 50 件固定)

Beginner プランは **プロジェクト作成/更新の課金対象 call が月 50 件** で固定上限となります。

- 50 件到達: 縮退モードに自動移行 (= プロジェクト作成 / 更新が書込停止)
- 月初 1 日 00:00 (UTC) に枠リセット
- 資産入力・チャット検索は **無制限・無料** で継続利用可

### 6.3 無料利用の Fair Use Limit (Beginner 限定)

**ADR-0022 (2026-06-01) 改定後**: Embedding を Expert/Pro で ¥1/業務操作 課金化したことで、Expert/Pro は `monthlyBudgetCap` で自然防御されるため Fair Use Limit の対象外となりました。**Beginner プランのみ** が Embedding cost=0 維持のため、引き続き Voyage AI の月 200M トークン無料枠 (全テナント共有) を 1 テナントが食い潰さないよう、tenant 単位で月次の暴走防止上限が適用されます ([ADR-0022 §2.3](../adr/0022-embedding-usage-based-billing.md)):

| プラン | Embedding 課金 | 暴走防止経路 |
|---|---|---|
| **Beginner** | ¥0 維持 | **Fair Use Limit (本セクション)** が適用 |
| **Expert / Pro** | ¥1 / 業務操作 | **§6.4 月次予算上限** で自然防御 (= cost > 0 で `monthlyBudgetCap` が発火) |

**Beginner プランの Fair Use Limit** (= Embedding 系のみ対象、LLM 系 ([§3.1](#31-プロジェクト作成--更新-project-upsert)) は別途 [§6.2 月 50 件上限](#62-beginner-プランの月次上限--50-件固定) で防御):

| 段階 | 上限 (Beginner テナント月次) | 挙動 |
|---|---|---|
| Warning | **8,000 calls** | 運営側に通知 (利用者には特に通知なし、利用継続可) |
| Hard | **10,000 calls** | Embedding 系の呼出が縮退モード (= チャット検索 / 資産 embedding 停止) |

> 通常運用 (asset 50 + chat 100 + backfill 数十 = 月 200 call 程度) ではまず到達しません。
> ヘビーユーザ (asset 1000 + chat 10000 = 月 11,000 call) で初めて到達する設計です。

Hard 到達時は月初リセットまたは Expert/Pro へのアップグレードでご相談ください (Expert/Pro 切替後は ¥1/業務操作 課金で本上限は適用されなくなります、`monthlyBudgetCap` 設定推奨)。

### 6.4 Expert / Pro の月次予算上限 (任意設定)

Expert / Pro プランでは、テナント管理者がテナント設定画面 (`/settings/tenant`) から **月次予算上限を円単位で自由設定** できます (デフォルト無制限)。

- 80% 到達: 黄色警告表示
- 100% 到達: 縮退モード (= プロジェクト作成 / 更新 / 「なぜ?」が停止)
- 月初 1 日 00:00 (UTC) に消化額リセット

詳細は [料金プラン ご利用ガイド §6](./plan-guide.md#6-予算上限と縮退モード) 参照。

## 8. 使用量の確認方法

### 8.1 テナント管理者の方

テナント設定画面 (`/settings/tenant`) で **当月の利用状況をリアルタイム** で確認できます:

- 当月のプロジェクト作成・更新 **回数 + 費用**
- (Pro のみ) 「なぜ?」機能 **回数 + 費用**
- 月次予算上限と現在の消化率 (80% で黄色、100% で赤色)
- 縮退モード状態 (= 予算到達 / Beginner 50 件到達時に表示)
- データ容量の現在値とピーク値

### 8.2 一般ユーザの方

一般ユーザは個別の利用状況画面はありませんが、AI 機能利用時に以下の表示で課金有無を判別できます:

- プロジェクト作成・更新時の **「課金 0 回 / 1 回」表示**
- 「なぜ?」ダイアログの **「キャッシュから取得」表示** (= 課金なし) / 表示なし (= 今回課金)

### 8.3 監査ログ (テナント管理者向け)

すべての API 呼出は `ApiCallLog` に記録されます (= 無料 call も記録)。テナント管理者は当月の CSV をエクスポート可能です。Stripe Meter Event 経由の請求金額とテナント側の表示金額は完全一致するよう設計されています ([feedback_billing_invariant.md](../../memory/) の billing invariant 維持)。

## 9. 失敗時の取り扱い

API 呼び出しが失敗した場合の挙動:

| 失敗パターン | 課金 | UI 表示 |
|---|---|---|
| Anthropic / Voyage の一時障害 | **¥0 (課金されない)** | 「AI 機能が一時利用できません」エラー、操作は完了せず |
| ユーザ単位レート制限超過 (§6.1) | **¥0** | 「現在ご利用いただけません」、数分後に再試行可 |
| Beginner 月次上限到達 (§6.2) | **¥0** | 「Beginner の月次上限 50 回に到達しました」、アップグレード誘導 |
| Fair Use Limit 到達 (§6.3) | **¥0** | 「Fair Use Limit に到達しました」(= 通常運用では到達しない) |
| 月次予算上限到達 (§6.4) | **¥0** | 「月次予算上限に到達しました (縮退モード)」、予算引上 or 月初リセット待ち |
| 「なぜ?」を Pro 以外で呼んだ場合 | **¥0** | UI ではボタン自体非表示 (API 直叩きされた場合は `plan_forbidden` で拒否) |

**「課金されたが、結果が表示されない」状況は仕様上発生しません**。表示成功 = 課金記録、失敗 = 課金なしの 1:1 invariant が維持されています。

## 11. FAQ

### Q1. AI を呼び出さない通常の操作 (画面表示・削除・タグ変更) は無料ですか?

**A.** **はい、完全無料です**。AI を呼び出さない操作は API 利用 (= ApiCallLog) に一切記録されず、課金対象外です。

### Q2. ナレッジを 1 日 1,000 件登録しても無料ですか?

**A.** **プランによります** ([ADR-0022](../adr/0022-embedding-usage-based-billing.md) 2026-06-01 改定):

- **Beginner プラン**: **完全無料・無制限** (= 90 日完全無料訴求保全)。月 10,000 calls の Fair Use Limit に達した場合のみ縮退モード。
- **Expert / Pro プラン**: **¥1 / 件** (= ナレッジ作成 = Embedding 1 業務操作 = ¥1)。1,000 件登録なら ¥1,000。

ただし、**ストレージ容量は別建てで従量課金** されます (50MB 無料 + 1GB ¥50)。詳細は [データ容量 ご利用ガイド](./db-capacity-billing-guide.md) 参照。

Beginner プランは月 1,000 件 × 30 日 = 30,000 件のような極端なペースだと Fair Use Limit ([§6.3](#63-無料利用の-fair-use-limit-beginner-限定)) の Hard limit (= 月 10,000 calls) に到達します。

### Q3. チャット検索は何回まで無料ですか?

**A.** **プランによります** ([ADR-0022](../adr/0022-embedding-usage-based-billing.md) 2026-06-01 改定):

- **Beginner プラン**: **無制限・無料**。月 10,000 calls の Fair Use Limit に達した場合のみ縮退モード。
- **Expert / Pro プラン**: **¥1 / 検索**。月 2,000 回検索なら ¥2,000。`monthlyBudgetCap` 設定推奨。

Beginner プランでチャット検索のみで月 10,000 回を超えるような利用は想定外なので、Expert/Pro プランへのアップグレードをご相談ください。

### Q4. プロジェクトの公開範囲を「自分のみ」にすれば、AI タグ付け課金は発生しませんか?

**A.** **はい、課金されません**。公開範囲が「自分のみ」のプロジェクトは提案エンジンの索引対象外のため、AI 呼出自体がスキップされます。

ただし、提案エンジン (= 過去類似プロジェクトの自動レコメンド) も働かないため、業務利用では通常「テナント内に公開」を推奨します。

### Q5. 「なぜ?」機能はなぜ Pro 限定なのですか?

**A.** Pro プラン唯一の **AI 品質差別化ポイント** だからです。

「なぜ?」機能は Claude Sonnet 4.6 (= 高品質モデル) を使い、150〜200 字の自然言語で「なぜ関連するか」を説明します。Beginner / Expert は Claude Haiku 4.5 (= 軽量モデル) を使い、提案候補の一覧表示までは無料で提供しています。

「説明文が必要 = Pro」「一覧で十分 = Expert / Beginner」という線引きで Pro のアップセル動線を保っています ([ADR-0019 §Consequences](../adr/0019-billable-feature-units-and-free-tier-expansion.md#consequences))。

### Q6. プロジェクト作成時、AI 自動タグ付けを毎回スキップする方法はありますか?

**A.** **目的・背景・スコープを空欄のままにする** と AI 呼出はスキップされます (¥0)。

ただし、空欄のプロジェクトは提案エンジンの索引対象にもならないため、後段の提案レコメンド精度が落ちます。業務利用では本文を入力していただくことを推奨します。

### Q7. CSV インポートで 10,000 件登録した場合、課金されますか?

**A.** **プランによります** ([ADR-0022](../adr/0022-embedding-usage-based-billing.md) 2026-06-01 改定):

- **Beginner プラン**: **資産 (Knowledge / Risk / Retro / Memo) は完全無料**。10,000 件すべて無料で登録できます (Fair Use Limit 10,000 calls/月の範囲内であれば)。
- **Expert / Pro プラン**: **1 取込操作 = ¥1** (= ADR-0022 §2.1 bulk 集約)。10,000 件を 1 回の取込で実行 → ¥1。100 回に分けて取込 → ¥100 (= 取込回数で課金、件数ではない)。
  - これは「1 業務操作 = 1 ApiCallLog = ¥1」の集約設計です。100 件 CSV 取込でも ¥1 で済むため Expert/Pro でも経済的。

**プロジェクト** を CSV インポートする場合は別途、1 件ごとに AI タグ付けが走るため Expert/Pro では 1 件あたり ¥10/¥15 が発生します。Beginner では月 50 件を超える分は書込停止扱いとなります。

Beginner プランの CSV インポートは Fair Use Limit のカウント対象になります (= 取込回数ではなく embedding 1 件単位)。10,000 件の一括取込でも 1 業務操作 ですが、内部的に 10,000 個の embedding 生成が走るため Fair Use Limit ([§6.3](#63-無料利用の-fair-use-limit-beginner-限定)) のカウントは増えます。Hard limit (月 10,000 calls) に近い場合はタイミング調整推奨。

### Q8. 課金された金額と Stripe の請求書の金額がズレることはありますか?

**A.** **ありません**。`ApiCallLog` の `costJpy` 合計 = テナント設定画面の表示金額 = Stripe Meter Event の請求金額が **完全一致** するよう設計されています ([billing invariant](../../memory/))。

ズレが検出された場合は運営側で drift 検知バッチが発火し、調査・原価補填されます。利用者様側で「請求書だけ高額」のような事故は構造的に発生しません。

### Q9. Anthropic / Voyage が障害でダウンした場合、利用料はどうなりますか?

**A.** **失敗した呼出は課金されません**。Anthropic / Voyage が一時障害でレスポンスを返さなかった場合、UI には「AI 機能が一時利用できません」と表示され、ApiCallLog にも課金記録は残りません。

復旧後に再操作いただくと、その時点で改めて課金されます。

### Q10. 削除したプロジェクト / 資産の過去課金分は返金されますか?

**A.** **いいえ、過去課金分は返金されません**。

API 呼出時に発生した課金は、その時点での AI 処理コストに対する対価です。後でプロジェクトや資産を削除しても、当該時点の課金は遡及して取り消されません ([Stripe Meter Event の特性](../adr/0006-stripe-metered-billing-integration.md) として、過去のメーター記録は変更不可)。

ただし、削除以降は新規 call が走らないため、それ以降の請求は発生しません。
