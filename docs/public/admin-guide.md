# テナント管理者 ご利用ガイド (ユーザ管理・監査ログ・権限変更履歴)

テナント管理者は、組織 (テナント) のユーザ・権限・監査を管理できます。本ガイドでは、ユーザ管理・監査ログ・権限変更履歴の各画面を、テナント管理者向けにご説明します。

> プラン・請求・容量の管理は各課金ガイド ([料金プラン](./plan-guide.md) / [クレジットカード払い](./credit-card-payment-guide.md) / [データ容量](./db-capacity-billing-guide.md) / [ファイルストレージ](./file-storage-billing-guide.md)) を、ユーザ招待の手順は [アカウント追加手順](./account-setup-guide.md) を参照してください。

## 1. テナント管理者ができること

テナント管理者 (admin) は、自組織内で以下を行えます。

- ユーザの招待・有効化/無効化・削除・ロック解除
- システムロール (管理者 / 一般ユーザ) の変更
- 監査ログ・権限変更履歴の参照
- 顧客マスタの管理 ([プロジェクト ご利用ガイド §7](./project-guide.md#7-顧客-customer-の管理))
- プラン変更・予算上限・請求・容量の管理
- 外部データの CSV 一括取込 ([CSV 取込手順](./csv-import-guide.md))

> これらの管理画面 (ユーザ管理 / 監査ログ / 権限変更履歴) は、一般ユーザには表示されません。

## 2. ユーザ管理

`ユーザ管理` 画面 (`/admin/users`) で、組織のユーザを管理します。

### 一覧の列

| 列 | 内容 |
|---|---|
| ユーザ名 | 氏名 |
| メールアドレス | ログイン ID |
| システムロール | 管理者 / 一般ユーザ |
| 利用状態 | 有効 / 無効 |
| 認証ロック | 永続ロック / 一時ロック (解除予定) / ログイン失敗回数 / — |
| 作成日時 / 更新日時 | 登録・最終更新 |

### できること

- 新規ユーザの招待 (氏名・メール・ロールを指定 → 招待メール送信)
- システムロールの変更 (管理者 ↔ 一般ユーザ)
- 利用状態の切替 (有効化 / 無効化)
- アカウントロックの解除、リカバリーコードの再発行
- ユーザの削除 (論理削除)

### 安全のための制約

- **自分自身のロール・利用状態は変更できません** (管理者が誤って自分を締め出すのを防ぐため)。
- システムロールの選択肢に運営者ロール (super_admin) は表示されません (運営専用のため)。
- ロールや利用状態を変更すると、対象ユーザの全セッションが即時無効化されます。

## 3. アカウントのロックと解除

ユーザ管理画面の各ユーザの編集ダイアログで、認証ロックの状態を確認・解除できます。

- **一時ロック**: 短時間に連続でログイン失敗すると一時的にロックされます (一定時間で自動解除)。
- **永続ロック**: 一時ロックが繰り返されると永続ロックになり、テナント管理者の手動解除が必要です。
- **解除**: 編集ダイアログの「ロック解除」で、ログイン失敗回数・ロックをまとめてクリアできます。

> 長期間ログインのないユーザは、セキュリティのため自動的にログインを停止 (ロック) されることがあります。アカウント情報やデータは保持され、管理画面の有効化で復帰できます。

## 4. 監査ログ

`監査ログ` 画面 (`/admin/audit-logs`) では、組織内で行われた操作 (作成・更新・削除・ログイン 等) の記録を、新しい順に確認できます。

- 「誰が・いつ・何を」変更したかを追跡でき、ソートして閲覧できます。
- 監査ログは記録専用で、後から書き換えられない設計です (証跡として信頼できます)。

---

## 5. 権限変更履歴

`権限変更履歴` 画面 (`/admin/role-changes`) では、システムロール・プロジェクトロールの変更を専用に追跡できます。

| 列 | 内容 |
|---|---|
| 変更日時 | 日時 |
| 変更者 | 操作した管理者 |
| 対象ユーザ | 変更された人 |
| 対象種別 | システムロール / プロジェクトロール |
| 対象プロジェクト | プロジェクトロールのとき |
| 変更前 / 変更後 | ロールの遷移 |
| 変更理由 | 任意の記録 |

CSV でのエクスポートにも対応しています。

## 6. FAQ

### Q1. 一般ユーザにユーザ管理を任せられますか?

**A.** いいえ。ユーザ管理・監査ログ・権限変更履歴はテナント管理者のみが利用できます。管理を任せたい人は、その人のシステムロールを「テナント管理者」に変更してください。

### Q2. 自分のロールを変更できません。

**A.** 仕様です。自分自身のロール・利用状態は変更できません (管理者不在や自己昇格を防ぐため)。別の管理者に変更を依頼してください。

### Q3. ユーザを削除すると、その人のデータも消えますか?

**A.** 作成されたナレッジ・タスク等のデータは組織内に残ります。削除されたユーザはログインできなくなります。

### Q4. 監査ログは改ざんされませんか?

**A.** 監査ログは記録専用で、後から書き換えられない設計です。操作の証跡として信頼できます。
