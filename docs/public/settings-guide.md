# 個人設定 ご利用ガイド (アカウント情報・テーマ・パスワード・MFA)

個人設定 (`設定` 画面) では、自分のアカウント情報の確認、画面テーマの変更、パスワードの変更、多要素認証 (MFA) の管理ができます。本ガイドでは、各設定項目をすべての利用者様向けにご説明します。

> 言語・タイムゾーンは**組織 (テナント) 全体の設定**で、テナント管理者が [テナント設定](./tenant-settings-guide.md) で変更します (個人ごとの切り替えはありません。組織内で日付計算をそろえるための仕様です)。
> テナント全体のプラン・請求・容量の設定 (テナント管理者向け) は [テナント設定ガイド](./tenant-settings-guide.md) を参照してください。アカウントの作成・ログインは [アカウント追加手順](./account-setup-guide.md) を参照してください。

## 1. 設定画面の開き方

画面右上のアカウントメニュー →「設定」から開きます。一般ユーザ・テナント管理者のどなたでも利用できます。設定画面は上から「アカウント情報」「画面テーマ」「パスワード変更」「多要素認証 (MFA)」「他の端末からログアウト」の順に並びます。

---

## 2. アカウント情報

設定画面の最上部に「アカウント情報」セクションがあり、ログインや所属確認に必要な情報を自分で確認できます (表示専用)。

| 項目 | 内容 |
|---|---|
| 組織 ID | ログイン時に入力する組織の識別コード |
| テナント表示名 | 所属している組織の名称 |
| メールアドレス | ログイン ID + パスワードリセットの受信先 |
| 氏名 | 登録氏名 |
| ロール | テナント管理者 / 一般ユーザ |
| 最終ログイン | 直近のログイン日時 (身に覚えのないログインの発見に) |
| MFA 有効化日時 | 多要素認証を有効にした日時 (未設定なら「未設定」) |
| アカウント作成日時 | アカウントが作られた日時 |

> **組織 ID を忘れたとき** は、このアカウント情報セクションで確認できます (招待メールにも記載されています)。次回ログイン時や、別ブラウザからのログイン時に「組織 ID」欄へ入力する値です。

## 3. 画面テーマ (10 種)

好みに合わせて画面の配色を変更できます。

| 大分類 | バリエーション |
|---|---|
| 基本 | ライト (既定) / ダーク |
| パステル (やさしい配色) | 青 / 緑 / 黄 / 赤 |
| ポップ (鮮やかな配色) | 青 / 緑 / 黄 / 赤 |

- 選んだテーマは保存され、ログイン・ログアウト・ブラウザ再起動をまたいでも維持されます。
- 変更は即時反映されます (ページの再読み込み不要)。
- テーマは利用者ごとの設定です (同じ組織でも人によって違う配色にできます)。
- ログイン前の画面 (ログイン・パスワード再設定 等) は常にライトテーマです。

---

## 4. パスワード変更

設定画面の「パスワード変更」から、現在のパスワードを確認のうえ新しいパスワードに変更できます。

- **パスワード要件**: 10 文字以上、英大文字・英小文字・数字・記号のうち 3 種類以上
- 直近 5 回に使ったパスワードは再利用できません
- 変更しても、いま使っている端末のログインはそのまま継続します (他の端末を一括ログアウトする機能は現在ありません)

パスワードを忘れた場合は、ログイン画面の「パスワードをお忘れですか?」からリカバリーコードを使って再設定します (詳細: [アカウント追加手順](./account-setup-guide.md))。

## 5. 多要素認証 (MFA)

設定画面の「多要素認証 (MFA)」セクションで、二段階認証を設定できます。MFA を有効にすると、ログイン時にパスワードに加えて認証アプリの 6 桁コードが必要になり、セキュリティが大きく向上します。セクション見出しの横に、現在「有効」か「無効」かが表示されます。

### 有効化の手順

1. 設定画面の「多要素認証 (MFA)」セクションで **「MFA を有効化する」** を押す
2. 表示された QR コードを認証アプリ (Google Authenticator / Authy / 1Password 等) でスキャン (QR を読めない場合は、表示される文字列を手入力でも登録できます)
3. アプリに表示された 6 桁コードを入力して有効化

- テナント管理者・一般ユーザのどなたでも **任意** で有効化できます。セキュリティ強化のため有効化を推奨します。
- 有効化後は、同じ画面の **「MFA を無効化する」** から、現在のパスワードと認証アプリのコードを再入力して無効化できます。
- （サービス運営者アカウントのみ MFA が必須で無効化できませんが、これは運営側のアカウントのため、お客様の操作には影響しません。）

> MFA の入力に何度も失敗するとロックされますが、アカウント作成時に発行された **リカバリーコード** で解除・再設定できます。リカバリーコードを紛失した場合は、一般ユーザはテナント管理者に、テナント管理者は運営にリセットを依頼します。

## 6. 他の端末からログアウト

設定画面の最下部にある **「他の端末からログアウト」** を押すと、いま自分のアカウントでログインしている **現在の端末以外のすべての端末・ブラウザ** を、まとめてログアウトできます。

- スマホやパソコンを **紛失・盗難** したとき
- **共用パソコンやネットカフェ** でログインしたまま閉じてしまったとき
- 身に覚えのないログインに気づいたなど、**不正アクセスが心配** なとき

に、安全のためご利用ください。

- **いま操作している端末はログインしたまま** 継続できます (再ログインは不要です)。
- 他の端末では、次に操作したタイミングでログイン画面に戻り、再ログインが必要になります。
- この操作は自分のアカウントにのみ影響します (他の人のログインには影響しません)。

> ボタンを押すと確認ダイアログが表示されます。実行後、念のためパスワードの変更もあわせて行うと、より安心です。

## 7. FAQ

### Q1. テーマを変えても次回ログインで戻ってしまいますか?

**A.** いいえ。選んだテーマは保存され、ログイン・ログアウト・別日でも維持されます。テーマは利用者ごとの設定です。

### Q2. 言語やタイムゾーンを自分だけ変えられますか?

**A.** いいえ。言語・タイムゾーンは組織 (テナント) 全体の設定で、テナント管理者がテナント設定で変更します。組織内で日付・時刻の表示をそろえるための仕様です (現在の表示言語は日本語、英語は準備中です)。

### Q3. パスワードの条件は?

**A.** 10 文字以上で、英大文字・英小文字・数字・記号のうち 3 種類以上を含める必要があります。また、直近 5 回に使ったパスワードは再利用できません。

### Q4. MFA を解除したいです。

**A.** テナント管理者・一般ユーザのどなたでも、設定画面の「多要素認証 (MFA)」セクションの「MFA を無効化する」から、現在のパスワードと認証アプリのコードを入力して無効化できます。（サービス運営者アカウントのみ無効化できませんが、これは運営側のアカウントです。）

### Q5. 組織 ID を忘れました。

**A.** 設定画面の「アカウント情報」セクションで確認できます。招待メールにも記載されています。
