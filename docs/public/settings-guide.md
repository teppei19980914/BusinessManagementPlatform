# 個人設定 ご利用ガイド (アカウント情報・テーマ・言語・MFA)

個人設定 (`設定` 画面) では、自分のアカウント情報の確認、画面テーマ・言語・タイムゾーンの変更、多要素認証 (MFA) やパスワードの管理ができます。本ガイドでは、各設定項目をすべての利用者様向けにご説明します。

> テナント全体のプラン・請求・容量の設定 (テナント管理者向け) は別ガイドの予定です。アカウントの作成・ログインは [アカウント追加手順](./account-setup-guide.md) を参照してください。

## 1. 設定画面の開き方

画面右上のアカウントメニュー →「設定」から開きます。一般ユーザ・テナント管理者のどなたでも利用できます。

---

## 2. アカウント情報

設定画面の最上部に「アカウント情報」セクションがあり、ログインや所属確認に必要な情報を自分で確認できます。

| 項目 | 内容 |
|---|---|
| 組織 ID | ログイン時に入力する組織の識別コード |
| テナント表示名 | 所属している組織の名称 |
| メールアドレス | ログイン ID + パスワードリセットの受信先 |
| 氏名 | 登録氏名 |
| ロール | テナント管理者 / 一般ユーザ |
| 最終ログイン | 直近のログイン日時 (身に覚えのないログインの発見に) |

> **組織 ID を忘れたとき** は、このアカウント情報セクションで確認できます (招待メールにも記載されています)。

---

## 3. 画面テーマ (10 種)

好みに合わせて画面の配色を変更できます。

| 大分類 | バリエーション |
|---|---|
| 基本 | ライト (既定) / ダーク |
| パステル (やさしい配色) | 青 / 緑 / 黄 / 赤 |
| ポップ (鮮やかな配色) | 青 / 緑 / 黄 / 赤 |

- 選んだテーマは保存され、ログイン・ログアウト・ブラウザ再起動をまたいでも維持されます。
- 変更は即時反映されます (ページの再読み込み不要)。
- ログイン前の画面 (ログイン・パスワード再設定 等) は常にライトテーマです。

---

## 4. 言語・タイムゾーン

| 設定 | 内容 |
|---|---|
| **言語** | 現在は **日本語** が選択できます (英語は準備中) |
| **タイムゾーン** | 日付・時刻の表示に使うタイムゾーン (既定: 日本時間)。「システム既定を使用」も選べます |

- タイムゾーンを変更すると、画面の日時表示や、ガントチャートの「今日」の判定に反映されます。
- 変更は「保存」で即時反映されます。

## 5. 多要素認証 (MFA)

MFA (二段階認証) を有効にすると、ログイン時にパスワードに加えて認証アプリの 6 桁コードが必要になり、セキュリティが大きく向上します。

### 有効化の手順

1. 設定画面で「多要素認証を有効化」を選択
2. 表示された QR コードを認証アプリ (Google Authenticator / Authy / 1Password 等) でスキャン
3. アプリに表示された 6 桁コードを入力して有効化

- **一般ユーザ**: MFA は **任意** です (後から有効化・無効化できます)。セキュリティ強化のため有効化を推奨します。
- **テナント管理者**: MFA は **必須** です (初回セットアップ時に有効化され、解除はできません)。

> MFA の入力に何度も失敗するとロックされますが、パスワード設定時に発行された **リカバリーコード** で解除できます。

## 6. パスワード変更

設定画面の「パスワード変更」から、現在のパスワードを確認のうえ新しいパスワードに変更できます。

- **パスワード要件**: 12 文字以上、英大文字・英小文字・数字・記号のうち 3 種類以上
- 直近 5 回のパスワードは再利用できません
- 変更すると、現在の端末以外の全セッションが無効化されます (セキュリティのため)

パスワードを忘れた場合は、ログイン画面の「パスワードをお忘れですか?」からリカバリーコードを使って再設定します (詳細: [アカウント追加手順](./account-setup-guide.md))。

## 7. FAQ

### Q1. テーマを変えても次回ログインで戻ってしまいますか?

**A.** いいえ。選んだテーマは保存され、ログイン・ログアウト・別日でも維持されます。

### Q2. 英語表示にできますか?

**A.** 現在は日本語のみ対応しています。英語表示は準備中です。

### Q3. MFA を解除できません。

**A.** テナント管理者は MFA が必須のため解除できません。一般ユーザは設定画面から無効化できます。

### Q4. 組織 ID を忘れました。

**A.** 設定画面の「アカウント情報」セクションで確認できます。招待メールにも記載されています。
