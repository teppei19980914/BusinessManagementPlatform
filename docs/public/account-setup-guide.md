# アカウント追加手順

「たすきば Knowledge Relay」をご利用いただくための、**アカウント作成からログインまでの手順書**です。エンジニアの方でなくてもお読みいただけるよう、専門用語をできるだけ避けて記載しています。

---

## はじめに：登場する 3 つの役割

本サービスをお使いいただく際は、次の 3 つの役割があります。

| 役割 | 何ができる人か |
| --- | --- |
| **テナント管理者**（アドミン） | 組織の最初の管理者です。サインアップした方が自動的にこの役割になります。組織のメンバーを招待・削除できます。 |
| **一般ユーザ** | テナント管理者から招待されて参加する、通常のメンバーです。サービス内で日々の業務に利用します。 |
| **システム管理者** | サービス全体の運営担当（弊社側）です。一般のお客様には関係ありません。 |

> **テナント（組織）とは？**
> お客様の組織ごとに区切られた、独立した利用空間のことです。テナントが違えば、データはお互いに見えません。お客様の会社・部署単位で 1 つのテナントを作成してご利用いただくのが基本です。

> **「組織 ID」とは？**
> サービス内部で組織を識別するための短い英数字コード（例：`my-company`）です。**ログイン時に毎回入力が必要**になります。サインアップで決めた組織 ID は、後述する **招待メールの本文にも記載** され、忘れた際の参照源として使えます。

---

## 全体の流れ

外部からはじめてご利用になる場合、次の 4 ステップでアカウントが整います（**重要：ステップ 2 と 3 の間にテナント管理者ご自身のログインが必要です**）。

```
[ステップ 1] サインアップ
    新しい組織（テナント）を作成し、最初の管理者になる
        ↓
    パスワード設定（招待メール経由）+ リカバリーコード保存
        ↓
[ステップ 2] テナント管理者の初回ログイン
    組織 ID + メールアドレス + パスワードでログイン
        ↓
[ステップ 3] メンバー招待
    管理者が、組織で一緒に使うメンバーをメールで招待する
        ↓
[ステップ 4] 招待された方のログイン準備
    招待メールからパスワードを設定し、組織 ID + メール + パスワードでログインする
```

それぞれの手順を順番に説明します。

## ステップ 1：新しい組織（テナント）を作成する（サインアップ）

### 対象者
これからはじめて本サービスを利用される、組織の代表者（または管理担当者）の方。

### 手順

#### ① ログイン画面を開く

ブラウザでサービスの URL にアクセスすると、ログイン画面が表示されます。

画面下部の **「新規組織でご利用ですか？ サインアップ」** のリンクをクリックしてください。

#### ② サインアップフォームに必要事項を入力する

「たすきば サインアップ」画面が開きます。次の 3 つのブロックに分かれていますので、順に入力してください。

**(1) テナント（組織）情報**

| 項目 | 説明 |
| --- | --- |
| 表示用テナント名 | サービス画面に表示される、組織の名称です。例：「株式会社サンプル」「企画部」など、わかりやすい名前で構いません。 |
| 組織 ID | サービス内部で組織を識別するための短い英数字コードです。URL の一部や他のテナントとの区別に利用されます。**英小文字・数字・ハイフン**のみ使用でき、**3〜60 文字**で指定します。例：`my-company`。**ログイン時に毎回入力が必要になる重要な ID** です。 |

**(2) 請求先情報**

> **無料の Beginner プランで開設する場合、請求先情報の入力は不要です。** 請求先の入力欄は表示されず、組織名・初期管理者・規約同意だけで手軽に開設できます。請求担当者名・メールは初期管理者の氏名・メールが自動で使われます（後からテナント設定でいつでも変更できます）。
>
> 請求先情報が必要になるのは、**Expert / Pro プランで開設する場合**、または **後から無料プランから有料プランへ変更する場合** です。そのときは下記の項目を入力します（住所が未入力だと有料プランへ変更できません。テナント設定の請求先セクションで入力してください）。

| 項目 | 説明 |
| --- | --- |
| 請求種別 | 「法人」または「個人」を選択します。 |
| 会社名 / 法人名 | 法人の場合は会社名を、個人の場合はお名前を入力します。 |
| 請求担当者名 | 請求に関するご連絡をお送りする方のお名前です。 |
| 請求先メール | 請求書・領収書をお送りするメールアドレスです。 |
| 郵便番号・住所一式 | 都道府県、市区町村、番地・町名を入力します。建物名・部屋番号は任意です。 |
| 電話番号 | 任意項目です。 |
| 支払い方法 | 「銀行振込（請求書払い）」または「クレジットカード」を選択します。Beginner プラン（無料試用）の方は **試用期間中は決済対象外** のため、後から有料プランへ移行された際に有効化されます。 |

**(3) 初期管理者（ログイン用）**

| 項目 | 説明 |
| --- | --- |
| 氏名 | 最初の管理者となる方のお名前です。 |
| メールアドレス | このメールアドレスに **アカウント設定の案内メール** が届きます。後でこのアドレスでログインします。 |

**(4) 利用規約・プライバシーポリシーへの同意**

サインアップフォーム末尾に、利用規約とプライバシーポリシーへの同意チェックボックスがあります。両方にチェックを入れてください。

#### ③ ご利用プランの確認

サインアップ画面の上部に、ご利用プランの説明が記載されています。

> **Beginner プラン（90 日試用、プロジェクト作成/更新 月 50 回まで無料、最大 5 席）で開始されます。** 資産入力（ナレッジ・リスク・課題・振り返り・メモ）とチャット検索などの Embedding 機能は、Beginner プランでは月 100 件まで無料です。試用期限後は読み取り専用モードに移行します（データのエクスポート機能は引き続きご利用いただけます）。引き続きご利用の場合は試用期間内に Expert / Pro プランへのアップグレードをお願いします。

サインアップした時点では、無料の試用プランで開始されます。継続してご利用になる場合は、試用期間内に有料プランへのアップグレードをご検討ください。

> **過去にご利用履歴がある場合のご注意**
> 同じメールアドレスで以前にテナントを作成された履歴がある場合、Beginner プランでの再払い出しはできません。Expert または Pro プランをご選択ください（悪用防止ルール）。

#### ④ 「サインアップ」ボタンを押す

すべての必須項目を入力したら、画面下部の **「サインアップ」** ボタンを押します。

#### ⑤ 成功画面の確認

サインアップが成功すると、「招待メールを送信しました」画面に切り替わります。この画面には:

- **送信先メールアドレス**（入力ミスがないかご確認ください）
- メールが届かない場合のチェックリスト（迷惑メールフォルダ確認、1〜2 分の待機、法人メールのフィルタ設定確認）
- **「メールを再送する」ボタン**（届かない場合に再送可能、60 秒のクールダウンあり）
- 解決しない場合の運営お問い合わせ動線

が表示されます。

#### ⑥ 案内メールを確認する

入力した「初期管理者のメールアドレス」宛に、件名 **「たすきば - アカウントの設定」** のメールが届きます。差出人は **noreply@tasukiba.com**（自動送信専用）です。

メール本文には次の重要な情報が記載されています：

```
━━━━━━━━━━━━━━━━━━━━
【重要】ログイン情報 (再ログイン時に必要)
あなたの組織 ID: <サインアップで決めた組織 ID>
あなたのメールアドレス: <サインアップで入力したメールアドレス>
━━━━━━━━━━━━━━━━━━━━
本メールは大切に保存してください。
ログイン画面で組織 ID とメールアドレスの入力が必要になります。

以下のURLからパスワードを設定してください。
<パスワード設定リンク>

――――――――――――――――――
※ このメールはシステムからの自動送信 (noreply@tasukiba.com) です。本メールへの返信は受信できません。
お問い合わせは公式 LP のお問い合わせフォームから「お問い合わせ種別: たすきばに関するお問い合わせ」をご選択のうえご連絡ください。
https://teppei19980914.github.io/HomePage/ja/contact/
```

> **⚠️ 重要：このメールは必ず保存してください**
> メール本文の **組織 ID** と **メールアドレス** は、今後のログイン時に毎回必要です。メールを削除してしまうと、組織 ID を忘れた際に確認できなくなります。スター付け・専用フォルダ保存などで残してください。

> **📧 差出人 noreply@tasukiba.com への返信は届きません**
> 本サービスからの自動送信メール（招待メール・期限通知メール等）は受信専用のアドレスから配信されます。本メールにそのまま返信されてもサポートには届きません。問合せは必ず本文末尾の **公式 LP のお問い合わせフォーム**（種別「たすきばに関するお問い合わせ」）からご連絡ください。

#### ⑦ パスワード設定リンクをクリックする

メール本文の **「パスワードを設定する」リンク**（または text 形式の URL）をクリックしてください。

> **注意**：このリンクの有効期限は **24 時間** です。期限を過ぎた場合は、サインアップ成功画面の「メールを再送する」ボタンから再送するか、もう一度サインアップをやり直してください。

#### ⑧ パスワードを設定する

リンクを開くとパスワード設定画面が表示されます。

1. ご希望のパスワードを入力し、確認のためもう一度入力します。
   - **パスワード要件**: 10 文字以上、英大文字・英小文字・数字・記号のうち 3 種類以上を含むこと。
2. 「設定」ボタンを押します。
3. 設定が完了すると **リカバリーコード**（パスワードを忘れたときに使う合言葉のようなコード、10 件）が **一度だけ** 表示されます。
   - **必ずメモに残し、紛失しない場所に保管してください。** 後からは確認できません。
   - パスワードマネージャや、印刷物として紙保管をおすすめします。
4. 画面の **「ログイン画面へ」** ボタンを押します。

これで、組織（テナント）の作成と、最初の管理者アカウントの準備が完了しました。次のステップで実際にログインします。

## ステップ 2：テナント管理者の初回ログイン

パスワード設定が完了したら、設定したパスワードを使って初回ログインを行います。

> 💡 **初めてログインすると、たすきフクロウのウェルカム案内が一度だけ表示されます。** 使い方ガイド・よくある質問・コミュニティ (Discord)・ヘルプチャットへの入口がまとまっているので、迷ったらここから。閉じたあとも「よくある質問」ページの「🦉 はじめてのご案内をもう一度見る」ボタンから再表示できます (詳細: [たすきフクロウ AI ヘルプチャット 使い方ガイド](./owl-help-chat-guide.md#24-入口-d-初回ログイン時のウェルカム案内-2026-05-31-追加))。

### 対象者
ステップ 1 でパスワード設定を完了したテナント管理者。

### 手順

#### ① ログイン画面を開く

サービスの URL にアクセスします（パスワード設定完了画面の「ログイン画面へ」ボタンからも遷移できます）。

#### ② ログイン情報を入力する

ログイン画面には次の 3 項目があります。すべて入力してください。

| 項目 | 何を入力するか | 確認方法 |
| --- | --- | --- |
| **組織 ID** | サインアップで決めた組織 ID（例：`my-company`） | **招待メール本文の「【重要】ログイン情報」ブロック** に記載されています。サインアップ時にご自身で決めた値です。 |
| **メールアドレス** | サインアップで入力した「初期管理者メールアドレス」 | **招待メール本文の「【重要】ログイン情報」ブロック** にも記載されています。サインアップ時にご自身で入力した値です。 |
| **パスワード** | ステップ 1 ⑧ で設定したパスワード | ご自身で設定した値です。 |

> **組織 ID 入力欄について**
> - 一度ログインに成功した組織 ID は、お使いの端末のブラウザに **最大 5 件まで記録**（90 日間）され、次回以降は候補から選択できます（共用 PC の場合は「履歴をクリア」リンクから消去可能）。
> - URL クエリ（メール本文のリンク経由など）で `?tenant=<組織ID>` が含まれている場合は、組織 ID 欄に自動入力されます。

#### ③ 「ログイン」ボタンを押す

すべて入力したら **「ログイン」** ボタンを押してください。認証に成功すると、プロジェクト一覧画面に遷移します。

> **ログインできない場合**
> - **組織 ID が違う**: メール本文の「組織 ID」ブロックを再度ご確認ください。半角英小文字・数字・ハイフンのみで入力してください（全角文字や大文字は不可）。
> - **メールアドレスが違う**: サインアップ時に入力したアドレスと完全一致しているかご確認ください。
> - **パスワードが違う**: 連続で失敗するとアカウントが一時ロック（30 分）されますので、ロック前に正しい情報をご確認ください。

#### ④（任意）多要素認証（MFA）の有効化

テナント管理者は MFA（二段階認証）の有効化が **任意** です。セキュリティ強化のため、業務開始前に有効化しておくことを推奨します。

1. 画面上のメニューから **「設定」** にアクセスします。
2. 「MFA を有効化する」ボタンを押します。
3. 認証アプリ（Google Authenticator、Authy、1Password など）で QR コードをスキャンします。
4. 表示された 6 桁の数字を入力して有効化します。

これで、ステップ 3 のメンバー招待を進める準備が整いました。

## ステップ 3：テナント管理者がメンバーを招待する

組織の管理者になった方が、一緒に利用する他のメンバーをサービスに招待する手順です。

### 対象者
ステップ 2 でログインを完了したテナント管理者（または、後から管理者権限を引き継いだ方）。

### 手順

#### ① ユーザ管理画面を開く

ログイン済みの状態で、画面上のメニューから **「ユーザ管理」** にアクセスします。

#### ② 「ユーザを追加」ボタンを押す

ユーザ管理画面に「ユーザを追加」ボタンがあります。これを押すと、招待用のダイアログが開きます。

#### ③ 招待するメンバーの情報を入力する

| 項目 | 説明 |
| --- | --- |
| 氏名 | 招待する方のお名前です。 |
| メールアドレス | 招待メールをお送りする宛先です。ログイン時にもこのアドレスを使用します。 |
| 役割 | **「テナント管理者」** または **「一般ユーザ」** を選択します。組織のメンバー管理を任せたい方には「テナント管理者」を、通常の業務利用者には「一般ユーザ」を選んでください。 |

#### ④ 「追加」ボタンで招待を送信する

ボタンを押すと、入力したメールアドレス宛に件名 **「たすきば - アカウントの設定」** の案内メールが noreply@tasukiba.com から自動送信されます。**メール本文には、組織 ID（あなたの組織を識別する英数字コード）と招待先メールアドレス（ログイン ID）の両方が含まれているため、招待されたメンバーは管理者にお問い合わせいただかなくてもログイン情報を確認できます**。

> **席数の上限について**
> Beginner プラン（無料試用）は、1 テナントあたり **5 席まで** ご利用いただけます（テナント管理者を含む人数）。席数は **「有効なメンバー + 招待中のメンバー」** で数えます（招待を出した時点で 1 席を予約するため、招待したがまだログインしていない人も席を使います）。満席のときに新しい招待を出そうとすると拒否されます。先に不要なメンバーを無効化するか、不要な招待を取り消して席を空けるか、Expert / Pro プランへのアップグレードをご検討ください。

## ステップ 4：招待されたメンバーがログインする

招待を受けた方が、サービスを使い始めるまでの手順です。

> 💡 **メンバーの方も、初めてログインするとたすきフクロウのウェルカム案内が一度だけ表示されます。** 「最初に何をすればいい?」と迷ったら、案内の「🦉 たすきフクロウに聞いてみる」や使い方ガイドからどうぞ (詳細: [たすきフクロウ AI ヘルプチャット 使い方ガイド](./owl-help-chat-guide.md#24-入口-d-初回ログイン時のウェルカム案内-2026-05-31-追加))。

### 対象者
管理者から招待メールを受け取った方。

### 手順

#### ① 招待メールを開く

件名 **「たすきば - アカウントの設定」** のメール (差出人 noreply@tasukiba.com) を開きます。

メール本文の **「【重要】ログイン情報 (再ログイン時に必要)」ブロック** に、所属する組織の **組織 ID** と **あなたのメールアドレス (ログイン ID)** の両方が記載されています。ログイン時に必要になりますので、メールは保存しておいてください。

> **メールが届かない場合**
> 迷惑メールフォルダもご確認ください。それでも見つからない場合は、招待してくれた管理者の方にお伝えください。管理者は **ユーザ管理画面の該当ユーザ行から「再送」** が可能です。

#### ② パスワード設定リンクをクリックする

メール本文に記載された **「パスワードを設定する」リンク** を開きます。

> **注意**：このリンクの有効期限は **24 時間** です。期限が切れた場合は管理者に連絡し、再招待してもらってください。

#### ③ パスワードを設定する

1. ご希望のパスワードを入力し、確認のためもう一度入力します（パスワード要件はステップ 1 ⑧ と同じ）。
2. 「設定」ボタンを押します。
3. 設定が完了すると **リカバリーコード**（10 件）が一度だけ表示されます。**必ずメモに残してください。**
4. 「ログイン画面へ」のボタンからログイン画面に進みます。

#### ④ ログインする

ログイン画面で、次の 3 項目を入力して **「ログイン」** ボタンを押します。

| 項目 | 何を入力するか |
| --- | --- |
| 組織 ID | **招待メール本文の「【重要】ログイン情報」ブロック** に記載されている値（管理者の組織 ID と同じ） |
| メールアドレス | **招待メール本文の「【重要】ログイン情報」ブロック** に記載されているメールアドレス（招待メールが届いたアドレスと同一） |
| パスワード | 上記 ③ で設定したパスワード |

これでサービスをご利用いただけます。

## パスワードを忘れたとき

本サービスでは、パスワードを忘れた場合に **リカバリーコード**（パスワード設定時に表示された英数字のコード）を使って再設定します。

### 手順

1. ログイン画面で **「パスワードをお忘れですか？」** をクリックします。
2. **組織 ID**、**メールアドレス**、保管していた **リカバリーコード（1 件）** を入力します。
3. 本人確認が完了すると、新しいパスワードの入力画面に進みます。
4. 新しいパスワードを 2 回入力して送信すると、再設定完了です。

> **リカバリーコードの仕様**
> - リカバリーコードは 10 件発行され、**1 件使うと消費される** ワンタイム性です。
> - 残り枚数が少なくなった場合は、設定画面から再生成いただけます（既存コードはすべて無効化されます）。

> **リカバリーコードを紛失した場合**
> - 一般ユーザの方は、組織の管理者にご相談ください。管理者は **ユーザ管理画面の該当ユーザ行から「リカバリーコード再発行」** を実行できます（メールで新しいコードが送信されます）。
> - 管理者の方ご自身がリカバリーコードを紛失した場合は、本ページ末尾の [お問い合わせ](#お問い合わせ) セクションをご参照ください。

## よくあるご質問（FAQ）

### Q. 組織 ID を忘れてしまいました。どうすればよいですか？

A. 次の順でご確認ください。

1. **招待メールの本文を再確認**: サインアップ時／招待時に送信された件名「たすきば - アカウントの設定」のメール本文 (差出人 noreply@tasukiba.com) に、組織 ID とログイン用メールアドレスの両方が記載されています。
2. **ブラウザの履歴**: 一度ログインに成功した組織 ID は、お使いの端末のブラウザに 90 日間記録されます。ログイン画面の「組織 ID」入力欄を空にしてフォーカスすると、過去 5 件まで候補表示されます。
3. **同じ組織の管理者・メンバーに確認**: 同じ組織の他のメンバーがログイン中であれば、その方に組織 ID を聞いてください。
4. **運営にお問い合わせ**: 上記すべてで確認できない場合は、本ページ末尾の [お問い合わせ](#お問い合わせ) からご連絡ください。

### Q. 複数の組織（テナント）を作成できますか？

A. 1 つのメールアドレスにつき、**自前テナント（自分が管理者の組織）は 1 つまで** です。別の組織を作成したい場合は、別のメールアドレスでサインアップしてください。なお、複数の組織からの招待を受けて **一般ユーザとして複数組織に所属する** ことは可能です。

### Q. 組織 ID は後から変更できますか？

A. 原則として変更できません。組織を識別する重要な情報のため、サインアップ時に慎重に決めてください。

### Q. 「ログインできません」と表示されます。

A. 次の点をご確認ください。

- **組織 ID** に誤りがないか（半角英小文字・数字・ハイフンのみ）
- **メールアドレス** に誤りがないか
- **パスワード** に誤りがないか
- **パスワード設定（招待メールのリンクからの設定）を完了している** か
- 連続してログインに失敗するとアカウントが **一時ロック（30 分）** されます。少し時間をおいてから再試行してください。長時間解除されない場合は管理者にご連絡ください。
- **退会済 / 削除済アカウント** ではないか（管理者に確認）

### Q. 招待メールが届きません。

A. 次の順でご確認ください。

1. **迷惑メール / スパムフォルダ** をご確認ください。
2. **1〜2 分待ってから受信箱を更新** してください（メールサーバの遅延の場合があります）。
3. **法人メールをご利用の場合**、受信制限・フィルタ設定をご確認ください（情シス担当者への確認が必要な場合があります）。
4. サインアップした方は、サインアップ成功画面の **「メールを再送する」ボタン** をご利用ください（60 秒のクールダウンあり）。
5. 招待されたメンバーの方は、招待してくれた管理者に **ユーザ管理画面から再送** を依頼してください。

### Q. メンバーを削除するとどうなりますか？

A. 削除されたメンバーは以降ログインできなくなります（論理削除）。本人が作成したナレッジ・課題・振り返り等のデータは組織内に残り、他のメンバーが引き続き閲覧・編集できます。詳しい挙動はサービス内のユーザ管理画面の説明をご確認ください。

### Q. 試用期間（90 日）が終わるとどうなりますか？

A. **読み取り専用モード** に切り替わり、新しいデータの追加・編集・削除はできなくなります。ただし、次の操作は引き続き可能です。

- **データの閲覧**
- **データのエクスポート**（バックアップ取得用）
- **プランのアップグレード**（Expert / Pro へ切り替えると即時に書き込み機能が復活します）
- **テナントのセルフ解約**（テナント設定画面から実行可能）

引き続きサービスをご利用になる場合は、読み取り専用モード期間中に Expert または Pro プランへのアップグレードをお願いします。

### Q. 読み取り専用モードのまま放置するとどうなりますか？

A. **テナント作成から 180 日（=試用期間 90 日 + 読み取り専用猶予 90 日）が経過した時点で、業務データは自動的に物理削除されます**。物理削除されると復旧はできません。

タイムラインは以下の通りです。

| 経過日数 | 状態 | できること |
|---|---|---|
| 0〜59 日 | Beginner 試用中 | すべての機能を利用可能 |
| 60 日 | 期限警告メール送信 | 通常運用継続 |
| 75 日 | 期限警告メール再送 | 通常運用継続 |
| 90 日 | **読み取り専用モードに移行** + 期限切れ通知メール（180 日後の自動削除を予告） | 閲覧 / エクスポート / アップグレード / セルフ解約 のみ可能 |
| 90〜179 日 | 読み取り専用モード継続（救済期間） | 同上。アップグレードすれば即時に通常運用に復帰 |
| **180 日** | **業務データの自動物理削除** | ログイン不可。データ復旧不可 |

データを残したくない場合はセルフ解約をご利用いただき、データを必要な場合は **必ず 180 日経過前にエクスポート** をお取りください。

### Q. MFA（二段階認証）は必須ですか？

A. テナント管理者 / 一般ユーザの方は **任意** です（設定画面から有効化／無効化可能）。プラットフォーム運営者（システム管理者）のみ強制となります。セキュリティ向上のため、業務開始前の有効化をおすすめします。

### Q. Expert / Pro から Beginner プランに戻せますか？

A. **戻せません** ([ADR-0013](../adr/0013-beginner-downgrade-prohibition.md))。Beginner は試用期間（90 日）用のプランのため、一度上位プランに上げると同じ組織では使えなくなります。月額の利用をゼロに抑えたい場合は、Expert / Pro のまま **テナント設定 →「月次予算上限」を ¥0** に設定してください（AI 機能が一時停止し、追加課金が発生しません）。

### Q. Expert / Pro を解約するとデータはいつ消えますか？

A. **テナント設定の「セルフ解約」を実行すると、解約から約 90 日後に業務データが物理削除** されます。猶予期間中はログインと既存データの閲覧・エクスポートが可能です。必ず削除前にエクスポートをお取りください（請求書など法律で保管が必要な記録は別途 5 年間運営側で保管します）。

### Q. 退会したあと、同じ組織で再加入できますか？

A. **削除済の組織 ID は再利用できません**。新しい組織として作り直す必要があります（以前の業務データは復元できないため、必要な情報は必ず削除前にエクスポートしてください）。
