# アカウント追加手順

「たすきば Knowledge Relay」をご利用いただくための、**アカウント作成からログインまでの手順書**です。エンジニアの方でなくてもお読みいただけるよう、専門用語をできるだけ避けて記載しています。

---

## はじめに：登場する 3 つの役割

本サービスをお使いいただく際は、次の 3 つの役割があります。

| 役割 | 何ができる人か |
| --- | --- |
| **テナント管理者**（アドミン） | 組織の最初の管理者です。サインアップした方が自動的にこの役割になります。組織のメンバーを招待・削除できます。 |
| **一般ユーザ** | テナント管理者から招待されて参加する、通常のメンバーです。サービス内で日々の業務に利用します。 |
| **システム管理者** | サービス全体の運営担当（弊社側）です。一般のお客様には関係ありません。 |

> **テナント（組織）とは？**
> お客様の組織ごとに区切られた、独立した利用空間のことです。テナントが違えば、データはお互いに見えません。お客様の会社・部署単位で 1 つのテナントを作成してご利用いただくのが基本です。

---

## 全体の流れ

外部からはじめてご利用になる場合、次の 3 ステップでアカウントが整います。

```
[ステップ 1] サインアップ
    新しい組織（テナント）を作成し、最初の管理者になる
        ↓
[ステップ 2] メンバー招待
    管理者が、組織で一緒に使うメンバーをメールで招待する
        ↓
[ステップ 3] 招待された方のログイン準備
    招待メールからパスワードを設定し、ログインする
```

それぞれの手順を順番に説明します。

---

## ステップ 1：新しい組織（テナント）を作成する（サインアップ）

### 対象者
これからはじめて本サービスを利用される、組織の代表者（または管理担当者）の方。

### 手順

#### ① ログイン画面を開く

ブラウザでサービスの URL にアクセスすると、ログイン画面が表示されます。

画面下部の **「新規組織でご利用ですか？ サインアップ」** のリンクをクリックしてください。

#### ② サインアップフォームに必要事項を入力する

「たすきば サインアップ」画面が開きます。次の 3 つのブロックに分かれていますので、順に入力してください。

**(1) テナント（組織）情報**

| 項目 | 説明 |
| --- | --- |
| 表示用テナント名 | サービス画面に表示される、組織の名称です。例：「株式会社サンプル」「企画部」など、わかりやすい名前で構いません。 |
| 組織 ID | サービス内部で組織を識別するための短い英数字コードです。URL の一部や他のテナントとの区別に利用されます。**英小文字・数字・ハイフン**のみ使用でき、**3〜60 文字**で指定します。例：`my-company` |

**(2) 請求先情報**

| 項目 | 説明 |
| --- | --- |
| 請求種別 | 「法人」または「個人」を選択します。 |
| 会社名 / 法人名 | 法人の場合は会社名を、個人の場合はお名前を入力します。 |
| 請求担当者名 | 請求に関するご連絡をお送りする方のお名前です。 |
| 請求先メール | 請求書・領収書をお送りするメールアドレスです。 |
| 郵便番号・住所一式 | 都道府県、市区町村、番地・町名を入力します。建物名・部屋番号は任意です。 |
| 電話番号 | 任意項目です。 |

**(3) 初期管理者（ログイン用）**

| 項目 | 説明 |
| --- | --- |
| 氏名 | 最初の管理者となる方のお名前です。 |
| メールアドレス | このメールアドレスに **アカウント設定の案内メール** が届きます。後でこのアドレスでログインします。 |

#### ③ ご利用プランの確認

サインアップ画面の上部に、ご利用プランの説明が記載されています。

> **Beginner プラン（90 日試用、月 100 回まで無料）で開始されます。試用期限後は読み取り専用モードに移行し、エクスポートも停止します。引き続きご利用の場合は試用期間内に Expert / Pro プランへのアップグレードをお願いします。**

サインアップした時点では、無料の試用プランで開始されます。継続してご利用になる場合は、試用期間内に有料プランへのアップグレードをご検討ください。

#### ④ 「サインアップ」ボタンを押す

すべての必須項目を入力したら、画面下部の **「サインアップ」** ボタンを押します。

#### ⑤ 案内メールを確認する

入力した「初期管理者のメールアドレス」宛に、件名 **「たすきば - アカウントの設定」** のメールが届きます。

メール本文に記載された **パスワード設定リンク** をクリックしてください。

> **注意**：このリンクの有効期限は **24 時間** です。期限を過ぎた場合は、お手数ですが再度サインアップをご依頼ください。

#### ⑥ パスワードを設定する

リンクを開くとパスワード設定画面が表示されます。

1. ご希望のパスワードを入力し、確認のためもう一度入力します。
2. 「設定」ボタンを押します。
3. 設定が完了すると **リカバリーコード**（パスワードを忘れたときに使う合言葉のようなコード）が **一度だけ** 表示されます。
   - **必ずメモに残し、紛失しない場所に保管してください。** 後からは確認できません。
4. 画面の案内に従ってログイン画面へ進みます。

これで、組織（テナント）の作成と、最初の管理者アカウントの準備が完了しました。

## ステップ 2：テナント管理者がメンバーを招待する

組織の管理者になった方が、一緒に利用する他のメンバーをサービスに招待する手順です。

### 対象者
ステップ 1 を完了したテナント管理者（または、後から管理者権限を引き継いだ方）。

### 手順

#### ① ログインしてユーザ管理画面を開く

1. ログイン画面で、ご自身のメールアドレスとパスワードを入力してログインします。
2. 画面上のメニューから **「ユーザ管理」** にアクセスします。

#### ② 「ユーザを追加」ボタンを押す

ユーザ管理画面に「ユーザを追加」ボタンがあります。これを押すと、招待用のダイアログが開きます。

#### ③ 招待するメンバーの情報を入力する

| 項目 | 説明 |
| --- | --- |
| 氏名 | 招待する方のお名前です。 |
| メールアドレス | 招待メールをお送りする宛先です。ログイン時にもこのアドレスを使用します。 |
| 役割 | **「テナント管理者」** または **「一般ユーザ」** を選択します。組織のメンバー管理を任せたい方には「テナント管理者」を、通常の業務利用者には「一般ユーザ」を選んでください。 |

#### ④ 「追加」ボタンで招待を送信する

ボタンを押すと、入力したメールアドレス宛に件名 **「たすきば - アカウントの設定」** の案内メールが自動送信されます。

> **席数の上限について**
> Beginner プラン（無料試用）では、1 テナントあたりの利用可能人数に上限があります。上限に達した場合は招待がエラーになりますので、有料プランへのアップグレードをご検討ください。

## ステップ 3：招待されたメンバーがログインする

招待を受けた方が、サービスを使い始めるまでの手順です。

### 対象者
管理者から招待メールを受け取った方。

### 手順

#### ① 招待メールを開く

件名 **「たすきば - アカウントの設定」** のメールを開きます。

> **メールが届かない場合**
> 迷惑メールフォルダもご確認ください。それでも見つからない場合は、招待してくれた管理者の方にお伝えください。管理者は再度の招待が可能です。

#### ② パスワード設定リンクをクリックする

メール本文に記載されたリンクを開きます。

> **注意**：このリンクの有効期限は **24 時間** です。期限が切れた場合は管理者に連絡し、再招待してもらってください。

#### ③ パスワードを設定する

1. ご希望のパスワードを入力し、確認のためもう一度入力します。
2. 「設定」ボタンを押します。
3. 設定が完了すると **リカバリーコード** が一度だけ表示されます。**必ずメモに残してください。**
4. 「ログイン画面へ」のリンクからログイン画面に進みます。

#### ④ ログインする

ログイン画面で、招待されたメールアドレスと、先ほど設定したパスワードを入力して **「ログイン」** ボタンを押します。

これでサービスをご利用いただけます。

## パスワードを忘れたとき

本サービスでは、パスワードを忘れた場合に **リカバリーコード**（パスワード設定時に表示された英数字のコード）を使って再設定します。

### 手順

1. ログイン画面で **「パスワードをお忘れですか？」** をクリックします。
2. **メールアドレス** と、保管していた **リカバリーコード** を入力します。
3. 本人確認が完了すると、新しいパスワードの入力画面に進みます。
4. 新しいパスワードを 2 回入力して送信すると、再設定完了です。

> **リカバリーコードを紛失した場合**
> 一般ユーザの方は、組織の管理者にご相談ください。管理者がアカウントを再発行することで復旧できます。
> 管理者の方ご自身がリカバリーコードを紛失した場合は、サービス運営（システム管理者）までお問い合わせください。

## よくあるご質問（FAQ）

### Q. 複数の組織（テナント）を作成できますか？

A. 1 つのメールアドレスにつき、利用できる組織は 1 つです。別の組織を作成したい場合は、別のメールアドレスでサインアップしてください。

### Q. 組織 ID は後から変更できますか？

A. 原則として変更できません。組織を識別する重要な情報のため、サインアップ時に慎重に決めてください。

### Q. 「ログインできません」と表示されます。

A. 次の点をご確認ください。

- メールアドレス・パスワードに誤りがないか
- パスワード設定（招待メールのリンクからの設定）を完了しているか
- 連続してログインに失敗するとアカウントが一時ロックされる場合があります。少し時間をおいてから再試行してください。長時間解除されない場合は管理者にご連絡ください。

### Q. メンバーを削除するとどうなりますか？

A. 削除されたメンバーは以降ログインできなくなります。詳しい挙動はサービス内のユーザ管理画面の説明をご確認ください。

### Q. 試用期間（90 日）が終わるとどうなりますか？

A. 読み取り専用モードに切り替わり、新しいデータの追加やエクスポートができなくなります。引き続きご利用の場合は、試用期間内に Expert または Pro プランへのアップグレードをお願いします。
