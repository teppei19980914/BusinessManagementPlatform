# テナント設定 ご利用ガイド（プラン・使用量・請求・データ入出力）

`テナント設定` 画面（`/settings/tenant`）では、組織（テナント）全体のプラン・使用量・請求・データ入出力・解約を管理します。本ガイドは **テナント管理者** 向けです。

> 個人のアカウント・テーマ・言語・二段階認証は別の [個人設定ガイド](./settings-guide) を、ユーザの招待・管理は [テナント管理者ガイド](./admin-guide) を参照してください。
> この画面は **テナント管理者のみ** が開けます（一般メンバー・運営者には表示されません）。

画面上部の「DB 容量 / API 利用量を再集計」を押すと、最新の使用量で集計し直せます（画面を開いた時点でも自動集計されます）。画面は **概要・使用量・請求** の 3 つのタブに分かれています。

---

## 1. 概要タブ

### プラン
- **Beginner（90 日試用・無料）/ Expert / Pro** から選び「変更を保存」。
- **Beginner には戻せません**（ADR-0013）。**Expert ↔ Pro は押した瞬間に反映**されます（日割りなし）。
- 料金や違いの詳細は [料金プランガイド](./plan-guide) を参照してください。

### 言語・タイムゾーン
- テナント全体の表示言語・タイムゾーンです。**配下の全ユーザ**の画面表示や、Beginner 残日数・月初リセットの境界に適用されます。

### スターターデータ（見本データ）の取り込み・削除
- 運営が用意した **見本の顧客・プロジェクト・課題・リスク・ナレッジ・振り返り** を 1 クリックで自テナントに取り込めます。データが何も無い状態でも、提案エンジンや AI チャット検索の便利さをすぐに体験できます。
- 取り込んだデータは **通常データとして一覧に表示** され、編集・削除もできます。お試し後は「取り込んだスターターデータを削除」で **一括削除** できます（手動で追加・編集した通常のデータは削除されません）。
- 取り込みは複数回行え、その回数分だけ増えます。
- **料金**: 無料の Beginner プランでは無料枠（DB 50MB）の範囲で利用できます。Expert / Pro プランでは取り込んだデータ分だけ DB 使用量が増え、容量に応じた従量課金の対象になるため、取り込み前に確認が表示されます。
- 詳しくは [スターターデータ ご利用ガイド](./starter-data-guide) を参照してください。
- なお、提案エンジン・AI チャットは **自テナント（自社）のデータのみ** を検索します。他テナント（他のお客様）のデータが混ざることはありません。

### データエクスポート
- テナントの全業務データ（プロジェクト / ナレッジ / 課題 / 振り返り / メモ / 顧客 / ステークホルダー等）を **ZIP** でダウンロードできます（JSON ＋ CSV ＋ 添付の URL）。パスワードや二段階認証の秘密情報は含まれません。

### データインポート
データインポートには 2 つの方法があります（いずれもテナント管理者専用）。

- **外部データ移行（CSV 一括取込）** — Excel や旧 PM ツールなど **外部システムからの初回移行** 用。**顧客・プロジェクト・WBS（タスク）・リスク・課題・ナレッジ・振り返り** の 7 種類を、種類ごとの CSV から取り込めます。テンプレ CSV をダウンロードして埋め、列を画面項目に割り当てて取り込みます。取り込みルールは画面の「CSVインポートルール」を参照（→ [外部データ CSV 取込手順](./csv-import-guide)）。
- **ZIP 一括取込（バックアップ復元 / テナント間移行用）** — **本サービスから出力した ZIP の取り込み専用**です（バックアップ復元や別テナントへの移行）。外部 Excel / 独自フォーマットの ZIP は受け付けません。**追記モード**：既存のデータは残したまま、ZIP 内のデータを新規追加します（既存データの削除・上書きは行いません）。メールアドレスが一致する既存ユーザはそのまま再利用され、新規追加ユーザは「有効（初回パスワード要設定）」の状態で登録されます。

> 他サービスの API と直接つないで自動取り込みする「API 連携」は今後のバージョンで提供予定です。

### 詳細情報（サポート用）
- テナント UUID・作成日時・単価（Haiku ¥10/call・Sonnet ¥15/call）を確認できます。

### テナント解約（危険な操作）
- 現在のテナント名を正しく入力して確認 → 解約します。
- 解約直後は読み取り専用、**90 日後に業務データが物理削除**（復元不可）されます。監査ログ・課金根拠は保管されます。
- **解約前に必ずデータエクスポート**をおすすめします。

---

## 2. 使用量タブ

- **生成 AI 系利用量**: 当月の LLM 実行回数（Beginner は月 50 回まで無料）と Embedding 生成回数（Beginner は月 100 件まで無料）。残数も表示されます。
- **月次予算上限**（Expert / Pro のみ）: AI 利用額の上限を設定できます（予期せぬ請求の防止）。
- **DB 系利用量**: DB 容量・ファイルストレージの「現在の使用量 / 月中ピーク（請求根拠）/ 想定請求額」を表示します。容量課金の詳細は [データ容量ガイド](./db-capacity-billing-guide) / [ファイルストレージガイド](./file-storage-billing-guide) を参照してください。
- 「embedding 未生成のデータがあります」のお知らせが出ることがあります。これは月初の処理で自動補完されます。

---

## 3. 請求タブ

- **今月請求金額**: LLM 費用・Embedding 費用・DB 容量超過（想定）・ストレージ超過（想定）・合計（税抜）。月末に確定します。
- **請求先情報**: 請求先種別（法人/個人）・会社名・担当者・メール・住所・支払い方法を登録/更新します。
- **支払い方法**: 銀行振込（請求書 PDF）またはクレジットカード（Stripe 自動引落）。切替方法は [支払い方法ガイド](./payment-methods-guide) / [クレジットカード払いガイド](./credit-card-payment-guide)、締め日・期日は [支払い条件ガイド](./payment-terms-guide) を参照してください。
- **請求履歴**: 「請求履歴を見る」から、直近 6 ヶ月の請求金額・入金状況を確認できます。
