## 1. プロジェクトとは

プロジェクトは、1 件の案件そのものを表す「親」の単位です。目的・背景・スコープ・期間・担当などを持ち、配下に **タスク (WBS) / 見積もり / リスク・課題 / 振り返り / メンバー / ステークホルダー** をぶら下げて管理します。

プロジェクトの目的・背景・スコープを入力すると、たすきばが過去の類似資産を自動で提案します (提案エンジン)。

## 2. プロジェクト一覧画面

`プロジェクト` ナビ (`/projects`) から、参加しているプロジェクトを一覧・検索できます。

### 一覧の列

| 列 | 内容 |
|---|---|
| プロジェクト名 | 案件名称 |
| 顧客名 | 顧客企業名 |
| 開発方式 | スクラッチ / PowerPlatform など |
| PM/TL | 主担当者 |
| ステータス | 企画中〜クローズ (後述 §4) |
| 開始予定日 | 計画開始日 |
| 終了予定日 | 計画終了日 |
| 進捗概要 | 完了タスク数 / 全タスク数 など |
| 高優先度リスク件数 | 優先度「高」の未クローズ件数 |
| 更新日時 | 最終更新日時 |

### 検索・絞り込み

キーワード / 顧客名 / 開発方式 / ステータス / PM/TL / 開始予定日 (範囲) / 終了予定日 (範囲) で絞り込めます。「クローズ案件を表示」の切替も可能です。

> 列幅はドラッグで調整でき、各一覧の「列幅をリセット」で既定に戻せます (調整した幅はブラウザのタブを閉じると既定に戻ります)。

### 新規作成

「新規プロジェクト作成」ボタンから作成します (テナント管理者 / PM/TL のみ。メンバー・閲覧者には表示されません)。

## 3. プロジェクトの入力項目

| 項目 | 必須 | 備考 |
|---|---|---|
| プロジェクト名 | ○ | 100 文字以内 |
| 顧客 | ○ | 顧客マスタからの選択式 (自由入力は不可。先に顧客を登録) |
| 目的 | ○ | 2000 文字以内 |
| 背景 | ○ | 2000 文字以内 |
| スコープ | ○ | 2000 文字以内 |
| スコープ外 | × | 2000 文字以内 |
| 開発方式 | ○ | 選択式 |
| 対象業務領域 | × | 複数選択可 (提案精度向上に有効) |
| 技術スタック | × | タグ形式 (提案精度向上に有効) |
| 開始予定日 | ○ | 日付 |
| 終了予定日 | ○ | 日付 |
| PM/TL | ○ | ユーザ選択 |
| 備考 | × | 2000 文字以内 |

> **目的・背景・スコープ** を入力して保存すると、AI がタグを自動抽出し、提案エンジンの索引に登録します (Expert / Pro はこのとき LLM 課金が 1 回。Beginner は月 50 回まで無料)。3 項目すべて空欄なら AI は呼ばれず ¥0 です。詳細: [API 利用 ご利用ガイド](./api-usage-guide.md)。
>
> 日付入力欄には「今日」(今日の日付をセット)・「削除」(値をクリア) ボタンが付いています。

## 4. 7 つの状態と状態遷移

プロジェクトは **7 つの状態** を持ち、企画から完了・振り返りまでを一方向に進みます。

| 状態 | 意味 |
|---|---|
| **企画中** | 案件立上げ。目的・背景・スコープを整理する段階 |
| **見積中** | 見積もりの作成と根拠整理を行う段階 |
| **計画中** | WBS・タスク・スケジュール・担当割当を確定する段階 |
| **実行中** | 進捗更新・実績記録・リスク/課題対応を行う段階 |
| **完了** | 作業完了後、実績整理と締め処理を行う段階 |
| **振り返り完了** | 振り返りとナレッジ化が完了した段階 |
| **クローズ** | 最終確定済みで、原則更新不可の段階 |

### 遷移のルール

```
企画中 → 見積中 → 計画中 → 実行中 → 完了 → 振り返り完了 → クローズ
```

- **一方向のみ**。逆戻り・飛び級はできません。
- 状態変更は **PM/TL またはテナント管理者** が行えます。クローズの解除はテナント管理者のみです。
- 状態の変更は履歴 (監査ログ) に記録され、誰がいつ変更したかを追跡できます。

## 5. 状態ごとにできること・できないこと

プロジェクトの状態によって、操作できる範囲が変わります (ロール権限に加えて状態でも制限されます)。○ = 可 / △ = 条件付き / × = 不可。

| 操作 | 企画中 | 見積中 | 計画中 | 実行中 | 完了 | 振り返り完了 | クローズ |
|---|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 基本情報・スコープ編集 | ○ | ○ | △ | △ | × | × | × |
| 見積もり作成・確定 | △ | ○ | △ | × | × | × | × |
| WBS / タスク作成 | × | △ | ○ | △ | × | × | × |
| 進捗率・実績の更新 | × | × | △ | ○ | △ | × | × |
| リスク起票 | ○ | ○ | ○ | ○ | △ | × | × |
| 課題起票 | × | △ | ○ | ○ | △ | × | × |
| ナレッジ下書き作成 | ○ | ○ | ○ | ○ | ○ | × | × |
| 振り返り作成・確定 | × | × | × | △ | ○ | × | × |
| 閲覧・検索 | ○ | ○ | ○ | ○ | ○ | ○ | ○ |

> クローズ状態のプロジェクトは原則すべて読み取り専用です。閲覧・検索・エクスポートは引き続き行えます。

## 6. プロジェクト詳細画面のタブ

プロジェクト名をクリックすると詳細画面が開き、上部のタブから各機能に移動できます。

| タブ | 内容 | 閲覧できるロール |
|---|---|---|
| 概要 | 基本情報・進捗/リスク概要 | 全ロール |
| WBS / タスク | タスク階層・進捗管理 ([タスク・WBS ガイド](./task-wbs-guide.md)) | 全ロール (編集は PM/TL) |
| ガント | スケジュールの時系列表示 ([ガントチャート ガイド](./gantt-guide.md)) | 全ロール |
| リスク / 課題 | プロジェクト配下のリスク・課題 ([リスク・課題 ガイド](./risk-issue-guide.md)) | 全ロール (起票はメンバー以上) |
| 振り返り | 完了後の総括 ([振り返り ガイド](./retrospective-guide.md)) | 全ロール (作成は PM/TL) |
| 見積もり | 見積項目の管理 ([見積もり ガイド](./estimate-guide.md)) | **PM/TL・管理者のみ** |
| メンバー | 参加メンバーとロール ([メンバー管理 ガイド](./members-guide.md)) | PM/TL・管理者 |
| ステークホルダー | 関係者の整理 ([ステークホルダー ガイド](./stakeholder-guide.md)) | **PM/TL・管理者のみ** |
| 参考 | 過去資産の自動提案 ([提案エンジン ガイド](./suggestion-guide.md)) | **PM/TL・管理者のみ** |

> 見積もり・ステークホルダー・参考タブは、メンバー / 閲覧者には表示されず、直接 URL を開いても閲覧できません。

## 7. 顧客 (Customer) の管理

プロジェクトの発注元となる **顧客** は、テナント管理者が「顧客管理」画面 (`/customers`) でマスタ管理します。プロジェクト作成時は、ここで登録した顧客から選択します。

### 顧客一覧・詳細の項目

| 項目 | 必須 | 備考 |
|---|---|---|
| 顧客名 | ○ | 100 文字以内 (同名の併存可) |
| 部門 | × | 100 文字以内 |
| 担当者 | × | 100 文字以内 |
| 担当者メール | × | メール形式 |
| 備考 | × | 1000 文字以内 |

一覧では、各顧客に **紐付いている進行中プロジェクトの件数** が表示されます。

### 顧客の削除 (カスケード)

- 紐付くプロジェクトが **0 件** の顧客 → 確認のうえ削除できます。
- 紐付くプロジェクトが **1 件以上** ある顧客 → 詳細画面のカスケード削除で、プロジェクト本体・WBS・見積・メンバー・添付を削除します。リスク・課題・振り返り・ナレッジは、削除するかどうかをチェックボックスで個別に選べます (他プロジェクトと共有しているナレッジは紐付け解除のみ)。

> 顧客管理は **テナント管理者のみ** が操作できます。

## 8. 削除とデータの扱い

- プロジェクト・資産の削除は **論理削除** が基本です (誤操作からの保護)。
- プロジェクト削除ダイアログでは、配下のどの資産を一緒に削除するかをチェックボックスで選べます。チェックしなかった資産は「全○○」横断画面に残ります。
- 削除・解約後のデータ保持期間や復活については [アカウント追加手順](./account-setup-guide.md) および [料金プラン ご利用ガイド §5.4](./plan-guide.md#54-解約テナントセルフ削除時の請求) を参照してください。

## 9. FAQ

### Q1. プロジェクトの状態を前の段階に戻せますか?

**A.** いいえ。状態遷移は一方向で、逆戻り・飛び級はできません。これは「企画 → 完了 → 振り返り」という案件の自然な流れを崩さないための設計です。

### Q2. メンバーですが新規プロジェクトを作成できません。

**A.** プロジェクトの作成・編集・状態変更は **PM/TL またはテナント管理者** のみが行えます。メンバー・閲覧者にはボタンが表示されません。

### Q3. 顧客を選ぼうとしても候補に出てきません。

**A.** プロジェクトの顧客は **顧客マスタからの選択式** です。先にテナント管理者が「顧客管理」画面で顧客を登録する必要があります。

### Q4. 目的・背景・スコープを入力すると必ず課金されますか?

**A.** Expert / Pro では、これら本文を入力して保存すると AI タグ付けで 1 回課金されます (¥10 / ¥15)。**3 項目すべて空欄なら課金されません**。Beginner は月 50 回まで無料です。詳細: [API 利用 ご利用ガイド](./api-usage-guide.md)。

### Q5. クローズしたプロジェクトはもう編集できませんか?

**A.** 原則として読み取り専用です。閲覧・検索・エクスポートは引き続き可能です。クローズの解除はテナント管理者のみが行えます。
