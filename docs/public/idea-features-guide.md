# アイデア出し機能 ご利用ガイド

**投票・ホワイトボード・匿名FAQ** の 3 ツールで、プロジェクト内のアイデア出しを支援します。各ツールは「全員が安心して発言できる匿名性」と「チームの合意形成」を両立するよう設計されています。

> アイデア出し機能は **v1.5.0** で追加されました。

## 1. 機能の概要と使い分け

アイデア出し機能は、プロジェクト詳細画面の **「ツール」タブ** から利用できます。

| ツール | 向いているシーン |
|---|---|
| **投票** | 候補を絞り込みたいとき。二択投票 (賛否+理由) やドット投票 (重みづけ配点) で全員の意見を可視化。 |
| **ホワイトボード** | ブレインストーミング。付箋形式でアイデアを集め、クローズ後に俯瞰する。 |
| **匿名FAQ** | 常時質問・疑問を受け付けたいとき。KPT や振り返りに限らず、プロジェクト期間中いつでも活用可能。 |

## 2. 投票 (Voting)

### 作成方法

1. 「ツール」タブ →「ライブ投票」または「事前投票」→「新規作成」
2. タイトル・投票方式 (二択投票 / ドット投票) を設定
3. 選択肢を入力 (二択投票は 2 件固定、ドット投票は 2〜10 件)
4. 終了時刻を設定して作成
   - **ライブ投票**: 制限時間を分単位で指定（作成と同時にカウントダウン開始）
   - **事前投票**: 終了日時を日時ピッカーで指定

### 投票方式

各セッションカードには投票方式バッジ（**二択投票** / **ドット投票**）が表示されます。

| 方式 | 特徴 |
|---|---|
| **二択投票 (binary)** | 選択肢から 1 つを選び、理由を必ず記入。「賛否の根拠を全員に残させたい」場面に最適。 |
| **ドット投票 (dot)** | 持ち票 (1〜10 票) を複数の選択肢に自由に配分。重みを付けた優先度投票に最適。 |

### 匿名化のしくみ

- **セッション中 (active)**: 自分の投票内容のみ確認できます。他の参加者の結果は見えません。
- **クローズ後**: 全員の集計結果 (ドット投票なら各選択肢の合計票数、二択投票は全回答の理由一覧) が公開されます。誰の投票かは引き続き公開されません。

### 自動クローズ

終了時刻を過ぎたセッションは、次回アクセス時に自動でクローズされます。作成者はいつでも手動でクローズできます。

### 日時表示

セッション一覧には **作成日時**・**終了日時** を表示します。クローズ済みセッションにはさらに **クローズ日時** が表示されます（形式: `YYYY/MM/DD HH:MM:SS`）。

## 3. ホワイトボード (Whiteboard)

### 作成方法

1. 「ツール」タブ →「ホワイトボード」→「+ 新規作成」
2. タイトル・終了日時を設定
3. 参加者は「付箋を投稿」から自由にコメントを追加

### 付箋の匿名化

- **セッション中**: 自分が投稿した付箋のみ表示されます。他の参加者の付箋は見えません。
- **クローズ後**: 全員の付箋が公開されます。投稿者は非公開のままです。

### カテゴリラベル

付箋に任意のカテゴリラベル (例: 「改善案」「懸念点」) を付与できます。クローズ後はラベルで絞り込んで俯瞰できます。

### 日時表示

セッション一覧には **作成日時**・**終了日時** を表示します。クローズ済みセッションにはさらに **クローズ日時** が表示されます（形式: `YYYY/MM/DD HH:MM:SS`）。

## 4. 匿名FAQ

### 使い方

- 「ツール」タブ →「匿名FAQ」→ テキストエリアに入力して「投稿」
- 誰でもいつでも質問を投稿できます (セッション不要)
- 他のメンバーは「**回答する/見る**」をクリックして回答を追加
- ❤ いいねボタンで有用な質問をハイライト

### ソート

- **新着順**: 最近更新 (回答投稿) のあったスレッドが先頭
- **投稿順**: スレッドの作成日時順
- **いいね順**: いいね数の多い質問が先頭

### 日時表示

スレッド一覧には **作成日時** を表示します。解消済みスレッドにはさらに **解消日時** が表示されます（形式: `YYYY/MM/DD HH:MM:SS`）。  
2 行目には回答件数と最終回答日時を表示します。

### スレッドのクローズ

投稿者は「解消」ボタンでスレッドをクローズできます。クローズ後も回答の追加は可能です。

## 5. 絞り込みとキーワード検索

各ツールの一覧画面には **キーワード検索ボックス** と **ステータスフィルタ** が用意されています。セッション数が増えてきたときに目的のセッションをすばやく見つけられます (v1.5.0 追加)。

| ツール | キーワード検索の対象 | ステータスフィルタ |
|---|---|---|
| **投票** | セッションタイトル | すべて / アクティブ / クローズ済み |
| **ホワイトボード** | セッションタイトル | すべて / アクティブ / クローズ済み |
| **匿名FAQ** | 質問本文 | — |

- **キーワード検索**: 入力後 0.4 秒で自動的に再検索されます (Enter キーは不要)。
- **ステータスフィルタ**: 「すべて」でアクティブ・クローズ済みの両方を表示、「アクティブ」または「クローズ済み」で絞り込めます。
- **組み合わせ**: キーワードとステータスは同時に指定できます。

## 6. フクロウ連携 — PJ内から探す

プロジェクト詳細画面の **たすきフクロウ** には「**📂 PJ内から探す**」タブ (3 本目) が表示されます (v1.5.0 追加)。このタブでは、**今いるプロジェクト内の資産だけ**を対象に意味検索できます。

**検索できる資産**

- ナレッジ / リスク・課題 / 振り返り
- クローズ済みの 投票セッション・ホワイトボードセッション・匿名FAQ スレッド

> アイデアツールの結果は、セッション/スレッドを**クローズした時点**で検索インデックスに登録されます。アクティブ中のセッションは検索対象外です。

**全資産横断との使い分け**

| タブ | 対象 | 向いているシーン |
|---|---|---|
| 🔍 全資産から探す | 全プロジェクト | 「似た案件が過去にないか調べたい」 |
| 📂 PJ内から探す | 今いるプロジェクトのみ | 「このPJで出た結論をまとめて振り返りたい」 |

> 「PJ内から探す」タブはプロジェクト詳細画面のみに表示されます。

詳しい検索の使い方は [チャットボット意味検索 使い方ガイド](./chat-semantic-search-guide) を参照してください。

## 7. アイデア-資産間リンク

各アイデアツールのセッション・スレッドから、プロジェクト内の **タスク・リスク・課題・ナレッジ・振り返り** へのリンクを手動で設定できます。

### リンクの追加方法

1. 投票セッション、ホワイトボードセッション、または Q&A スレッドの詳細を開く
2. 「関連する資産を追加」セクションから資産の種類と ID を指定
3. 「リンクを追加」で保存

### 逆引き表示

リンクを設定した資産の詳細ダイアログには、「関連するアイデア (N 件)」セクションが表示されます。どのアイデア出しセッションから注目されたかを後から確認できます。

## 8. クローズプロジェクトでの挙動

プロジェクトが **クローズ (closed)** になると、ツールタブは **読み取り専用** になります。

### セッションの自動クローズ (v1.5.0)

プロジェクトをクローズした瞬間に、クローズ前に **active** だった投票/ホワイトボードセッションと **open** 状態の Q&A スレッドは**すべて自動的にクローズ**されます。クローズ後の各セッション・スレッドは閲覧のみ可能です。

| 操作 | クローズ後の挙動 |
|---|---|
| ツールタブの閲覧 | **可能** — タブは常時表示 |
| 既存セッション・スレッドの閲覧 | **可能** — 集計結果も含めて閲覧できる |
| 新規セッション作成 / 投票 / 付箋投稿 / Q&A 投稿 | **不可** — 画面上の操作ボタンが非表示 |
| セッションのクローズ・削除 | **不可** |
| ❤ いいね | **不可** |

> この制限は UI だけでなく **API レベルでも強制**されます。直接 API を呼び出した場合も 403 で拒否されます。

## 10. FAQ

### Q1. 投票中に誰が何票入れたか分かりますか？

**A.** 分かりません。投票セッションがクローズされるまで、自分以外の結果は見えない設計です。クローズ後も「誰が」は公開されず、集計数のみが表示されます。

### Q2. ホワイトボードをクローズし忘れた場合は？

**A.** 終了日時を過ぎたセッションは、次回アクセス時に自動でクローズされます。また作成者はいつでも手動クローズできます。

### Q3. 付箋は後から編集できますか？

**A.** 現在はセッション中に付箋を削除して再投稿することで同等の操作ができます (付箋の直接編集は非対応)。

### Q4. Q&A で「匿名」とありますが、管理者には分かりますか？

**A.** API レスポンスや画面には一切返しません。DB には書込者 ID が保存されますが、テナント管理者も画面から誰の投稿か確認することはできません。

### Q5. アイデア-資産間リンクを削除するとどうなりますか？

**A.** 表示上のリンクが解除されるだけで、アイデアセッション本体も資産本体も削除されません。誤ってリンクを作成した場合は安全に削除できます。

### Q6. ライブ投票と事前投票の違いは何ですか？

**A.** ライブ投票は「制限時間（分）」を指定して作成し、作成した瞬間から時間が進みます。会議中にリアルタイムで意見を集める場面に最適です。事前投票は終了日時を日時ピッカーで指定するため、非同期で意見を募る場合に向いています。
