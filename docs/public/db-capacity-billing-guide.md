# データ容量 ご利用ガイド (従量課金)

たすきば Knowledge Relay は、ご利用いただくデータ容量に応じた **シンプルな従量課金** を採用しています。本ガイドでは「いくら使ったらいくら請求されるのか」「いつ集計されるのか」「どこで使用量を確認できるのか」をご説明します。

> 本ガイドは **テナント管理者・一般ユーザどなたでも** ご利用いただける内容です。
> 一部の操作 (使用量画面の閲覧) はテナント管理者権限が必要です。

## 1. 3 行サマリ

| 項目 | 内容 |
|---|---|
| **無料枠** | **50MB まで完全無料** |
| **超過時** | **1GB ごとに 50 円** (1MB 未満は繰上、税抜) |
| **上限** | **テナント当たり 50GB** (技術上の安全上限、超過時は書込が停止) |

シンプルに言うと「使った分だけ、1GB あたり 50 円」です。隠れた料金やプラン縛りはありません。

> 🆕 **Beginner プランの方** (ADR-0025 / 2026-05-29): 50MB 無料枠を超えると **新規作成 / 更新が自動でブロック** されます (削除のみ可、overage 課金は発生しません)。不要なデータを削除すれば自動的に再集計され (debounce 30 秒)、再び書込み可能になります。50MB を超えるデータを継続利用したい場合は **Expert / Pro プランへのアップグレード** をご検討ください (¥50/GB tier の従量課金で 50GB まで継続利用可能)。詳細: [Beginner プラン仕様](../specification/BEGINNER_PLAN.md)

## 2. 料金体系

データ容量の超過分は **1GB tier ごと** に 50 円ずつ加算される **階段関数型** の料金体系です。

| 月中の最大使用量 | 月額料金 (税抜) |
|---|---|
| 0 〜 50MB | **0 円** (無料枠) |
| 51MB 〜 1,050MB | **50 円** |
| 1,051MB 〜 2,050MB | **100 円** |
| 2,051MB 〜 3,050MB | **150 円** |
| ... | ... |
| 50GB (上限) | **2,500 円** |

> 「1GB = 1,000MB」「1MB = 1,000,000 バイト」(SI 単位、業界標準) です。
>
> たとえ 1 バイトでも超過があれば次の tier に切上げられます (例: 50MB + 1 バイト → 51MB tier = 50 円)。

### 旧プランをご利用だった方へ

旧料金体系 (2026-05-15 〜 2026-05-24) では、月額固定の 4 段階プラン (Standard ¥0 / Plus ¥500 / Pro ¥1,500 / Enterprise ¥5,000) でしたが、**2026-05-25 から従量課金に統一** されました。

| プラン (旧) | 月額 | 月額 (新従量、同等容量) | 差額 |
|---|---|---|---|
| Standard (20MB) | ¥0 | ¥0 (= 50MB 無料枠内) | — |
| Plus (220MB) | ¥500 | ¥50 (≤1GB 内) | **-¥450/月** |
| Pro Storage (1GB) | ¥1,500 | ¥50 (≤1GB 内) | **-¥1,450/月** |
| Enterprise (5GB) | ¥5,000 | ¥250 (5GB 利用時) | **-¥4,750/月** |

ほぼすべてのユーザで **大幅な値下げ** となります。

## 3. 何が課金対象になるか

たすきば 上で **テナント (=ご利用組織) ごとに保有するすべてのデータ** が対象です:

| カテゴリ | 主なデータ |
|---|---|
| 業務データ | プロジェクト、タスク、見積、見積項目 |
| 知見資産 | Knowledge、リスク・課題、振り返り、メモ |
| 顧客・人 | 顧客、ステークホルダー、**ユーザ (= ご招待されたメンバー)** |
| コミュニケーション | コメント、メンション、通知、添付ファイル情報 |
| 設定・履歴 | テナント設定、課金履歴、月次使用量履歴、監査ログ |

> **ユーザ (= 招待されたメンバー) のレコードも対象** ですが、1 ユーザあたり 2KB 程度の小さなデータなので、25,000 ユーザを招待しても 50MB 無料枠内に収まります。
>
> 添付ファイル本体 (画像 / PDF 等) は v1 では外部ストレージ未対応のため metadata のみ計上 (= 1 件あたり数百バイト)。

## 4. いつ集計され、いつ請求されるか

### 4.1 集計の仕組み

**「月中の最大使用量 (peak)」** が課金根拠になります。

```
時間軸 → Day 1     Day 15     Day 25    Day 30 (月末)
使用量:  100MB  →  500MB  →   100MB  →  100MB

月末の請求対象 = 月中の最大値 = 500MB
```

たとえ月末に削除して使用量を下げても、**月内の最大値で請求される** ことにご注意ください。これは「月末に大量削除 → 月初に再アップロード」という抜け道を防ぐための仕様です (= Supabase 側の原価は GB-Hours で発生しているため)。

### 4.2 集計タイミング

| 集計方法 | 頻度 | 役割 |
|---|---|---|
| **書き込み時の即時計測** | データ追加/更新ごと | ハードキャップ判定 + peak リアルタイム更新 |
| **日次自動再計算** | 毎日 09:00 UTC (= 18:00 JST) | すべてのデータ操作を確実に補足 (= 課金漏れ防止) |
| **月初の請求確定** | 毎月 1 日 00:00 UTC (= 09:00 JST) | 前月分の最終課金額を確定 |

### 4.3 請求タイミング

```
2026-06-01 ─────────────── 6 月の利用 ─────────────── 2026-06-30
                                                        │
                                                        │ 月中の最大使用量を「peak」として記録
                                                        ↓
2026-07-01 09:00 JST  ★ 月初の請求確定 (自動)
                       │ 6 月分の peak から課金額を算出
                       │ 課金履歴に記録
                       │
2026-07-03 〜 07-05 頃  Stripe (決済プラットフォーム) で請求書発行
                       │
                       ├─ クレジットカード払いの場合 → 自動引落
                       └─ 銀行振込払いの場合       → 請求書メール送付
```

### 4.4 月の途中でご解約された場合

月の途中で退会された場合も、**退会時点までの使用量が当月分として即時請求** されます。

```
2026-06-15 14:00  退会操作
                  │
                  ├─ 当月 (6/1 〜 6/15) の peak で課金額算出
                  ├─ 当該月の請求書に計上
                  └─ ご退会処理を確定
```

退会タイミングを月末直前に集中させても、その時点までの利用分は確実に請求対象になります。

## 5. 使用量の確認方法

### 5.1 テナント管理者の方

テナント設定画面 (`/settings/tenant`) で **いつでも当月の使用状況** を確認できます。

表示される情報:
- **現在の使用量**: 直近 24 時間以内に更新されたデータ容量
- **月中ピーク**: 当月内の最大使用量 (= 請求根拠)
- **想定請求額**: 月中ピークから算出した請求予測額 (税抜)
- **進捗バー**: 50GB 上限に対する使用率
- **Level バッジ**: 警告レベル (正常 / Level 1 / Level 2 / Level 3)

### 5.2 Level (警告レベル) について

| Level | 月中ピーク | 状態 | 想定月額 |
|---|---|---|---|
| **正常** | 0 〜 1GB | 通常運用 | 0 〜 50 円 |
| **Level 1** | 1GB 〜 10GB | 通常運用 (使用量増加注意) | 50 〜 500 円 |
| **Level 2** | 10GB 〜 50GB | 高額請求注意 | 500 〜 2,500 円 |
| **Level 3** | 50GB 到達 | **書込が一時的に停止されます** (データ読み取り・エクスポートは継続可能) | 2,500 円 |

> Level 1 / 2 はあくまで「お知らせ」であり、書込制限はかかりません。Level 3 (50GB 到達) で初めて書込が停止されます。

## 6. 50GB 上限について

たすきば では **テナント 1 組織あたり 50GB の技術的上限** を設定しています。

### なぜ上限があるのか

これは料金 (コスト) ではなく **技術的な安全策** です。

たすきば はすべてのテナントが同じデータベースサーバ上で稼働しているため、特定のテナントが極端に大容量のデータを抱えると、他のテナントの動作速度が低下する可能性があります。50GB は「ご利用者様の体感速度を守るための上限」です。

### 上限に達した場合

```
状態: 50GB 到達 (Level 3)
─────────────────────────
✅ できること:
  - データの閲覧 (read)
  - データのエクスポート (CSV ダウンロード等)
  - 不要なデータの削除
  - 既存データの編集 (容量が増えない範囲で)

❌ できないこと:
  - 新規データの追加
  - 既存データへの大幅な追加 (容量増加を伴う変更)
```

### 復旧方法

不要なデータ (古いプロジェクト、過去の議事録、不要な Knowledge 等) を削除いただくと、自動的に書込が再開されます。

それでも 50GB 内で運用が難しい場合は[お問い合わせ](mailto:support@example.com)よりご相談ください (= 個別の追加容量契約を検討させていただきます)。

## 7. 請求の例 (典型シナリオ)

### 例 1: 個人ユーザ (小規模)
- 月中ピーク: 30MB
- 課金額: **¥0** (= 無料枠内)

### 例 2: 小規模チーム (5 名、プロジェクト 10 件)
- 月中ピーク: 250MB
- 課金額: **¥50** (税抜) / 月 (= 1GB tier 内)

### 例 3: 中規模チーム (20 名、プロジェクト 50 件、Knowledge 1,000 件)
- 月中ピーク: 800MB
- 課金額: **¥50** (税抜) / 月 (= 1GB tier 内)

### 例 4: 中規模チーム (30 名、長期運用、累計 Knowledge 3,000 件)
- 月中ピーク: 1.5GB
- 課金額: **¥100** (税抜) / 月 (= 2GB tier)

### 例 5: 大規模利用 (50 名、複数年運用)
- 月中ピーク: 5GB
- 課金額: **¥250** (税抜) / 月 (= 5GB tier)

### 例 6: ヘビーユーザ (上限到達)
- 月中ピーク: 50GB
- 課金額: **¥2,500** (税抜) / 月 (= 上限料金)
- 状態: 書込停止 (削除推奨)

## 8. 料金変更時のお知らせルール

将来料金体系を変更する場合、必ず以下のルールでお知らせします:

> **値上げ・課金体系変更の場合**:
> 効力発生日の **30 日以上前** から ユーザ規約 (Terms of Service) 該当ページに掲示し、
> かつ **ご登録のメールアドレス宛にお知らせ** をお送りします。

- **値下げ** の場合は即時適用される場合があります
- **過去のご使用分には旧料金が適用** されます (= 遡及課金は行いません)
- 単価変更を行う場合は ADR (Architecture Decision Record) として理由・経緯・影響範囲を公開します

## 9. FAQ

### Q1. ユーザを招待すると課金されますか?

**A.** はい、技術的にはユーザレコードもデータ容量に含まれますが、1 ユーザあたり 2KB 程度と非常に小さく、**50MB 無料枠内で 25,000 ユーザまで招待可能** な計算です。実用上、ユーザ招待で課金が発生するケースはほぼありません。

### Q2. ファイル (画像 / PDF) をアップロードすると課金されますか?

**A.** 現バージョン (v1) では添付ファイル本体は外部ストレージに保存されず、ファイル名やサイズ情報 (metadata、1 件数百バイト) のみ計上されます。本格的なファイルストレージ機能は将来バージョン (v1.x 以降) で別途料金体系を設ける予定です。

### Q3. 月の途中で大量データを投入してすぐ削除した場合、課金されますか?

**A.** **はい、月内の最大値 (peak) で課金されます**。たとえ月末に削除して使用量を 0 に戻しても、月中の peak は記録されているため、その時点の容量で請求されます。これは Supabase (基盤データベース) の原価が「使った時間×容量」で発生しているため、抜け道を防ぐ仕様です。

### Q4. 想定請求額と実際の請求額がズレることはありますか?

**A.** 設計上発生しません。たすきば の請求システムは「使用量の記録 = ダッシュボード表示 = 請求書 = Stripe (決済プラットフォーム)」がすべて同じ数値を参照する **billing invariant** (請求一致保証) を実装しているため、表示と請求は完全一致します。

### Q5. 「現在の使用量」と「月中ピーク」が異なるのはなぜですか?

**A.** 「現在の使用量」は最新の値、「月中ピーク」は **当月内のいかなる時点における最大値** です。月の途中でデータを削除した場合は「現在の使用量 < 月中ピーク」となり、請求は **月中ピークの値** で行われます。

### Q6. 50GB 上限を引き上げることはできますか?

**A.** 通常の料金体系内では引き上げできません。これは技術的な安全策 (= 他テナントへの影響防止) のためです。50GB を超えるデータ運用が必要な場合は、別途専用環境を含めた個別契約を相談させていただきます。[お問い合わせ](mailto:support@example.com)よりご連絡ください。

### Q7. 容量を確認できる頻度は?

**A.** **24 時間以内に最新化** されます。書込操作直後はリアルタイムに反映されますが、それ以外のテーブルも含めた全体の使用量は日次自動再計算 (毎日 18:00 JST) で正確化されます。請求の根拠となる「月中ピーク」は常に最新の正確な値が記録されます。

### Q8. テナント (組織) を解約したら過去分の請求はどうなりますか?

**A.** 解約手続きと同時に、その時点までの当月分使用量が即時集計され、月末の通常請求と同じ経路で請求書に計上されます。解約タイミングによる課金漏れは発生しません。

### Q9. 消費税はどう加算されますか?

**A.** 本ガイドの料金はすべて **税抜表記** です。請求書発行時に消費税 (現状 10%) が一括加算されます。

### Q10. クレジットカード払いと銀行振込払いで料金は変わりますか?

**A.** 変わりません。どちらの支払い方法でも同じ料金体系・同じ請求タイミングです。支払い方法の詳細は[クレジットカード払い ご利用ガイド](./credit-card-payment-guide.md)をご参照ください。
