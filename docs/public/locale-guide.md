# 表示言語ガイド (日本語 / English)

> たすきば Knowledge Relay の **表示言語** を切替える方法と、現時点で英語表示に対応している画面の一覧です。
>
> 関連: [個人設定ガイド](./settings-guide.md) / [テナント設定ガイド](./tenant-settings-guide.md) / [画面一覧リファレンス](./screen-reference.md)

---

## 1. 対応言語

| 言語 | コード | 状態 |
|---|---|---|
| 日本語 | `ja-JP` | 全画面対応 (既定) |
| English | `en-US` | **主要画面に対応** (v1.3.0 / 2026-06-19) |

> 中国語・ベトナム語・韓国語など追加言語のご要望は、Discord コミュニティまたはお問い合わせフォームよりお寄せください。技術的には基盤が整備されており、翻訳作業を経て追加対応可能です。

---

## 2. 表示言語の切替手順

### 個人で切替える (推奨)

各ユーザが自分の表示言語を上書きできます。テナント既定とは独立に保存されます。

1. 画面右上のユーザアイコンをクリック → **設定** を選択
2. 「アカウント情報」セクション内の **表示言語** で「日本語」または「English」を選択
3. **保存** をクリック
4. 次のページ遷移から選択した言語で表示されます (再ログイン不要)

### テナント既定として切替える (テナント管理者のみ)

テナント全員の既定言語を変更します。各メンバーが個人設定で上書きしていない場合に適用されます。

1. テナント管理者でログイン
2. 画面右上のユーザアイコン → **テナント設定** を選択
3. **概要** タブの「言語・タイムゾーン」セクションで **表示言語** を選択
4. **保存** をクリック

## 3. 英語表示に対応している画面 (v1.3.0 時点)

選択中の言語を **English** に切替えると、以下の画面・操作で英語表示に追従します。

### 設定画面

- **アカウント設定**: テーマ／パスワード変更／MFA（二段階認証）設定の操作完了・失敗トースト、設定情報の読み込み失敗バナー
- **テナント設定**: 読み込み失敗バナー、「設定画面へ戻る」リンク、集計中表示、不整合修復ボタンの確認ダイアログ
- **クレジットカード支払い設定**: カードの状態表示（未登録／有効／要対応）、カード登録・変更フロー、カード情報取得失敗の警告、カード期限切れ／拒否時の案内
- **DB 容量・ファイルストレージのプラン詳細**: 無料枠の表示、超過時のアップグレード導線、料金体系の説明
- **請求履歴**: 直近 6 ヶ月の対象月・支払方法・金額・ステータス・入金日／支払期日の表記
- **外部データ移行**: 取り込み手順ガイド

### 画面横断 (各エンティティ)

- **顧客管理（一覧・詳細）**: 登録・更新・削除トースト
- **メモ**: 作成・更新・削除トースト、読み込み失敗バナー
- **マイタスク**: 読み込み失敗バナー
- **WBS（タスク）**: WP／アクティビティ削除・作成、一括複製・一括削除、一括計画更新・一括実績更新、タスク更新、WBS エクスポートのトースト
- **リスク／課題・振り返り・ナレッジ**: 作成／更新／削除のトースト、類似過去課題のヒント表示
- **「全○○」画面**: 紐付けプロジェクト件数表示・操作ボタン

### システム管理者向け運営画面 (super_admin 専用、エンドユーザには非表示)

- 全テナント一覧 / 個別テナント診断 / 新規テナント払い出しフォーム / テナント削除・停止／再開ダイアログ
- 請求ダッシュボード（当月サマリ・月次推移・銀行振込手動消込）
- cron 実行履歴 / Stripe DLQ 監視 / メール送付失敗一覧
- DB 容量アラート・ファイルストレージアラート / 周知バナー管理 / スターターデータ キュレーション
- super_admin ダッシュボードのナビゲーション

## 4. 現時点で英語表示に切替わらない画面 (順次対応予定)

以下の画面・領域は、English 設定でも日本語表示のまま動作します。次リリース以降で順次対応してまいります。

| 領域 | 内容 |
|---|---|
| 認証 | サインアップ／ログイン／パスワードリセット／MFA 認証画面 |
| ヘルプ | お問い合わせ画面、使い方ガイド、よくある質問（たすきフクロウ AI チャット） |
| テナント設定の一部 | プラン変更フォーム本体、データ移行ウィザード（CSV／API 連携）、API 連携インポートウィザード |
| メール本文 | 招待メール、パスワードリセット、Beginner プラン期限通知 等 |
| 通知 | 画面右下のベル（Notification） |
| データエクスポート | エクスポート時に同梱される README |

## 5. よくある質問

**Q. 「English」に切替えても日本語のまま表示される画面があります**
→ 上記「4. 現時点で英語表示に切替わらない画面」をご確認ください。順次拡張予定です。

**Q. メールは英語で届きますか?**
→ v1.3.0 時点ではメール本文は日本語固定です。次回以降のリリースで対応予定です。

**Q. たすきフクロウ AI チャットは英語で答えてくれますか?**
→ v1.3.0 時点では FAQ／ガイドコンテンツが日本語のため、回答も日本語が中心です。en-US 並列カタログの整備後、英語応答にも対応予定です。

**Q. 日付や金額の表示はどうなりますか?**
→ 日付フォーマットは選択した言語と組織のタイムゾーン設定に応じて自動変換されます。金額は現在 JPY（¥）固定です。

**Q. 個人設定とテナント既定はどちらが優先されますか?**
→ **個人設定** が優先されます。個人設定が未指定の場合のみ、テナント既定が適用されます。

**Q. URL に言語コード（`/en/`, `/ja/` など）は付きますか?**
→ 付きません。URL は言語によらず共通で、表示言語のみがユーザ／テナント設定に応じて切り替わります。
