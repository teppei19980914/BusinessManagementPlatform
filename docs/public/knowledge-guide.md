# ナレッジ ご利用ガイド

ナレッジは、過去のプロジェクトで得た **教訓・パターン・調査結果** を蓄積し、次の案件で再利用するための資産です。本ガイドでは、一覧の見方・入力項目・公開フロー・権限を、すべての利用者様向けにご説明します。

> CSV で既存ナレッジを一括取り込みする場合は [外部データ CSV 取込手順](./csv-import-guide.md) を参照してください。

## 1. ナレッジとは

「**こういうときは、こうする**」という判断の根拠や、調査して分かったこと、障害対応の記録などを、決まった枠組みで残す資産です。公開すると、未来の類似プロジェクトで自動的に提案され、組織の知見として再利用できます。

---

## 2. どこで使うか

- **横断一覧** (`全ナレッジ` ナビ): テナント内の公開ナレッジを横断して閲覧・検索します。
- **プロジェクト配下**: プロジェクトに紐付けてナレッジを作成・管理できます (1 つのナレッジを複数プロジェクトに紐付け可)。
- **振り返りから**: 振り返りで挙げた知見を「ナレッジ化」して登録できます。

## 3. 一覧画面の列

| 列 | 内容 |
|---|---|
| タイトル | ナレッジ名 |
| 種別 | 調査 / 検証 / 障害対応 / 教訓 など |
| 対象プロジェクト | 紐付く案件 |
| 対象工程 | 要件定義 / 設計 など |
| 対象技術 | 技術タグ |
| 開発方式 | スクラッチ など |
| 公開状態 | 下書き / 公開 |
| 作成者 | ユーザ名 |
| 更新日時 | 最終更新 |
| 再利用性 | 低 / 中 / 高 |

> 行をクリックすると詳細 (背景・内容・結果 など) が読み取り表示されます。

## 4. 入力項目

| 項目 | 必須 | 備考 |
|---|---|---|
| タイトル | ○ | 150 文字以内 |
| ナレッジ種別 | ○ | 選択式 (failure / success / lesson / template / general 等) |
| 対象プロジェクト | △ | 任意だが推奨 |
| 対象工程 | × | 複数選択可 |
| 対象技術 | × | タグ形式 (カンマ区切り) |
| 開発方式 | × | 選択式 |
| 背景 | ○ | 2000 文字以内 |
| 内容 | ○ | 5000 文字以内 |
| 結果 | ○ | 3000 文字以内 |
| 結論 | × | 2000 文字以内 |
| 推奨事項 | × | 2000 文字以内 |
| 再利用性 | × | 低 / 中 / 高 |
| 関連タスク / リスク / 見積項目 | × | 複数紐付け可 |
| 関連リンク | × | URL を複数添付可 |
| 公開範囲 | ○ | 下書き / 公開 |

> 種別・工程・技術のタグを入れておくと、提案エンジンが類似ナレッジを見つけやすくなります。

## 5. 下書きと公開 (公開フロー)

ナレッジには 2 つの公開範囲があります。

| 公開範囲 | 表示ラベル | 誰が見られるか | 提案エンジン / 意味検索 |
|---|---|---|---|
| **下書き** | 自分のみ | 作成者本人 (+ テナント管理者) | 対象外 (索引化されず、課金もされない) |
| **公開** | テナント全員 | 同じ組織の全ユーザ | 対象 (索引化され提案・検索に出る) |

- まず **下書き** で書きためて、内容が固まったら **公開** する、という流れが使えます。
- **公開にした瞬間に検索インデックス (索引化) が作られます**。Expert / Pro ではこのとき Embedding 課金が 1 回、Beginner は月 100 件の無料枠内です。
- 公開を取り消して下書きに戻すこともできます (既存の索引は提案側のフィルタで除外されます)。

詳細: [しくみ・用語ガイド §3](./concepts-guide.md#3-公開範囲-visibility-のしくみ)

## 6. 権限

| 操作 | 管理者 | PM/TL | メンバー | 閲覧者 |
|---|:--:|:--:|:--:|:--:|
| 公開済みを見る・検索する | ○ | ○ | ○ | ○ |
| 下書きを見る | ○ | ○ | △ (自分のもの) | × |
| 新規作成 (下書き) | ○ | ○ | ○ | × |
| 自分の下書きを編集 | ○ | ○ | ○ | × |
| 他人の下書き・公開済みを編集 | ○ | ○ | × | × |
| 公開する / 公開範囲を変更 | ○ | ○ | × | × |
| 自分が作成したものを削除 (一覧から) | ○ | ○ | ○ | × |
| 「全ナレッジ」からの削除 (モデレーション) | ○ | × | × | × |

> メンバーは下書きの作成と、自分が作成 (または担当) したナレッジの編集ができます。公開はPM/TL 以上が行います。

## 7. FAQ

### Q1. 下書きのナレッジは他の人に見られますか?

**A.** いいえ。下書き (自分のみ) は作成者本人とテナント管理者しか見られず、提案エンジンにも出ません。安心して書きためられます。

### Q2. ナレッジを公開すると課金されますか?

**A.** Expert / Pro では公開時に索引化が走り、Embedding 課金が 1 回 (¥5) 発生します。Beginner は月 100 件の無料枠内です。下書きのままなら課金されません。

### Q3. 1 つのナレッジを複数プロジェクトで使えますか?

**A.** はい。ナレッジは複数プロジェクトに紐付けられます。提案エンジンでも、関連する複数の案件で参照されます。

### Q4. 振り返りで挙げた学びをナレッジにできますか?

**A.** はい。振り返り画面から「ナレッジ化」して登録できます。詳細は [振り返り ご利用ガイド](./retrospective-guide.md) を参照してください。
