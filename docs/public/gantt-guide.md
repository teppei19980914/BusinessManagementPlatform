# ガントチャート ご利用ガイド

ガントチャートは、プロジェクトのタスクを **時系列で可視化** する画面です。スケジュールの遅れや進捗を一目で把握できます。本ガイドでは、表示の見方と使い方を、すべての利用者様向けにご説明します。

> ガントチャートは **表示専用** です。タスクの編集は [タスク・WBS ご利用ガイド](./task-wbs-guide.md) から行います。

## 1. どこで使うか

- **プロジェクト単位**: プロジェクト詳細 →「WBS 管理」タブ →「ガントチャートを表示」
- **横断 (自分の担当)**: 「マイタスク」画面 →「ガントチャートを表示」(自分の担当タスクをプロジェクトごとに縦並びで表示)

---

## 2. 表示の見方

- タイムラインは **日単位** で表示されます (月ヘッダー + 日付/曜日の 2 段)。
- **週末 (土日)** はグレー背景、**当日** は青背景でハイライトされます。
- **日本の祝日** (元日・こどもの日・敬老の日 など) は土日と同じグレー背景で表示され、マウスを乗せると祝日名が表示されます。
- 各タスクが棒で表示され、親ワークパッケージ名がタスク名の上に小さく表示されます。

---

## 3. 表示される列

| 列 | 内容 |
|---|---|
| 親 WP 名 | 所属するワークパッケージ名 |
| タスク名 | 表示対象タスク |
| 担当者 | 担当 |
| 開始予定日 / 終了予定日 | 計画日 |
| 進捗率 | 0〜100% |
| ステータス | 未着手 など |
| マイルストーン | 該当時のみ |
| 遅延フラグ | 遅延しているタスクの表示 |

---

## 4. 便利な表示の工夫

- **「今日」に自動スクロール**: 画面を開くと、自動的に「今日」の列が左端に来るようにスクロールします。毎回手で今日を探す必要がありません。
- **タイムゾーン対応**: 「今日」の判定は、あなたの設定したタイムゾーンを基準に行われます。
- **言語対応**: 月ヘッダーの表記は表示言語に従います (日本語なら「2026年5月」)。
- **担当者・ステータスでの絞り込み**、表示期間の切替ができます。
- タスク名の列幅はドラッグで調整できます。

## 5. 権限

| 操作 | 管理者 | PM/TL | メンバー | 閲覧者 |
|---|:--:|:--:|:--:|:--:|
| ガントを見る (プロジェクト内) | ○ | ○ | ○ | ○ |
| 自分の担当ガントを見る (マイタスク経由) | ○ | ○ | ○ | ○ |
| ガント上で直接編集 | × | × | × | × |

> ガントチャートは全ロールが閲覧できます。直接編集はできず、タスクの変更は WBS / タスク画面から行います。

## 6. FAQ

### Q1. ガント上でタスクの日付を直接ドラッグして変えられますか?

**A.** いいえ、ガントは表示専用です。日程の変更は [タスク・WBS 画面](./task-wbs-guide.md) から行ってください (PM/TL・管理者)。

### Q2. 開いたとき今日の位置が分かりにくいです。

**A.** 画面を開くと自動的に「今日」の列が左端に来るようスクロールします。当日は青背景でハイライトされています。

### Q3. 自分の担当タスクだけを横断で見たいです。

**A.** 「マイタスク」画面の「ガントチャートを表示」から、自分の担当タスクをプロジェクトごとにまとめて確認できます。
