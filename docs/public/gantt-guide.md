# 進捗確認 ご利用ガイド (旧称: ガントチャート)

進捗確認は、プロジェクトのタスクを **時系列で可視化する「ガント表示」** と、**担当者ごとに直近の状況をまとめる「担当者別確認」** (v1.3.0 追加) の 2 つの見方を組み合わせて、プロジェクトの進み具合を一目で把握できる画面です。

> 進捗確認は **表示専用** です。タスクの編集は [タスク・WBS ご利用ガイド](./task-wbs-guide) から行います。

## 1. どこで使うか

- **プロジェクト単位**: プロジェクト詳細 →「進捗確認」タブ (WBS 管理タブと並ぶ独立タブです)
- **横断 (自分の担当)**: 「マイタスク」画面 →「ガントチャートを表示」(自分の担当タスクをプロジェクトごとに縦並びで表示。担当者別確認ボードはプロジェクト単位のみの機能で、マイタスク側にはまだありません)

「進捗確認」タブを開くと、画面上部に **「ガント表示」「担当者別確認」** の 2 つの切替ボタン (チップ) があります。どちらか一方だけ、または両方同時に表示できます (初期状態は両方 ON)。

---

## 2. ガント表示の見方

- タイムラインは **日単位** で表示されます (月ヘッダー + 日付/曜日の 2 段)。
- **週末 (土日)** はグレー背景、**当日** は青背景でハイライトされます。
- **日本の祝日** (元日・こどもの日・敬老の日 など) は土日と同じグレー背景で表示され、マウスを乗せると祝日名が表示されます。
- 各タスクが棒で表示され、親ワークパッケージ名がタスク名の上に小さく表示されます。

## 3. ガント表示で見られる列

| 列 | 内容 |
|---|---|
| 親 WP 名 | 所属するワークパッケージ名 |
| タスク名 | 表示対象タスク |
| 担当者 | 担当 |
| 開始予定日 / 終了予定日 | 計画日 |
| 進捗率 | 0〜100% |
| ステータス | 未着手 など |
| マイルストーン | 該当時のみ |
| 遅延フラグ | 遅延しているタスクの表示 |

## 4. 担当者別確認ボードの見方

「担当者別確認」チップを ON にすると、担当者ごとに 1 枚のカードが並びます。各カードは **終わった / やっている / これから / 保留** の 4 つの列に分かれていて、その担当者が抱えているタスクの状況がひと目で分かります。WBS であらかじめ計画したタスクだけでなく、後から差し込まれた突発タスクも同じカードに表示されます。

- **対象期間**: 「今日」を基準に **前後 3 日間** のタスクが表示されます。
- **終わった**: その期間内に完了したタスク
- **やっている**: 現在進行中のタスク (期間に関わらず表示されます)
- **これから**: これから着手予定のタスク (予定の開始日を過ぎてもまだ未着手のタスクも、ここに表示されます)
- **保留**: 一時停止中のタスク (期間に関わらず常に表示されます)
- **「遅延」バッジ**: 「やっている」「これから」のタスクのうち、予定の終了日を過ぎているものに表示されます。ヒアリングの際に確認すべきタスクの目印として使えます。
- 該当するタスクが 1 つもない担当者のカードは表示されません。

> ヒアリングの前に「担当者別確認」を開くと、各メンバーに「何が終わったか」「今何をしているか」「次に何をする予定か」を聞く準備がしやすくなります。

## 5. 便利な表示の工夫

- **「今日」に自動スクロール**: ガント表示を開くと、自動的に「今日」の列が左端に来るようにスクロールします。毎回手で今日を探す必要がありません。
- **タイムゾーン対応**: 「今日」の判定は、あなたの設定したタイムゾーンを基準に行われます。
- **言語対応**: 月ヘッダーの表記は表示言語に従います (日本語なら「2026年5月」)。
- **担当者・ステータスでの絞り込み** (ガント表示)、表示期間の切替ができます。担当者の絞り込みは担当者別確認ボードにも反映されます。
- タスク名の列幅はドラッグで調整できます。
- 表示切替 (ガント表示/担当者別確認) の選択状態は、ブラウザを閉じるまで保持されます。

## 6. 権限

| 操作 | 管理者 | PM/TL | メンバー | 閲覧者 |
|---|:--:|:--:|:--:|:--:|
| ガント表示を見る (プロジェクト内) | ○ | ○ | ○ | ○ |
| 担当者別確認ボードを見る (プロジェクト内) | ○ | ○ | ○ | ○ |
| 自分の担当ガントを見る (マイタスク経由) | ○ | ○ | ○ | ○ |
| ガント上で直接編集 | × | × | × | × |

> 進捗確認は全ロールが閲覧できます。直接編集はできず、タスクの変更は WBS / タスク画面から行います。

## 7. FAQ

### Q1. ガント上でタスクの日付を直接ドラッグして変えられますか?

**A.** いいえ、進捗確認は表示専用です。日程の変更は [タスク・WBS 画面](./task-wbs-guide) から行ってください (PM/TL・管理者)。

### Q2. 開いたとき今日の位置が分かりにくいです。

**A.** ガント表示を開くと自動的に「今日」の列が左端に来るようスクロールします。当日は青背景でハイライトされています。

### Q3. 自分の担当タスクだけを横断で見たいです。

**A.** 「マイタスク」画面の「ガントチャートを表示」から、自分の担当タスクをプロジェクトごとにまとめて確認できます。

### Q4. 担当者別確認ボードに、思ったタスクが表示されません。

**A.** 担当者別確認ボードは「今日の前後 3 日間」に関係するタスクのみを表示します。終わったタスクは完了日が 3 日より前だと表示されなくなり、これから着手するタスクは開始予定日が 3 日より先だと表示されません (進行中・保留のタスクは期間に関わらず常に表示されます)。それ以外のタスクは WBS / タスク画面、またはガント表示で確認してください。また、担当者フィルタで絞り込んでいる場合は、選択していない担当者のカードは表示されません。

### Q5. 「進捗確認」という名前になったのはなぜですか?

**A.** v1.3.0 で、ガント表示に加えて担当者別確認ボードを追加したことに合わせて、タブ名を「ガントチャート」から「進捗確認」に変更しました。ガント表示の機能自体は変わりません。
