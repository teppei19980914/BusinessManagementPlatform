# 見積もり ご利用ガイド

見積もりは、プロジェクトの作業項目ごとに **工数と根拠** を記録・参照する機能です。過去のナレッジや実績を参照しながら見積もりを作成できます。本ガイドでは、一覧の見方・入力項目・確定の流れ・権限を、ご説明します。

> 見積もり機能は **PM/TL・テナント管理者のみ** が利用できます。メンバー・閲覧者には見積もりタブが表示されず、直接 URL を開いても閲覧できません。

## 1. 見積もりとは

プロジェクトの作業 (要件定義・設計・開発・試験 など) を項目に分け、それぞれの **見積工数** と **見積根拠** を記録します。過去の類似ナレッジや実績を紐付けることで、根拠のある見積もりを作成できます。

## 4. 作成から確定までの流れ

1. **作成** — プロジェクトが「見積中」状態のときに見積項目を作成します (企画中・計画中は限定的)。
2. **根拠記入** — 見積工数と根拠を記入し、参考にしたナレッジ・過去実績を紐付けます。
3. **確定** — 見積もりが固まったら確定します。確定後、プロジェクトを「計画中」へ進められます。

> 見積もりの作成・編集・確定はプロジェクトの状態に依存します。実行中以降は原則編集できません。

## 6. FAQ

### Q1. メンバーですが見積もりタブが見当たりません。

**A.** 見積もり機能は PM/TL・テナント管理者のみが利用できます。メンバー・閲覧者にはタブが表示されません (仕様)。

### Q2. 見積もりを編集できなくなりました。

**A.** 見積もりはプロジェクトが「見積中」のときに編集・確定できます。「計画中」では限定的、「実行中」以降は原則編集できません。

### Q3. 過去の見積もりを参考にできますか?

**A.** 関連ナレッジ・関連過去実績を紐付けられます。また、提案エンジン ([参考タブ](./suggestion-guide.md)) が過去の類似資産を自動提示します。
