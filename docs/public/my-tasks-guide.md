# マイタスク ご利用ガイド

マイタスクは、**自分が担当しているタスク** をプロジェクト横断でまとめて確認し、進捗・実績を更新するための個人向け画面です。本ガイドでは、一覧の見方・更新項目・権限をご説明します。

## 1. マイタスクとは

複数のプロジェクトに参加していると、自分の担当タスクがあちこちに散らばります。マイタスクは、それらを **1 画面に集約** して、進捗・実績を効率よく更新できる画面です。

---

## 2. どこから開くか

画面右上のアカウントメニュー →「マイタスク」から開きます。横断のガントチャート表示にも切り替えられます ([ガントチャート ご利用ガイド](./gantt-guide.md))。

---

## 3. 一覧の列

| 列 | 内容 |
|---|---|
| プロジェクト名 | 所属案件 |
| タスク名 | タスク名称 |
| ステータス | 未着手 / 進行中 / 完了 / 保留 |
| 進捗率 | 0〜100% |
| 開始予定日 / 終了予定日 | 計画日 |
| 予定工数 | 予定 |
| 実績工数 | 現在の実績 |
| 遅延フラグ | 遅延しているかどうか |
| 最新コメント | 最新の作業メモ |
| 最終更新日時 | 更新日時 |

---

## 4. 更新できる項目

自分の担当タスクについて、以下を更新できます。

| 項目 | 必須 | 備考 |
|---|---|---|
| 進捗率 | ○ | 0〜100 |
| ステータス | ○ | 未着手 / 進行中 / 完了 / 保留 |
| 実績工数 | ○ | 数値 |
| 残工数 | × | 数値 |
| 作業メモ | × | 2000 文字以内 |
| 課題有無 | × | チェック |
| 次アクション | × | 1000 文字以内 |
| 完了日 | △ | 完了時に入力 (「今日」ボタンあり) |

> **進捗率を 100% にするとステータスが自動的に「完了」**になります。計画情報 (担当・予定日・予定工数) の変更は PM/TL が行います。

---

## 5. 権限

| 操作 | 管理者 | PM/TL | メンバー | 閲覧者 |
|---|:--:|:--:|:--:|:--:|
| 自分の担当タスク一覧を見る | ○ | ○ | ○ | × |
| 自分の進捗・実績を更新 | ○ | ○ | ○ | × |
| リスクを起票 | ○ | ○ | ○ | × |
| 他人のタスクの実績を更新 | ○ | ○ | × | × |

> 自分の担当タスクの実績更新は、ロールを問わず担当者本人ができます。閲覧者は対象外です。

---

## 6. FAQ

### Q1. マイタスクで担当者や予定日を変えられますか?

**A.** いいえ。マイタスクで更新できるのは自分の担当タスクの **実績情報** (進捗率・ステータス・実績工数・作業メモ等) です。担当者・予定日・予定工数などの計画情報は PM/TL が WBS / タスク画面で変更します。

### Q2. 進捗を 100% にしたら「完了」になりました。

**A.** 仕様です。「進捗 100% = 完了」で整合するようになっています。

### Q3. 他のプロジェクトの自分のタスクも見られますか?

**A.** はい。マイタスクは参加している全プロジェクトの自分の担当タスクを横断して表示します。
