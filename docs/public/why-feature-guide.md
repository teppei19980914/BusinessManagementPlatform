# 「なぜ?」機能 ご利用ガイド (Pro プラン限定)

提案エンジンが「過去の類似プロジェクト」を提示したとき、**なぜそれが類似と判断されたか** を AI が自然言語で説明する機能です。本ガイドでは「どこで使えるか」「いくらかかるか」「効果的な使い方」を、Pro プランをご利用の方・検討中の方向けにご説明します。

> 「なぜ?」機能は **Pro プラン限定** です。Beginner / Expert プランではボタンが表示されず、ご利用いただけません。プランの違いは[料金プラン ご利用ガイド](./plan-guide)をご参照ください。

## 1. 3 行サマリ

| 項目 | 内容 |
|---|---|
| **対象プラン** | **Pro プラン限定** (Beginner / Expert は不可) |
| **料金** | **¥15 / 回** (税抜、初回クリック時のみ) |
| **特徴** | Claude Sonnet が「なぜ関連するか」を 150〜200 字で説明、2 回目以降はキャッシュから無料表示 |

---

## 2. どんな機能か

提案エンジンは、いま編集中のプロジェクトに関連する **過去の類似プロジェクト / ナレッジ / 課題 / リスク / 振り返り / メモ** を一覧で提示します (提案一覧の表示は全プラン無料)。

「なぜ?」機能を使うと、その**個別の提案候補**について「**なぜいま編集中のプロジェクトと関連していると判断したのか**」を AI (Claude Sonnet) が日本語で説明します。

例 (提案として「Webサイトリニューアル案件」が表示された場合):

> 通常表示: 「このプロジェクトは過去の "Webサイトリニューアル案件" と類似しています (類似度 82%)」
>
> ↓ 「なぜ?」ボタンを押すと
>
> 「**スコープ (ステークホルダー部署 × EC ドメイン × 3 ヶ月期間) が一致** しており、特に "決済 API 統合フェーズ" でリスクパターンが共通します。過去案件では認証連携で 2 週間の遅延が発生しており、本案件でも同種の遅延リスクが想定されます。」

これにより、提案候補を採用 (紐付け) するかどうかの判断材料が一気に増えます。役員会・経営層への報告書、外部顧客向けの提案資料での **根拠説明** に有用です。

## 3. どこで使えるか

プロジェクト詳細画面の **「提案」タブ** に表示される各候補の右上に「なぜ?」リンクが現れます (Pro プランのみ)。

対応している提案カテゴリは以下の 5 種類です:

| 提案カテゴリ | 「なぜ?」対応 | 説明文の観点 |
|---|---|---|
| **ナレッジ** (過去案件で蓄積された知見) | ✅ | このナレッジが本プロジェクトでどう活きるか |
| **過去課題** (過去案件で発生したトラブル) | ✅ | 同種の課題が再発するリスクの観点 |
| **過去リスク** (過去案件で識別されたリスク) | ✅ | 共通するリスクパターンと再発防止策 |
| **振り返り** (過去案件の Keep / Problem / Try) | ✅ | 過去の改善経験が本案件で活きる観点 |
| **公開メモ** (テナント内で全員公開のメモ) | ✅ | 関連するメモの内容との接点 |

> Pro プランでないユーザには「なぜ?」リンク自体が表示されません (Beginner / Expert で間違って使えてしまう UI 露出はなし)。

## 4. 使い方

### Step 1. プロジェクト詳細画面の「提案」タブを開く

`/projects/<プロジェクト ID>` にアクセスし、画面上部の **「提案」タブ** を選択します。

### Step 2. 関心のある提案候補の「なぜ?」リンクをクリック

提案候補ごとに右側に「**なぜ?**」リンクが表示されています。クリックするとダイアログが開き、生成中の表示 (「AI が関連理由を生成中です...」) が出ます。

### Step 3. 説明文を確認

数秒で AI が日本語で 150〜200 字程度の説明文を返します。生成元のモデル名 (`claude-sonnet-4-6` 等) と、キャッシュからの取得かどうかが下部に表示されます。

> 初回クリック時は数秒の生成時間がかかります (LLM 呼び出し)。2 回目以降は同じ (プロジェクト × 候補) であれば **キャッシュから即座に表示** されます。

### Step 4. ダイアログを閉じる

「閉じる」ボタンで終了。説明文はテナント内で永続キャッシュされ、別の Pro プランユーザが同じ候補に対して「なぜ?」を押した場合も同じ説明文が表示されます (= 再課金されません)。

## 5. 料金

### 5.1 基本単価

| 操作 | 単価 (税抜) |
|---|---|
| **「なぜ?」初回クリック** (= AI が説明文を新規生成) | **¥15** |
| **「なぜ?」2 回目以降** (= 同じ候補のキャッシュ表示) | **¥0 (無料)** |

### 5.2 課金単位

1 クリック (= 1 つの提案候補について 1 回の説明文生成) で 1 回課金されます。

### 5.3 課金 0 円になるケース

以下のいずれかに該当する場合は **課金されません**:

- **キャッシュヒット**: 同じプロジェクト × 同じ候補について過去に説明文が生成されている (= テナント内で誰かが既に押している)
- **API 呼び出しが失敗した場合** (= 説明文が表示されなかった場合、課金対象外)
- **縮退モード中** (= 課金されないが、機能自体も利用不可)

### 5.4 課金タイミング

クリックして説明文の生成が**成功した瞬間**に課金が記録されます。当月末締めの請求書に含まれます (Stripe 自動引落 / 銀行振込)。

## 6. 効果的な使い方 (推奨シーン)

「なぜ?」機能は **¥15/回** のため、すべての候補に対して押すのではなく、**重要な意思決定や外部資料作成のタイミング** で限定的に使うことを推奨します。

### 推奨シーン

| シーン | 効果 |
|---|---|
| **役員会・経営層への報告書作成** | 「過去の類似案件」を紹介する際の根拠を AI が言語化 |
| **外部顧客向け提案資料の作成** | 提案根拠を客観的に説明、説得力が上がる |
| **過去の類似案件との比較分析** | 「どこが同じで、どこが違うのか」を整理しやすい |
| **リスク評価の妥当性確認** | リスク再発防止策の根拠として記載できる |
| **新メンバーへの引継ぎ** | 「なぜこのナレッジを参照すべきか」を新メンバーに自動で説明 |

### 非推奨シーン (= 通常はクリック不要)

| シーン | 理由 |
|---|---|
| 提案一覧を流し見しているだけ | 通常の類似度バッジ + スニペット表示で十分なケースが多い |
| 採用 (紐付け) する候補をすでに決めている | 採用 (紐付け) 操作は別途無料、判断に説明文は不要 |
| 同一テナントで何度も同じ候補を確認 | 2 回目以降はキャッシュで無料表示されるため、敢えてクリックする意義は薄い |

## 7. 縮退モード時の挙動

「なぜ?」機能は **縮退モード中は利用できません**。

縮退モードは以下の条件で発生します:

| プラン | 縮退モード移行条件 |
|---|---|
| **Pro** | テナント管理者が設定した **月次予算上限到達時** (予算未設定なら縮退モードなし) |

縮退モード中の挙動:

- 「なぜ?」リンクは表示されますが、クリックすると「現在ご利用いただけません」とエラー表示されます
- 課金は発生しません (= LLM 呼び出しが行われないため)
- 提案一覧の通常表示 (= 類似度バッジ + スニペット) は引き続き無料で利用可能

縮退モードの全体仕様は[料金プラン ご利用ガイド §6](./plan-guide#6-予算上限と縮退モード)をご参照ください。

## 8. 使用量の確認方法

### 8.1 テナント管理者の方

テナント設定画面 (`/settings/tenant`) で、当月の **「なぜ?」機能の利用回数と費用** を確認できます。

- 「なぜ?」機能 **回数 + 費用 (¥15 × 回数)**
- 月次予算上限と現在の消化率 (プロジェクト作成・更新の費用と合算)

### 8.2 一般ユーザの方

一般ユーザは個別の利用状況画面はありませんが、「なぜ?」ダイアログ内に **「キャッシュから取得」** と表示されているかどうかで、課金が発生したかどうかを判断できます。

| ダイアログの表示 | 課金状況 |
|---|---|
| 「キャッシュから取得」あり | **¥0** (再課金なし) |
| 「キャッシュから取得」なし | **¥15** (今回新規生成、課金あり) |

## 9. FAQ

### Q1. Beginner / Expert プランで「なぜ?」機能を使えますか?

**A.** いいえ、**Pro プラン限定** の機能です。Beginner / Expert プランでは「なぜ?」リンク自体が画面に表示されません。

「なぜ?」機能を使いたい場合は **Pro プランへのアップグレード** をご検討ください。アップグレードは **即時反映** されます ([料金プラン ご利用ガイド §5.1](./plan-guide#51-アップグレード--即時反映) 参照)。

### Q2. 同じ候補に対して何度も「なぜ?」を押した場合、毎回課金されますか?

**A.** **いいえ**。初回クリック時のみ課金 (¥15) され、2 回目以降は **キャッシュから無料表示** されます。

キャッシュは「プロジェクト × 提案候補」の組合せ単位で永続化されるため、別のユーザが同じ組合せで「なぜ?」を押した場合も再課金されません。

### Q3. 別のプロジェクトで同じ過去ナレッジを参照した場合、キャッシュは効きますか?

**A.** **いいえ**。キャッシュキーは「**プロジェクト × 候補**」の組合せです。

たとえば「ナレッジ A」が「プロジェクト X」と「プロジェクト Y」の両方で提案として表示された場合、X で説明文を生成すれば X 側のキャッシュには残りますが、**Y 側では別途課金が発生** します。これは、説明文が「このプロジェクトに対してなぜ関連するか」という観点で個別に最適化されるためです。

### Q4. 説明文が「いまいち的外れ」だった場合、再生成できますか?

**A.** 現バージョンでは **再生成機能はありません**。説明文は AI が生成したものをそのままキャッシュに保存します。

将来的に「再生成」ボタンを追加する可能性はありますが、現在は **初回生成の説明文を見て採用判断にお使いください** という設計です (= 再生成のたびに ¥15 課金される事故を防ぐため)。

### Q5. 説明文の品質はどの程度ですか?

**A.** **Anthropic 社の Claude Sonnet 4.6** (= 高品質モデル) を使用しており、150〜200 字程度の自然な日本語で「具体的な共通点」を提示します。

ただし、AI 生成のため以下の点にご注意ください:

- 入力 (プロジェクト目的 / 背景 / スコープ + 候補の内容) に書かれていない情報は答えません (hallucination 防止)
- 抽象的な表現 (「役立つ可能性があります」等) を避け、具体的な共通点 (業務ドメイン / 技術スタック / 工程) を 1〜2 個明示するように指示しています
- 説明文は **判断補助** であり、最終判断は人間が行うことを推奨します

### Q6. プロジェクトの内容を更新した後、説明文も自動で更新されますか?

**A.** **いいえ、自動更新はされません**。

説明文はキャッシュに保存され、プロジェクトの目的 / 背景 / スコープが変わってもキャッシュが優先表示されます。説明文を更新したい場合は、現在は **テナント管理者が手動でキャッシュ削除** をご相談ください (= 将来の機能拡張で UI 経由削除を提供予定)。

### Q7. AI 説明文の英語版はありますか?

**A.** **現バージョンでは日本語のみ** です。テナントの locale 設定が `en-US` でも、説明文は日本語で生成されます。

英語対応は将来のロードマップに含まれていますが、現時点で予定は確定していません。

### Q8. 「なぜ?」機能を使った履歴は監査ログに残りますか?

**A.** **はい**、利用履歴 (課金監査ログ) に記録されます。

テナント管理者は当月の「なぜ?」機能の利用履歴を、テナント設定画面から CSV でエクスポートできます。

### Q9. プロジェクトを削除すると、説明文キャッシュも消えますか?

**A.** **はい**。プロジェクト削除 (論理削除) と同時に、そのプロジェクト配下の説明文キャッシュは参照されなくなります。

ただし、テナント全体の使用量 (= 過去課金分) には影響しません (= 過去に発生した ¥15 課金が遡って減ることはありません)。

### Q10. 縮退モードと「なぜ?」機能停止の違いは?

**A.** **縮退モード** はテナント全体の AI 機能停止 (予算上限到達時)、**「なぜ?」機能停止** は Pro プランでない場合の非開放です。

| 状態 | 「なぜ?」リンク表示 | クリック時の挙動 |
|---|---|---|
| **Pro プラン + 通常運用** | ✅ 表示 | 説明文生成 (¥15 課金 or キャッシュ無料) |
| **Pro プラン + 縮退モード中** | ✅ 表示 | エラー「現在ご利用いただけません」(課金なし) |
| **Beginner / Expert プラン** | ❌ 非表示 | (クリック不可) |
