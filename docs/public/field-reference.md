# 入力項目・一覧リファレンス（プロジェクト詳細・各タブ）

たすきば Knowledge Relay の **プロジェクト詳細画面の各タブ** について、(1) 編集画面で入力する項目、(2) 一覧画面に表示される列、(3) 一覧で使える操作（並べ替え・列幅調整・絞り込み・エクスポート/インポート・一括編集）を、画面に表示されるラベル名ごとに整理したリファレンスです。

> 表記: **必須** = 入力しないと保存できない項目 / **任意** = 空のままでも保存できる項目。
> 画面の使い方の全体像は [画面一覧リファレンス](./screen-reference) と各機能ガイドを参照してください。

---

## 共通: 「公開範囲」の動き（下書き / 公開）

リスク・課題・振り返り・ナレッジには **公開範囲** の設定があり、誰に表示されるかが変わります。

| 設定値 | 表示される範囲 | 主な使いどころ |
|---|---|---|
| **下書き** | **作成した本人と管理者だけ**が閲覧できます。他のメンバー（そのプロジェクトのメンバーを含む）には表示されません。 | 作成途中の保存、社内レビュー前の下書き |
| **公開** | **プロジェクトの全メンバー**が閲覧できます。 | 共有して活用してほしい確定情報 |

> 補足 (2026-06-19 v1.3.0「軽量入力」): 件名・タイトルは **常に必須** です。「公開」にするときは、提案で役立つよう本文の主要項目（各タブの表で「公開時必須」と記載）も必須になります。実施日・担当者・影響度などは公開時でも任意です。下書きのままなら、まず件名・タイトルだけで気軽に保存し、本文は後から追記できます。

## 共通: 一覧画面の操作（並べ替え・列幅・絞り込み・エクスポート/インポート・一括編集）

一覧を持つタブには、次のような共通の操作があります。**使える操作はタブによって異なります**（下の対応表を参照）。

| 操作 | できること |
|---|---|
| **並べ替え** | 並べ替えに対応した列の見出しをクリックすると、その列で昇順／降順に並びます。複数の列を組み合わせた並べ替えもでき、並べ替えの状態はそのブラウザに記憶されます。 |
| **列幅の調整** | 列の境界をドラッグして各列の幅を変えられます。**「列幅をリセット」**で初期幅に戻せます。 |
| **絞り込み（フィルター）** | キーワードやステータスなどで表示を絞り込めます。キーワードは空白区切りで複数語の OR 検索、先頭に `-`（例 `-完了`）でその語を含む行を除外できます。「自分が作成（起票）したもののみ」で自分の分だけに絞れます。 |
| **エクスポート / インポート** | 一覧の内容を CSV で書き出し（エクスポート）、CSV で一括取り込み・上書き編集（インポート）できます。チェックを付けた行だけを書き出すこともできます（未選択時は全件）。 |
| **一括編集** | 行のチェックボックスで複数選択し、公開範囲などをまとめて変更できます。選択件数が上部に表示されます。 |
| **添付・リンクの表示** | 「リンク」列は編集画面で登録した**外部リンク（URL）**を複数行で表示し、「添付」列は**アップロードしたファイル本体**を表示します（別々の列に分かれます）。 |

### タブ別: 使える操作の対応

| タブ | 並べ替え | 列幅調整／リセット | 絞り込み | エクスポート／インポート | 一括編集 |
|---|:--:|:--:|:--:|:--:|:--:|
| 概要 | ―（一覧ではなく単一表示） | ― | ― | ― | ― |
| 見積もり | ✕ | ✕ | ✕ | ✕ | ✕ |
| WBS 管理 | ✕（階層の順で表示） | ◯ | ◯（担当者・状況） | ◯ | ◯（担当者・期限・ステータス・実績）※工数集計・ID 表示切替も可 |
| リスク一覧 / 課題一覧 | ◯ | ◯ | ◯（ステータス・優先度・キーワード・自分が起票） | ◯ | ◯（公開範囲） |
| 振り返り一覧 | ◯ | ◯ | ◯（キーワード・自分が作成） | ◯ | ◯（公開範囲） |
| ナレッジ一覧 | ◯ | ◯ | ◯（キーワード・自分が作成） | ◯ | ◯（公開範囲） |
| 参考 | ―（提案の閲覧画面） | ― | ― | ― | ― |
| メンバー | ✕ | ✕ | ✕ | ✕ | ✕ |
| ステークホルダー | ◯ | ◯ | ◯（優先度） | ✕ | ✕ |

## 概要タブ（プロジェクトの基本情報）

プロジェクトの目的・背景・期間などを編集します。画面右上に **編集**・**削除** があります。プロジェクト一覧へ戻るときは、画面左上の「たすきば」ロゴ、またはヘッダーの「全プロジェクト」タブを使います。

**画面に表示される内容**: 基本情報（ステータス・プロジェクト名・顧客・開発方式・契約形態・開始予定日・終了予定日・実績開始日・実績終了日）→ 目的 → 背景 → スコープ → 関連 URL（メイン資料 / その他の関連 URL / ファイルのアップロード）。※「スコープ外」「備考」は編集画面でのみ入力でき、概要の表示には出ません。

> **ステータスの表示と変更**: プロジェクトのステータス（企画中・進行中・完了 など）は、画面上部のプロジェクト名の横のバッジと、概要タブの基本情報の先頭に表示されます。**変更は「編集」画面のステータス項目（プルダウン）から行います。新規作成画面でも選べます。** 任意のステータスを自由に選択でき、決まった順番に沿って進める必要はありません（以前の専用「ステータス変更」プルダウンは廃止しました）。

### 編集する項目

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| プロジェクト名 | プロジェクトの名称 | 必須 | 一覧や各画面の見出しに表示されます |
| 顧客 | 紐づく顧客を選択 | 必須 | あらかじめ登録した顧客から選びます |
| ステータス | 企画中 / 見積中 / 計画中 / 実行中 / クローズ から選択 | 必須 | 新規作成・編集の両方で選べます。任意のステータスを自由に選択でき、順番の制約はありません（新規作成時の既定は「企画中」）。**「クローズ」にすると読み取り専用**になり、以後は編集できなくなります（削除のみ可能） |
| 目的 | このプロジェクトで達成したいこと | 必須 | 「参考情報」→「提案」サブタブで似た過去案件を探す手がかりになります |
| 背景 | 現状・経緯・前提 | 必須 | 同上 |
| スコープ | 実施する範囲 | 必須 | 同上 |
| スコープ外 | 対象外とする範囲 | 任意 | 認識ずれの防止に使います |
| 備考 | その他の補足 | 任意 | |
| 開発方式 | スクラッチ開発・ローコード/ノーコード 等から選択 | 必須 | |
| 契約形態 | 準委任・請負・SES 等から選択 | 任意 | 未選択も可（「未設定」） |
| 開始予定日 | 着手予定日 | 必須 | 「今日」ボタンで当日を入力できます |
| 終了予定日 | 完了予定日 | 必須 | 同上 |
| 実績開始日 | 実際に着手した日 | 任意 | 着手前は空のままにします。「クリア」で空に戻せます |
| 実績終了日 | 実際に完了した日 | 任意 | 同上 |

## 見積もりタブ（見積もり項目）

作業項目ごとの工数見積もりを登録します。一覧の上部に **合計工数** が表示されます。

**一覧に表示される列**: 項目名 / 区分 / 工数（数値と単位をまとめて表示）/ 備考 / ステータス（確定・未確定）/ 作成者 / 作成日時 / 更新者 / 更新日時 / 操作（確定・削除）。
※この一覧は並べ替え・列幅調整・絞り込み・エクスポート/インポートには対応していません（シンプルな表です）。

### 編集する項目

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| 見積項目名 | 見積対象の作業名 | 必須 | |
| 区分 | 要件定義・設計・開発・テスト 等から選択 | 必須 | |
| 見積工数 | 工数の数値 | 必須 | 1 以上の数値 |
| 単位 | 人時 / 人日 から選択 | 必須 | |
| 備考 | 算出の根拠や補足メモ | 任意 | 一覧の「備考」列に表示されます |

> 確定した見積もりは編集できなくなります（履歴として参照）。

## WBS 管理タブ（作業構造・タスク）

WBS（作業分解）の構造ノードを作成・編集します。**種別** によって入力する項目が変わります。

**一覧に表示される列**: 名称（まとめ用「ワークパッケージ」／実作業「アクティビティ」の種別バッジ＋階層、開閉できます）/ 担当者 / ステータス / 進捗&工数（進捗率と工数をまとめて表示。まとめ用ノードは配下の集計）/ 予定期間 / 実績期間 / 添付 / 操作（編集・削除）。各行にチェックボックス（一括選択用）。
**この一覧で使える操作**: 列幅の調整／リセット、担当者・状況での絞り込み、エクスポート/インポート、**工数集計**（担当者別の日次工数）、**ID 表示の切り替え**、一括編集（担当者・期限・ステータス・実績）。（並べ替えは階層の順で固定です。）

### 種別 = ワークパッケージ（まとめ用のノード）

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| 種別 | 「ワークパッケージ」 | 必須 | |
| 親ワークパッケージ | 配置先の親（なし=最上位） | 任意 | |
| 名称 | ノード名 | 必須 | |
| 関連 URL | 参考リンク | 任意 | 作成後に自動保存されます |

> **工数・日程は入力しません。** 配下の子要素から自動で集計されます。
> 最上位に配置したワークパッケージの終了日は、マイルストーンとして自動設定されます。

### 種別 = アクティビティ（実作業）

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| 種別 | 「アクティビティ」 | 必須 | |
| 親ワークパッケージ | 配置先の親（なし=最上位） | 任意 | |
| 名称 | 作業名 | 必須 | |
| 担当者 | 実施担当 | 必須 | |
| 開始予定日 / 終了予定日 | 予定の期間 | 任意 | 「今日」「クリア」あり |
| 予定工数（人時） | 見積もり工数 | 任意 | 編集画面では「最大日工数」の目安が表示されます |
| 作業内容 | 手順・成果物・確認観点など | 任意 | |
| 関連 URL | 参考リンク | 任意 | |

### 編集時の「実績項目」

アクティビティの編集画面には、上記の予定項目に加えて実績を入力するセクションがあります。

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| ステータス | 未着手 / 着手中 / 完了 など | 必須 | 進捗のステータスを表します |
| 進捗率 | 0〜100% | 任意 | |
| 実績開始日 / 実績終了日 | 実際の期間 | 任意 | 「今日」「クリア」あり |
| 実績工数（人時） | 実際にかかった工数 | **完了時は必須** / それ以外は任意 | **ステータスを「完了」にするときは 0 より大きい値の入力が必須**です（単体・一括どちらの更新でも）。未着手では入力できません。稼働分析サブタブの「担当者別 週次 消化工数」「工数効率」に使われます。完了以外で未入力（0）のままにすると、そのタスクは消化工数グラフに乗らず、効率の計算対象からも外れます |

## 進捗確認タブ（タスクの時系列表示 + 担当者別の直近確認、旧称: ガントチャートタブ）

WBS 管理タブと同じタスクを表示する閲覧用の画面です（入力はしません）。画面上部のチップで「ガント表示」「担当者別確認」を個別に表示/非表示切替できます。

**ガント表示**: タスクを横棒（バー）で時系列に表示します。担当者・状況での絞り込みと、左側「タスク名」列の幅調整／リセットができます。バーの色（凡例）は **予定**（薄い青＝予定の期間）/ **実績（進捗）**（青＝進捗に応じた実績）/ **遅延**（赤）/ **マイルストーン**（紫の◇）。左側にはタスク名・種別バッジ・ステータス・進捗率・担当者を表示し、上部の日付軸では土日・祝日が色分けされます。

**担当者別確認ボード**: 担当者ごとに 1 枚のカードで、**終わった / やっている / これから / 保留** の 4 列にタスクを分類して表示します（今日を基準に前後 3 日間が対象。やっている/保留はウィンドウに関わらず常に表示）。予定終了日を過ぎても未完了のタスクには「遅延」バッジが付きます。担当者フィルタはガント表示と共有しますが、状況フィルタは適用されません。

## リスク一覧 / 課題一覧タブ

リスク（これから起こりうること）と課題（すでに起きていること）を管理します。両者は項目が共通で、ラベルだけが切り替わります。

**一覧に表示される列**: 件名 / ステータス / 優先度 / 担当者 / 結果 / 作成者 / 作成日時 / 更新者 / 更新日時 / リンク / 添付 / 操作（削除）。各行にチェックボックス（一括選択用）。
**この一覧で使える操作**: 並べ替え、列幅の調整／リセット、絞り込み（ステータス・優先度・キーワード・自分が起票したもののみ）、エクスポート/インポート、一括編集（公開範囲）。
※「公開範囲」「影響度／重要度」「発生可能性／緊急度」は一覧の列には出ず、編集画面で確認・変更します。

### 入力する項目

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| 公開範囲 | 下書き / 公開 | 必須 | 上記「公開範囲の動き」を参照 |
| 脅威 / 好機 | 脅威 / 好機（**リスクのみ**） | 必須 | 課題には表示されません |
| 件名 | 概要のタイトル | 常に必須 | 下書きでも必須 |
| 考えられる事象 / 発生事象 | 何が起こる（起きた）か | 公開時必須 | リスク=「考えられる事象」、課題=「発生事象」。下書きでは任意 |
| 考えられる原因 / 直接原因 | 原因 | 公開時必須 | 下書きでは任意 |
| 考えられる対応策 / 対応策 | 対応の方針 | 公開時必須 | 下書きでは任意 |
| メモ | 補足 | 公開時必須 | 下書きでは任意 |
| 結果 | 対応・収束後の結末 | 任意 | **対応が終わった後に記録する事後項目**のため、**新規作成画面には表示されず、編集画面でのみ入力できます**（一覧には「結果」列として表示、未入力は「-」） |
| 影響度 / 重要度 | 高 / 中 / 低 から選択 | 必須 | リスク=「影響度」、課題=「重要度」 |
| 発生可能性 / 緊急度 | 高 / 中 / 低 から選択 | 任意 | リスク=「発生可能性」、課題=「緊急度」 |
| ステータス | 未対応 / 対応中 / 完了 など | 必須 | |
| 担当者 | 対応担当 | 任意 | 新規作成時は自分が初期値 |
| 期限 | 対応期限 | 任意 | |

> **優先度は自動で決まります（手動で設定できません）。** リスクは「影響度 × 発生可能性」、課題は「重要度 × 緊急度」の組み合わせから算出されます（両方が高いほど優先度が高くなります）。

## 参考タブ（過去案件の活用）

このタブは入力画面ではなく、**このプロジェクトに似た過去のナレッジ・課題・リスク・振り返りを自動で抽出して提案**する閲覧用の画面です。概要タブの「目的・背景・スコープ」などの内容が、似た過去案件を探す手がかりになります。提案されたものを紐付けると、元のプロジェクトとデータを共有したまま、本プロジェクトの各一覧にも表示されます。

## ステークホルダータブ（利害関係者）

プロジェクトの利害関係者と、関わり方の戦略を整理します。一覧の上部に、影響度と関心度の組み合わせで分類した **4 つのカード**（密接に連携 / 満足させておく / 常に情報を伝える / モニタリング）が表示され、それぞれに該当する人数と相手の姿勢が並びます。

**一覧（表）に表示される列**: 氏名 / 所属 / 役職 / 優先度 / 姿勢 / AsIs → ToBe（現在 → 望ましい関与度）/ Gap（関与度の引き上げ幅）/ 作成者 / 作成日時 / 更新者 / 更新日時 / 操作（削除）。
**この一覧で使える操作**: 並べ替え（Gap などで並べ替え可）、列幅の調整／リセット、優先度での絞り込み。
※「影響度」「関心度」は一覧の列には出ず、編集画面で入力します（その値から優先度が自動で決まります）。

### 入力する項目

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| 内部メンバー紐付け | 社内ユーザと紐付け（外部関係者なら紐付けなし） | 任意 | |
| 氏名 | 表示用の氏名 | 必須 | |
| 所属組織 / 役職 | 所属と役職 | 任意 | |
| 連絡先メモ | 連絡先などのメモ | 任意 | |
| 影響度（1〜5） | 影響力の大きさ | 必須 | 下記の「優先度」の自動判定に使われます |
| 関心度（1〜5） | 関心の高さ | 必須 | 同上 |
| 姿勢 | 支持的 / 中立 / 反対 | 必須 | |
| 現在のエンゲージメント | 現状の関与度 | 必須 | |
| 望ましいエンゲージメント | 目指す関与度 | 必須 | 現在との差（ギャップ）が一覧の「Gap」に表示されます |
| 人となり / 考え方 | 接し方のコツなど | 任意 | |
| 対応戦略 | 具体的なアクション | 任意 | |

> **優先度は影響度・関心度から自動で決まります（手動設定不可）。** 影響度と関心度がともに高い相手は「高」、ともに低い相手は「低」、それ以外は「中」になります。一覧では優先度の高い順に並びます。

## 全リスク / 全課題 / 全振り返り / 全ナレッジ（横断参照）

画面上部メニューの「全リスク」「全課題」「全振り返り」「全ナレッジ」は、**全プロジェクトを横断して、公開された情報をまとめて閲覧する参照専用の画面**です（ログインしていれば誰でも開けます）。行をクリックすると詳細が**読み取り専用**で開きます（編集は各プロジェクトの「○○一覧」から行います）。新規作成・編集・チェックでの一括編集はできません。

- 各画面の列は、**先頭に「プロジェクト」列**が付き、続いて対応する各「○○一覧」と同じ列・同じ順番で並びます（2026-06-03 に統一）。
  - 全リスク / 全課題: プロジェクト・件名・ステータス・優先度・担当者・結果・作成者・作成日時・更新者・更新日時・リンク・添付。
  - 全振り返り: プロジェクト・実施日・ステータス・担当者・作成者・作成日時・更新者・更新日時・リンク・添付。
  - 全ナレッジ: プロジェクト・タイトル・種別・担当者・作成者・作成日時・更新者・更新日時・リンク・添付。
- 並べ替え・列幅の調整／リセット・キーワード絞り込みが使えます（全リスク/全課題はステータス・優先度でも絞り込めます）。
- **削除**: 各行の削除はテナント管理者のみに表示されます（横断的な管理削除用）。

## 全顧客管理（顧客）※テナント管理者向け

プロジェクトに紐づける顧客（企業・組織）を登録・管理する画面です。画面上部メニューの「全顧客管理」から開きます。**この画面はテナント管理者のみが利用できます**（一般メンバー・PM/TL には表示されません）。

**一覧に表示される列**: 顧客名 / 部門 / 担当者 / 担当者メール / 関連プロジェクト（紐づくプロジェクトの件数）/ 作成者 / 作成日時 / 更新者 / 更新日時 / 操作（削除）。
**この一覧で使える操作**: キーワードでの絞り込み、列見出しでの並べ替え。
**削除の条件**: 進行中のプロジェクトが紐づいている顧客は、一覧から直接は削除できません（紐づくプロジェクトが無い顧客のみ削除可。紐づきがある場合は顧客詳細からまとめて削除します）。

### 入力する項目（新規登録・編集とも共通）

| 項目 | 入力する内容 | 必須/任意 | 設定値による動き・補足 |
|---|---|:--:|---|
| 顧客名 | 顧客企業・組織の名称 | 必須 | プロジェクト作成時の「顧客」選択肢に並びます |
| 部門 | 部門・組織名 | 任意 | |
| 担当者 | 窓口担当者の氏名 | 任意 | |
| 担当者メール | 窓口のメールアドレス | 任意 | 入力する場合はメール形式（`@` を含む）である必要があります |
| 備考 | その他のメモ・特記事項 | 任意 | |

> 編集画面には上記に加えて **コメント**（@ メンションで通知）欄があります。新規登録画面にはコメント欄はありません。

### 顧客詳細画面

顧客名をクリックすると顧客詳細を開きます（こちらもテナント管理者のみ）。表示内容は次のとおりです。

- **顧客情報**: 部門 / 担当者 / 担当者メール / 備考 / **紐付 active プロジェクト（進行中で紐づくプロジェクトの件数）**。右上に「編集」「削除」。
- **紐付プロジェクト 一覧**: プロジェクト名 / ステータス / 開始予定日 / 終了予定日。プロジェクト名から各プロジェクトへ移動できます。
- **編集**: その場で編集ダイアログが開きます（項目は新規登録・編集と同じ）。
- **削除**:
  - 紐づく進行中プロジェクトが無い場合は、そのまま顧客を削除します。
  - 紐づく進行中プロジェクトがある場合は、**カスケード削除ダイアログ**が開きます。顧客と紐づく進行中プロジェクトをまとめて削除でき、そのとき**プロジェクトの「リスク／課題／振り返り／ナレッジ」を一緒に削除するか**を 4 つのチェックで選べます（既定はオフ＝これらの資産は残します）。
