# エクスポートCSV リファレンス（ZIP の `csv/` フォルダ）

テナント設定の「📦 全データを ZIP でダウンロード」で取得した ZIP には、`csv/` フォルダに**人間が Excel 等で見るための CSV**が入っています（5 ファイル）。本書は、各 CSV の**列が画面のどの項目に当たるか**と、**プルダウン項目はどの値が何を意味するか**をまとめたものです。

> - CSV の**見出しも選択値（プルダウン）も画面に合わせた日本語**です（2026-06-04〜）。文字コードは UTF-8（Excel 対応の BOM 付き）。
> - **データの復元（取り込み）は ZIP 内の `data/` の JSON を使います。** CSV は閲覧用なので、CSV を編集しても復元内容は変わりません。
>   - 他ツールからの**手入力での移行**は、テナント設定の「外部データ移行」ウィザード（`/settings/tenant/migration-import`）をご利用ください。自分の CSV の列を画面項目に割り当てて取り込めます。
> - 末尾に「**システム管理列**」（ID・作成者ID・作成日時 など）が並びます。これらは自動で決まる値で、ユーザが意味を意識する必要はありません。

## プルダウン項目の値の意味

CSV には**画面と同じ日本語の値**が入ります（例：公開範囲＝「下書き」「公開」）。各プルダウン項目の取りうる値と意味は次のとおりです。表の「内部コード」は参考（システム内部の値。「外部データ移行」ウィザードでは日本語・内部コードのどちらを入れても取り込めます）。

### 公開範囲（ナレッジ・リスク・課題・振り返り）
| 値 | 画面表示 | 意味 |
|---|---|---|
| `draft` | 下書き | 作成者と管理者のみ閲覧 |
| `public` | 公開 | プロジェクトの全メンバーが閲覧 |

### メモの公開範囲
| 値 | 画面表示 | 意味 |
|---|---|---|
| `private` | 自分のみ | 作成者だけが閲覧 |
| `public` | 公開 | 公開メモとして閲覧可 |

### プロジェクト ステータス
| 値 | 画面表示 |
|---|---|
| `planning` | 企画中 |
| `estimating` | 見積中 |
| `scheduling` | 計画中 |
| `executing` | 実行中 |
| `closed` | クローズ（読み取り専用になる） |

### 開発方式（プロジェクト）
| 値 | 画面表示 |
|---|---|
| `scratch` | スクラッチ開発 |
| `low_code_no_code` | ローコード/ノーコード開発 |
| `package` | パッケージ開発 |
| `other` | そのほか |

### 契約形態（プロジェクト）
| 値 | 画面表示 |
|---|---|
| `quasi_mandate` | 準委任 |
| `lump_sum` | 請負 |
| `ses` | SES |
| `other` | そのほか |
| （空） | 未設定 |

### ナレッジ 種別
| 値 | 画面表示 |
|---|---|
| `research` | 調査 |
| `verification` | 検証 |
| `incident` | 障害対応 |
| `decision` | 意思決定 |
| `lesson` | 教訓 |
| `best_practice` | ベストプラクティス |
| `other` | その他 |

### リスク・課題 種別
| 値 | 画面表示 |
|---|---|
| `risk` | リスク（これから起こりうること） |
| `issue` | 課題（すでに起きていること） |

### リスク・課題 状態
| 値 | 画面表示 |
|---|---|
| `open` | 未対応 |
| `in_progress` | 対応中 |
| `monitoring` | 監視中 |
| `resolved` | 解消 |

### 優先度（リスク・課題／自動算出）
| 値 | 画面表示 |
|---|---|
| `high` | 高 |
| `medium` | 中 |
| `low` | 低 |
| `minimal` | 最低 |

> 優先度は「影響度（重要度）× 発生可能性（緊急度）」から自動で決まります（手入力できません）。
