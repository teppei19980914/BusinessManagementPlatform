## 1. たすきばが扱う「資産」とは

たすきばは、プロジェクト運営で生まれる知見を **構造化された「資産」** として蓄積します。主な資産は次の通りです。

| 資産 | 何を記録するか |
|---|---|
| **プロジェクト** | 案件そのもの。目的・背景・スコープ・期間・担当などを持つ「親」 |
| **タスク (WBS)** | プロジェクトを分解した作業項目。階層構造・担当・予定/実績で管理 |
| **見積もり** | 工数や根拠の見積記録 |
| **ナレッジ** | 過去案件で得た教訓・パターン・調査結果 |
| **リスク・課題** | 想定リスクや発生した課題と、その対応・結果 |
| **振り返り** | 完了後の総括 (良かった点 / 問題 / 改善) |
| **メモ** | プロジェクトに紐付かない個人の覚え書き |
| **顧客 / ステークホルダー** | 発注元の顧客マスタ、案件の関係者情報 |

これらの資産は、後から **検索・参照・再利用** できる形で残ります。特にナレッジ・リスク・課題・振り返り・メモは、後述の **提案エンジン** と **意味検索** の対象になります。

## 2. データの保存先 — データベースとファイルストレージの違い

たすきばのデータは、**2 種類の保存先** に分かれて格納され、それぞれ別の従量課金が適用されます。

| | **データベース (DB)** | **ファイルストレージ** |
|---|---|---|
| 何を保存するか | テキスト系データ (プロジェクトの目的・背景・スコープ、ナレッジ本文、コメント、タグ、**URL・リンクのテキスト** 等) | 添付した **ファイル本体** (PDF / Excel / Word / 画像 等) |
| しくみ | PostgreSQL (リレーショナルデータベース) | オブジェクトストレージ |
| 無料枠 | **50MB** まで | **100MB** まで |
| 超過単価 | **1GB ごと ¥50** | **1GB ごと ¥10** |
| 累積上限 | なし (青天井従量) | なし (青天井従量) |
| 1 件あたりの上限 | 1 回の登録で 5MB まで | 1 ファイル 50MB まで |

### どちらに入るか迷ったら

- **文字 (テキスト)** はすべて DB → 例: ナレッジ本文、メモ、コメント、URL リンクの文字列
- **ファイルそのもの** だけがファイルストレージ → 例: 添付した PDF、Excel、画像

> 「ファイルへのリンク (URL)」は **テキスト** なので DB に入ります。ファイル本体をアップロードした場合のみファイルストレージにカウントされます。

ファイルストレージの方が単価が安いのは、保管コストがデータベースより低いためです。

詳細: [データ容量 ご利用ガイド](./db-capacity-billing-guide.md) / [ファイルストレージ ご利用ガイド](./file-storage-billing-guide.md)

## 3. 公開範囲 (visibility) のしくみ

ナレッジ・リスク・課題・振り返りには **2 種類の公開範囲** があります。

| 公開範囲 | 表示ラベル | 誰が見られるか | 提案エンジン / 意味検索 |
|---|---|---|---|
| **下書き** | 自分のみ | 作成者本人 (+ テナント管理者) のみ | 対象外 (AI 索引化されない = 課金もされない) |
| **公開** | テナント全員 | 同じ組織の全ログインユーザ | 対象 (索引化され、提案・検索に出る) |

メモだけは少し異なり、**「自分のみ (private)」/「全員に公開 (public)」** の 2 種類です。

### ポイント

- **「自分のみ / 下書き」のデータは AI 索引化されず、AI 課金も発生しません**。まだ共有したくない作業中のメモに向いています。
- **「公開」にした瞬間に索引化** され、提案エンジン・意味検索の対象になります (Expert / Pro はこのタイミングで Embedding 課金、Beginner は月 100 件の無料枠内)。
- 公開範囲は後からいつでも変更できます。

## 4. 意味検索と全文検索の違い

たすきばの検索は、一般的な **全文検索** ではなく **意味検索 (semantic search)** を中心に据えています。

| | 全文検索 (キーワード一致) | 意味検索 (たすきば) |
|---|---|---|
| しくみ | 入力した文字を含むデータを全部返す | 「意味の近さ」で並べ替えて返す |
| 例: 「工数膨張」で検索 | 「工数膨張」という文字を含むものだけ | 文字が違っても「スケジュール遅延の原因」「多重下請けの負荷」など意味的に近いものを上位に |
| 弱点 | 100 件以上ヒットして絞れない / 言い換えに弱い | — |

意味検索は、文章を **意味を表す数値の並び (ベクトル)** に変換して比較するしくみです。そのため「請求書」と「インボイス」のような **言い換え** でも、近い意味として拾えます。

> 縮退モードなどで意味検索が一時的に使えないときは、**文字の部分一致** による検索に自動で切り替わり、検索自体は止まりません。

詳細: [チャットボット意味検索 使い方ガイド](./chat-semantic-search-guide.md)

## 5. 2 つの AI 入り口 — 自動提案と意味検索

たすきばには、過去資産にたどり着く **2 つの経路** があります。

| 経路 | きっかけ | 体験 |
|---|---|---|
| **自動提案 (提案エンジン)** | システムが自動で | プロジェクトを作った瞬間や「参考」タブで、関連しそうな過去資産が自動で並ぶ (= 探さなくても届く) |
| **意味検索 (たすきフクロウ)** | あなたが自発的に | 画面右下の「たすきフクロウ」アイコンから自然文で質問する (= 探したいときに探せる) |

両者は同じ意味検索の土台を共有し、**「届く」と「探す」の両方** を提供します。

## 6. AI 機能の 3 つの種類

たすきばの AI 機能は、しくみと料金の観点で 3 種類に分かれます。

| 種類 | 何をするか | 代表機能 | 料金 |
|---|---|---|---|
| **LLM (文章の理解・生成)** | AI が文章を読んでタグを付けたり、説明文を生成する | プロジェクト作成時の自動タグ付け / 「なぜ?」機能 | Expert ¥10・Pro ¥15 / 回。「なぜ?」は Pro のみ ¥15。Beginner は月 50 回無料 |
| **Embedding (意味検索の索引化)** | 文章を意味ベクトルに変換して検索・提案できるようにする | 資産入力・チャット意味検索・CSV インポート・添付ファイル索引化 | Expert / Pro ¥5 / 業務操作。Beginner は月 100 件無料 |
| **ヘルプチャット (学習支援)** | たすきば自体の使い方を FAQ から回答する | たすきフクロウ AI ヘルプチャット | **全プラン無料** (テナント月 100 回まで) |

> **「ヘルプチャット」は「Embedding」とは別枠** です。Beginner プランの Embedding 月 100 件 (資産入力・意味検索など) を消費せず、全プラン無料でご利用いただけます。「月 100 件 (Embedding)」と「月 100 回 (ヘルプチャット)」は別々のカウンタなので混同にご注意ください。

詳細: [API 利用 ご利用ガイド](./api-usage-guide.md)

## 7. 縮退モードとは

**縮退モード** は、AI 機能の利用上限に達したときに切り替わる状態です。「サービスが止まる」のではなく、**AI のお手伝いだけが一時的にお休み** する状態を指します。

- 縮退モード中も、データの閲覧・作成・更新・削除・エクスポートは通常どおり行えます。
- 一時的にお休みするのは「AI による自動タグ付け」「新しい意味検索の索引化」「(Pro の)「なぜ?」説明文生成」です。
- 既に作られた索引を使った検索・提案は引き続き動きます。
- 月初 (毎月 1 日) に自動的に元に戻ります。上限を引き上げる / プランを上げると即時復帰します。

入る条件はプランによって異なります (Beginner はプロジェクト作成 月 50 回 / Embedding 月 100 件、Expert・Pro は設定した月次予算上限)。詳細: [料金プラン ご利用ガイド §6](./plan-guide.md#6-予算上限と縮退モード)

## 8. 課金の全体像

たすきばの料金は **すべて従量課金** で、月額固定費はありません。4 つの課金軸があります。

| 課金軸 | 対象 | 無料枠 | 単価 |
|---|---|---|---|
| **LLM** | プロジェクト作成/更新・「なぜ?」 | Beginner 月 50 回 | Expert ¥10・Pro ¥15 / 回 |
| **Embedding** | 資産入力・意味検索・インポート・添付索引化 | Beginner 月 100 件 | Expert / Pro ¥5 / 業務操作 |
| **データ容量 (DB)** | テキスト系データの合計 | 50MB | 1GB ごと ¥50 |
| **ファイルストレージ** | 添付ファイル本体の合計 | 100MB | 1GB ごと ¥10 |

- すべて **税抜** 表記、請求書発行時に消費税が加算されます。
- 支払いは **クレジットカード払い (自動引落)** または **銀行振込** から選べます。
- ダッシュボードの表示金額・請求書・決済額はすべて一致する設計です (請求一致保証)。

詳細: [料金プラン ご利用ガイド](./plan-guide.md) / [API 利用 ご利用ガイド](./api-usage-guide.md)

## 9. 用語集

| 用語 | 意味 |
|---|---|
| **テナント** | ご利用組織ごとに区切られた独立の利用空間。テナントが違えばデータは一切見えません |
| **組織 ID** | テナントを識別する短い英数字コード。ログイン時に毎回入力します |
| **システムロール** | サービス全体での権限。テナント管理者 (admin) / 一般ユーザ (general) |
| **プロジェクトロール** | プロジェクトごとの権限。PM/TL / メンバー / 閲覧者 |
| **提案エンジン** | 過去資産を自動で関連付けて提示するたすきばの中核機能 |
| **意味検索 (semantic search)** | 文字の一致ではなく「意味の近さ」で検索するしくみ |
| **Embedding (索引化)** | 文章を意味ベクトルに変換し、検索・提案に使えるようにする処理 |
| **縮退モード** | AI 機能の上限到達時に、AI 補助だけが一時休止する状態 |
| **月中ピーク (peak)** | 当月内の最大使用量。容量課金の根拠になる値 |
| **下書き / 公開 (visibility)** | 資産の公開範囲。下書き = 自分のみ、公開 = テナント全員 |
