# テナントバナー利用ガイド

テナントバナーは、テナント管理者（組織の管理者権限を持つユーザー）が自分の組織のユーザーに向けて、画面上部に帯メッセージを表示できる機能です。メンテナンス予告・社内イベント告知・締め切り通知など、タイムリーな周知に活用できます。

---

## テナントバナーとは

ログイン後の全ページ上部に、指定した期間だけ帯メッセージが表示されます。

- **表示対象**: 自テナント（自組織）のユーザーのみ
- **表示期間**: 開始日時〜終了日時を指定（自動的に表示・非表示が切り替わる）
- **緊急度**: 高（赤）・中（黄）・低（青）の3段階で色分け
- **×ボタン**: ユーザーが閉じることができる（再ログイン後は再表示）

> **システム管理者のバナーとの違い**: たすきば全体の運営者（super_admin）が出す「システム周知バナー」とは別です。テナントバナーは自組織のユーザーにのみ表示されます。両方のバナーが同時に存在する場合は、緊急度の高い順に上から重ねて表示されます。

---

## 操作できるユーザー

- **テナント管理者**（組織設定 > 権限が「管理者」のユーザー）のみ操作できます
- 一般ユーザーは閲覧・×での非表示のみ可能です

---

## バナーを作成する

1. 画面右上のメニューから **「組織設定」** を開く
2. **「バナー」** タブを選択する
3. **「バナーを管理する →」** リンクをクリックしてバナー管理ページへ移動する
4. **「新規作成」** ボタンをクリックする
5. 以下の項目を入力する

| 項目 | 説明 |
|---|---|
| メッセージ | 帯に表示する本文（500文字以内、Markdown対応） |
| 緊急度 | 高（赤）/ 中（黄）/ 低（青）から選択 |
| 表示開始日時 | この日時からバナーが表示される |
| 表示終了日時 | この日時を過ぎると自動的に非表示になる（開始より後を指定） |
| 有効 | チェックなしで保存すると「停止」状態で作成される（後から有効化可能） |

6. **「作成」** ボタンをクリックして保存する

---

## バナーの状態

| 状態 | 説明 |
|---|---|
| 表示中 | 現在ユーザーに表示されている |
| 予約 | 開始日時前のため、まだ表示されていない |
| 終了 | 終了日時を過ぎて自動非表示になった |
| 停止 | 「取り下げ」操作で手動非表示にした（期間内でも非表示） |

---

## よくある操作

### バナーを取り下げる（即時非表示）

表示中・予約中のバナーを今すぐ止めたい場合：
1. バナー管理ページの一覧でバナーを見つける
2. 「取り下げ」ボタンをクリックする
3. バナーが「停止」状態になり、ユーザーへの表示が止まる

### バナーを再開する

停止中のバナーを再表示したい場合：
1. 一覧で停止中のバナーを見つける
2. 「再開」ボタンをクリックする
3. 表示期間内であれば「表示中」に、期間前であれば「予約」に戻る

> **注意**: 再開時に既存の表示中バナーと期間が重複する場合はエラーになります。先に既存バナーを取り下げてから再開してください。

### 過去のバナーを複製して新規作成する

以前のバナーを元に内容をコピーして新しいバナーを作成できます：
1. 一覧で複製したいバナーを見つける
2. 「複製」ボタンをクリックする
3. 内容が引き継がれた新規作成フォームが開く
4. 期間などを修正して保存する

### バナーを削除する

誤作成したバナーを履歴ごと削除したい場合：
1. 一覧でバナーを見つける
2. 「削除」ボタンをクリックする
3. 確認後に物理削除される（元に戻せません）

---

## 制約・注意事項

- **同時表示は1本まで**: 同じ組織で表示期間が重なるバナーを2本以上有効にすることはできません（「期間が重複しています」エラー）。新しいバナーを出すには既存のバナーを取り下げてください。
- **「期間なし」は不可**: 開始日時と終了日時は必須です。無期限に表示したい場合は終了日時を遠い未来（例: 1年後）に設定してください。
- **×で閉じた後**: ユーザーが×で閉じた場合、そのセッション中は再表示されません。ログアウト→再ログイン後に再表示されます。
- **複製は別のバナー**: 複製して作成したバナーは別の ID を持つため、以前に×で閉じたユーザーにも新たに表示されます。

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| バナーが表示されない | ① enabled（有効）になっているか確認 ② 現在が表示期間内か確認 ③ ユーザーがすでに×で閉じていないか確認 |
| 「期間が重複しています」エラー | 既存の有効バナーと表示期間が重なっている。既存バナーを取り下げてから作成する |
| 終了日時を開始より前に設定できない | 開始日時 < 終了日時 が必須。日時を修正する |
| 管理者タブが見えない | 自分のアカウントが「管理者」権限か確認する（一般ユーザーは管理タブ非表示） |
