# ファイルストレージ ご利用ガイド (添付ファイル従量課金)

たすきば Knowledge Relay では、プロジェクトや知見資産に添付したファイル本体 (PDF / Excel / 画像 等) をクラウドストレージに保存し、ご利用容量に応じた **シンプルな従量課金** を採用しています。本ガイドでは「ファイル添付の料金体系」「いつ集計・請求されるか」「セキュリティ」「ファイル検索機能」をご説明します。

> 本ガイドは **添付ファイル本体** に関するもので、データベース上のテキストデータ (= プロジェクト情報・ナレッジ・メモ等) は [データ容量 ご利用ガイド](./db-capacity-billing-guide) を別途ご参照ください。

## 1. 3 行サマリ

| 項目 | 内容 |
|---|---|
| **無料枠** | **100MB まで完全無料** (= 画像 1-5MB を 30-100 枚程度) |
| **超過時** | **1GB ごとに 10 円** (1MB 未満は繰上、税抜) |
| **累積容量の上限** | **なし** (Expert / Pro は使った分だけ従量課金、累積でアップロードが止まることはありません) |
| **1 ファイルの上限** | **50MB / 1 ファイル** (動画・大型 ZIP は不可) |

シンプルに言うと「**ファイルは 100MB まで無料、それ以降は 1GB ¥10**」です。データ容量 (¥50/GB) より大幅に安く設定されています。累積容量に上限はなく、**蓄積したファイルが増えたことを理由にアップロードが止まることはありません** (「データはたすきばの命」)。

> 🆕 **Beginner プランの方** (ADR-0025 / 2026-05-29): 100MB 無料枠を超えるとアップロードが **取込前に自動でブロック** されます (= overage 課金は発生しません)。不要なファイルを削除すると自動的に再集計され、再びアップロード可能になります。100MB を超えるデータをまとめて保存したい場合は **Expert / Pro プランへのアップグレード** をご検討ください (¥10/GB tier の従量課金、累積容量の上限なし)。

## 2. 料金体系

ファイルストレージ超過分は **1GB tier ごと** に 10 円ずつ加算される **階段関数型** の料金体系です。

| 月中の最大使用量 | 月額料金 (税抜) |
|---|---|
| 0 〜 100MB | **0 円** (無料枠) |
| 101MB 〜 1,100MB | **10 円** |
| 1,101MB 〜 2,100MB | **20 円** |
| 2,101MB 〜 3,100MB | **30 円** |
| ... | ... |
| 50GB 利用時 | **500 円** |
| 100GB 利用時 | **1,000 円** |

> 累積容量に上限はありません。使った分だけ 1GB ごとに 10 円が加算されます (Expert / Pro)。
>
> 「1GB = 1,000MB」「1MB = 1,000,000 バイト」(SI 単位、業界標準) です。
>
> たとえ 1 バイトでも超過があれば次の tier に切上げられます (例: 100MB + 1 バイト → 1MB billable → 10 円)。

### データ容量との料金差の理由

| 種類 | 単価 | 用途 |
|---|---|---|
| **データ容量** | ¥50/GB | テキスト・ナレッジ等 (= データベース内) |
| **ファイルストレージ (本ガイド)** | **¥10/GB** | バイナリファイル本体 (= クラウドストレージ) |

ファイルストレージはデータ容量よりも保管コストが低いため、料金もそれに応じて安く設定されています。

## 3. 何が課金対象になるか

**たすきば上で添付したファイル本体** (= PDF / Excel / 画像 / Word 等) が対象です。

| 紐付け先 | 対応有無 |
|---|---|
| プロジェクト | ✅ |
| タスク | ✅ |
| 見積 | ✅ |
| リスク・課題 | ✅ |
| 振り返り | ✅ |
| ナレッジ | ✅ |
| メモ | ✅ |

> **注意**: 既存の「URL 参照型」添付 (= 外部リンクのみ保存) は **課金対象外** で従来通り無料です。本機能は「ファイル本体を たすきば にアップロードする」場合のみ課金されます。

### サポートされるファイルタイプ

| 種類 | アップロード可否 | embedding (検索対象化) |
|---|---|---|
| PDF (.pdf) | ✅ | ✅ |
| Excel (.xlsx / .xls) | ✅ | ✅ |
| CSV (.csv) | ✅ | ✅ |
| Word (.docx) | ✅ | ✅ |
| テキスト (.txt / .md / .json) | ✅ | ✅ |
| 画像 (.jpg / .png / .gif / .webp) | ✅ | ❌ (将来 OCR 対応予定) |
| 圧縮 (.zip) | ✅ | ❌ |
| **実行ファイル (.exe / .bat / .sh 等)** | **❌ セキュリティで拒否** | — |
| **動画・大型 (50MB 超)** | **❌ サイズ上限超過で拒否** | — |

## 4. いつ集計され、いつ請求されるか

### 4.1 集計の仕組み (= データ容量と同じ仕組み)

**「月中の最大使用量 (peak)」** が課金根拠になります。

```
時間軸 → Day 1     Day 15     Day 25    Day 30 (月末)
使用量:  500MB  →  2GB    →   500MB  →  500MB

月末の請求対象 = 月中の最大値 = 2GB → 月額 20 円
```

たとえ月末に削除して使用量を下げても、**月内の最大値で請求される** ことにご注意ください (= 月末に大量削除して月初に再アップロードする抜け道を防ぐための仕様)。

### 4.2 集計タイミング

| 集計方法 | 頻度 | 役割 |
|---|---|---|
| **アップロード時の即時計測** | ファイル添付ごと | 1 ファイルのサイズ判定 (50MB) + peak 更新 |
| **日次自動再計算** | 毎日 18:00 JST | 全テナントの使用量を再同期 (= 計測漏れ防止) |
| **月初の請求確定** | 毎月 1 日 09:00 JST | 前月分の最終課金額を確定 |

### 4.3 請求タイミング

```
2026-06-01 ─────────────── 6 月の利用 ─────────────── 2026-06-30
                                                        │
                                                        │ 月中の最大使用量を「peak」として記録
                                                        ↓
2026-07-01 09:00 JST  ★ 月初の請求確定 (自動)
                       │ 6 月分の peak から課金額を算出
                       │ 課金履歴に記録 (= データ容量分と統合された請求書)
                       │
2026-07-03 〜 07-05 頃  Stripe で請求書発行
                       │
                       ├─ クレジットカード払い → 自動引落
                       └─ 銀行振込払い         → 請求書メール送付
```

### 4.4 月の途中で解約された場合

データ容量と同じく、退会時点までの使用量が **当月分として即時請求** されます。退会タイミングを月末直前に集中させても、その時点までの利用分は確実に請求対象になります。

退会時にはクラウドストレージ内のファイル本体も全て削除されます (= ご注意ください、復旧不可)。

## 5. 使用量・請求金額の確認方法

### 5.1 テナント管理者の方

テナント設定画面 (`/settings/tenant`) で **いつでも当月の使用状況** + **過去 6 ヶ月の請求履歴** を確認できます。

表示される情報:
- **現在のファイルストレージ使用量** (直近 24 時間以内に更新)
- **月中ピーク** (= 当月の最大使用量、請求根拠)
- **想定請求額** (税抜)
- **Level バッジ** (正常 / Level 1 / Level 2 / Level 3 — 使用量増加のお知らせ)
- **過去 6 ヶ月の月別請求履歴** (= 不正な変動の検知用)

### 5.2 「不正な請求」を防ぐ仕組み

たすきばでは **誤請求・不正請求を防ぐ** ため、以下の多層的な仕組みを実装しています:

1. **テナント側で常時可視化**: 管理者がいつでも自テナントの使用量・請求額を確認でき、想定外の変動があれば即時に気づけます
2. **過去 6 ヶ月の履歴表示**: 月別の請求推移を表示し、突然の金額変動を検知できます
3. **請求一致保証 (billing invariant)**: 使用量の記録・ダッシュボード表示・請求書・決済プラットフォームへの送信額が、すべて同じ数値を参照する設計のため、経路ごとの値ズレが構造的に発生しません
4. **運営側の監視**: 運営側でも全テナントの請求整合性・異常な使用増加を日次で監視しています

### 5.4 Level (お知らせレベル) について

各 Level は **使用量増加のお知らせ** であり、Expert / Pro プランでは **いずれの Level でもアップロードは止まりません** (累積容量で停止することはありません)。

| Level | 月中ピーク | 状態 | 想定月額 |
|---|---|---|---|
| **正常** | 0 〜 1GB | 通常運用 | 0 〜 10 円 |
| **Level 1** | 1GB 〜 10GB | 通常運用 (使用量増加のお知らせ) | 10 〜 100 円 |
| **Level 2** | 10GB 〜 50GB | 通常運用 (高額請求の注意喚起) | 100 〜 500 円 |
| **Level 3** | 50GB 到達 | 通常運用 (運営側で動作速度の監視を強化) | 500 円〜 |

> ファイルはオブジェクトストレージに保存され、データベースの動作に影響しないため、容量が増えても他テナントの速度に影響しにくい構造です。Level 3 はあくまで運営側の監視の目安です。

## 6. 1 ファイルのサイズ上限について

累積容量に上限はありませんが、**1 ファイルあたり 50MB の上限**があります。

### なぜこの上限があるのか

これは料金 (コスト) ではなく、**1 回のアップロードでサーバにかかる瞬間的な負荷を抑えるための技術的な安全策**です。動画や極端に大きな ZIP など、業務文書の範囲を超えるファイルを防ぎ、すべてのお客様のアップロードが安定して完了するようにしています。

PDF / Excel / Word / 画像といった通常の業務文書はほとんどが 50MB 未満です。

### 50MB を超えるファイルの場合

50MB を超える 1 ファイルのみアップロードがエラーになります。ファイルを分割するか、圧縮してから再度お試しください。**蓄積したファイルの合計が大きくなっても、新しいファイルのアップロードが止まることはありません** (Expert / Pro は使った分だけ従量課金。Beginner のみ無料枠 100MB 超過でアップロードが止まります)。

## 7. ファイル添付の検索機能 (新機能)

ファイルをアップロードすると、自動的に **検索インデックス (embedding)** が作成され、提案エンジン + チャット検索の対象になります。

### 7.1 検索インデックス作成タイミング

- アップロード完了から **最大 12 秒以内** に自動で作成 (= 非同期)
- UI 上では「検索インデックス作成中」と表示
- 完成すると「インデックス済」マークが表示

### 7.2 検索対象になるファイルタイプ

| ファイル | 検索対象 | 検索方法 |
|---|---|---|
| PDF / Excel / Word / CSV / テキスト | ✅ ファイル本文を検索 | チャット検索 + 提案エンジン |
| 画像 (JPG / PNG 等) | ❌ ファイル名・説明のみ | 部分一致のみ (OCR は将来対応) |
| ZIP / バイナリ | ❌ ファイル名のみ | 部分一致のみ |

### 7.3 チャット検索で「ファイル」を探す

チャット機能 (画面右下の「たすきフクロウ」アイコン) で、以下のキーワードを含むクエリを入力すると、**添付ファイルだけを対象** に検索します:

- 「ファイル」「添付」「PDF」「Excel」「資料」「文書」 等

例:
- 「ECサイトのプロジェクトに添付されてた PDF を探して」
  → 添付 PDF のみ検索 (ナレッジやプロジェクトは除外)
- 「打ち合わせ議事録の Excel ある?」
  → 添付 Excel のみ検索

これにより「**過去のあのファイル**」を素早く見つけられます。

### 7.4 提案エンジンとの統合

プロジェクト作成時、過去の類似資産 (ナレッジ・リスク・振り返り・**添付ファイル**) を AI が自動で提案します。添付ファイルは 📎 アイコンで他の資産と区別されます。

## 8. セキュリティ

たすきばは以下の仕組みで、ファイル添付機能のセキュリティと他テナント保護を実現しています:

### 8.1 大容量ファイルでサーバが停止する事象の防止

- **直接アップロード方式**: ファイルはブラウザからクラウドストレージへ **直接** アップロードされ、たすきばのサーバを経由しません。これにより大容量ファイル (50MB) のアップロードでサーバが停止する事象を防止します。
- **50MB ファイル上限**: 1 ファイル 50MB を超えるアップロードは事前拒否 (= 1 回あたりの瞬間負荷の保護。累積容量に上限はありません)

### 8.2 危険ファイルの拒否

実行可能ファイル (`.exe` / `.bat` / `.sh` / `.ps1` 等) は **アップロード時に自動拒否** されます。マルウェア配布などの不正利用を防止します。

### 8.3 テナント越境の防止

各テナントのファイルは **テナント ID で完全に分離** され、ストレージ・データベースの両レベルで他テナントから一切アクセスできないように設計されています。

### 8.4 アップロード URL の漏洩対策

アップロード用の Pre-signed URL は **60 秒で失効** し、漏洩時の被害を最小化します。

### 8.5 異常使用の自動検知

1 日に 5GB 以上のファイル増加があったテナントを super_admin に自動通知します (= 不正利用・誤操作の早期発見)。

## 10. 料金変更時のお知らせルール

データ容量と同じく、将来料金体系を変更する場合は以下のルールでお知らせします:

> **値上げ・課金体系変更の場合**:
> 効力発生日の **30 日以上前** から ユーザ規約ページに掲示し、
> かつ **ご登録メールアドレス宛にお知らせ** をお送りします。

- **値下げ** の場合は即時適用される場合があります
- **過去のご使用分には旧料金が適用** されます (= 遡及課金は行いません)

## 11. FAQ

### Q1. 既存の URL 参照型添付 (= 外部リンク) は課金対象になりますか?

**A.** いいえ、対象外です。本機能は「ファイル本体をたすきばにアップロードする」場合のみ課金されます。既存の URL 参照型添付は従来通り完全無料です。

### Q2. PDF をアップロードしたらすぐに検索できますか?

**A.** アップロード完了から **最大 12 秒以内** に自動で検索インデックスが作成されます。UI 上で「検索インデックス作成中」「インデックス済」の状態が確認できます。

### Q3. 画像 (JPG / PNG) も検索対象になりますか?

**A.** 初期バージョンではファイル名・説明文のみ検索対象です。画像内のテキスト (OCR) は将来バージョンで対応予定です。

### Q4. アップロード可能な最大ファイルサイズは?

**A.** **50MB / 1 ファイル** です。動画や大型 ZIP は対象外で、業務文書 (PDF / Excel / 画像 / Word) を想定した上限です。

### Q4-A. データ容量 (DB) とファイルストレージの違いは何ですか?

**A.** 従量課金の対象が異なります。
- **データ容量 (DB)**: テキスト系データを保存する PostgreSQL の容量です。プロジェクトの目的・背景・スコープ、ナレッジ・リスク・課題・振り返り・メモの本文、**URL・リンクのテキスト**、コメント、タグ等は全てここに含まれます。詳細は [データ容量 ご利用ガイド](./db-capacity-billing-guide) を参照。
- **ファイルストレージ = 本ガイドの対象**: 添付ファイル本体 (PDF / Excel / Word / 画像 等) を保存するクラウドストレージの容量です。**ファイルそのもの**だけが対象で、ファイル名やコメント等のテキスト情報は DB 側に入ります。

両方とも累積容量に上限はなく、使った分だけの従量課金 (DB ¥50/GB、ファイル ¥10/GB) です。蓄積したデータが増えても保存・アップロードが止まることはありません。

### Q4-B. PDF / Excel / 画像はどちらの容量に含まれますか?

**A.** 添付ファイル機能でアップロードした **ファイル本体** は **ファイルストレージ (本ガイド)** にカウントされます (クラウドストレージに保存)。ただし、ファイル名・説明文・コメント等のテキスト情報は [データ容量 (DB)](./db-capacity-billing-guide) 側に入ります。Markdown のテキスト中に画像を埋め込んだ場合 (= 画像 URL の参照のみ) は DB 側だけがカウント対象です。

### Q5. データ容量と料金が違うのはなぜですか?

**A.** ファイルストレージとデータベースは別のストレージシステムで、特性が異なります。ファイルストレージは大容量ファイルの保管に適した仕組みのため、単価も **¥10/GB** と安く設定しています (データ容量は ¥50/GB)。

### Q6. 月の途中でファイルを大量にアップロードして即削除しても課金されますか?

**A.** **はい、月内の最大値 (peak) で課金されます**。データ容量と同じ仕様です。

### Q7. 「ファイルを探して」とチャットで聞くとどうなりますか?

**A.** 「ファイル」「添付」「PDF」「Excel」「資料」等のキーワードを検出すると、**添付ファイルのみ** を対象に検索します (ナレッジ・プロジェクト等は除外)。「過去のあの添付ファイル」を素早く見つけられます。

### Q8. アップロード時に「危険なファイル」と表示されました

**A.** 実行可能ファイル (`.exe` / `.bat` / `.sh` / `.ps1` 等) はセキュリティ上の理由で拒否されます。これらは ZIP で圧縮してもサイズ別にお預かりしてください。

### Q9. ファイル容量に上限はありますか? 大量に蓄積してもアップロードは止まりませんか?

**A.** 累積容量に上限はありません。Expert / Pro プランでは、蓄積したファイルがどれだけ増えても 1GB ごとに ¥10 の従量課金が続くだけで、**アップロードが止まることはありません** (「データはたすきばの命」)。ファイルはオブジェクトストレージに保存され、データベースの動作に影響しないため、容量増加が他テナントの速度に影響しにくい構造です。1 ファイルあたり 50MB の上限がありますが、これは 1 回のアップロードの瞬間負荷を抑えるためのもので、累積容量とは無関係です。なお Beginner プランのみ、無料枠 (ファイル 100MB) 超過でアップロードが止まります (削除は可能、課金は発生しません)。

### Q10. 「不正な請求」を心配しています、どう確認できますか?

**A.** 以下の多層的な仕組みで透明性を保証しています:

1. **テナント設定画面**でいつでも当月の使用量・請求額・過去 6 ヶ月履歴を確認可能
2. **システム管理者** (運営側) は全テナントの請求金額一覧を CSV エクスポートで監査
3. **請求一致保証 (billing invariant)**: 使用量の記録 = ダッシュボード表示 = 請求書 = 決済プラットフォームへの送信額 が 100% 一致するよう設計
4. **運営側の監視**: 計測値と実容量の乖離・1 日あたりの急激な増加を、運営側が日次で監視

### Q11. ファイルを削除するとクラウドストレージからも削除されますか?

**A.** はい、論理削除と同時にクラウドストレージ上のファイルも **即時削除** されます。ストレージ使用量はすぐに削減されますが、誤削除には注意してください (復旧不可)。

### Q12. 退会した場合、ファイルはどうなりますか?

**A.** 退会手続きと同時にクラウドストレージ内のテナント領域が完全削除されます。**事前に必要なファイルをダウンロードしてください**。
