> 本機能は **テナント管理者 (admin)** のみがご利用いただけます。

## 1. クレジットカード払いの概要

- 毎月末日にその月の利用料が自動集計され、**翌月初に登録カードから自動引落** されます。
- 領収書 PDF は **Stripe からご登録メールアドレス宛に自動送信** されます。
- 引落・カード情報の管理はすべて **Stripe (世界標準の決済プラットフォーム)** を通じて行われます。たすきば側にカード番号は保存されません (= PCI DSS 準拠の安全性)。
- ご利用可能ブランド: **Visa / Mastercard / American Express / JCB**

---

## 2. 銀行振込との違い

| 項目 | 銀行振込 (デフォルト) | クレジットカード払い |
|---|---|---|
| 支払い手段 | 請求書 PDF をメール送付 → 振込み | 登録カードから自動引落 |
| 締日 | 月末締め | 月末締め |
| 支払い期日 | 翌月 25 日 | 翌月初 (自動引落) |
| 手間 | 毎月の振込操作が必要 | **自動 (操作不要)** |
| 領収書 | 運営側から PDF 送付 | **Stripe から自動 PDF 送信** |
| 振込手数料 | お客様ご負担 | **なし** (= 全額カード請求) |

## 3. クレジットカード払いへの切替手順

### Step 1: テナント設定画面を開く

画面右上の **「テナント管理者」** メニュー → **「テナント設定」** をクリック。

### Step 2: 「請求先情報」セクションまでスクロール

請求書の宛先となる情報 (会社名、担当者名、住所等) を入力します。
**初回のみ** 全項目の入力が必要です。

### Step 3: 「支払い方法」を「クレジットカード」に変更

請求先情報フォーム末尾の **「支払い方法」セレクトボックス** で **「クレジットカード」** を選択します。

### Step 4: 「請求先情報を更新」ボタンをクリック

ボタンを押すと **自動的に Stripe のカード登録画面 (Stripe Checkout) に遷移** します。
住所等の請求先情報も同時に保存されます。

### Step 5: カード情報を入力 → 「保存」

Stripe Checkout 画面で:
- カード番号
- 有効期限
- セキュリティコード (CVC)
- カード名義 (ローマ字)
- 国または地域

を入力して「保存」をクリック。

### Step 6: 自動でテナント設定画面に戻る

カード登録が完了すると自動でたすきばに戻り、**「クレジットカード払いに切替えました」** のメッセージが表示されます。

### Step 7: 確認

「支払い方法」セクションが以下のように表示されていれば完了です:

```
現在の支払い方法: ✅ クレジットカード払い (有効・自動引落)

請求に使用されるカード (Stripe 登録情報)
Visa •••• 4242  有効期限 12/34
このカードに毎月の利用料が自動引落されます。
```

## 4. 登録カード情報の確認

「テナント設定」画面の **「支払い方法」セクション** に、Stripe に登録された **現在の請求先カード** がリアルタイムで表示されます。

| 表示状態 | 意味 |
|---|---|
| ✅ クレジットカード払い (有効・自動引落) | 正常。登録カードから毎月自動引落されます |
| ⚠ クレジットカード払い (カード未登録) | 支払い方法は credit_card だがカード登録が未完了。すぐ登録してください |
| ❌ クレジットカード払い (要対応) | 引落エラーが発生しています。早急にカード再登録してください |
| 🏦 銀行振込 | クレジットカード払いではない状態 |

**画面に表示されているカード = 実際に毎月引落されるカード** が一致するよう、たすきばは **常に Stripe からリアルタイム取得** しています。

## 5. クレジットカード情報の変更

カードの差替え・有効期限延長は、**「クレジットカード情報更新」ボタン** からおこないます。

### Step 1: 「テナント設定」→「支払い方法」セクション

### Step 2: 「クレジットカード情報更新」ボタンをクリック

確認ダイアログが表示されます → **「OK」をクリック**。

### Step 3: Stripe Checkout 画面で新しいカード情報を入力

カード番号 / 有効期限 / CVC / カード名義 を入力 → **「保存」をクリック**。

### Step 4: 自動でテナント設定画面に戻る

完了すると自動でたすきばに戻り、**「クレジットカード情報を登録しました」** メッセージが表示されます。
変更したカードが画面の「請求に使用されるカード」欄に即時反映されているか確認してください。

> **重要 (Stripe 仕様について)**: 既存サブスクリプションの **月次自動引落カードは「クレジットカード情報更新」ボタンから入力したカードに直接 update** されます (= 次回以降の引落はすべて新カードから)。サブスクリプション自体は維持されるため、月跨ぎの二重請求は発生しません。

> **「請求履歴を見る」リンク**: 「クレジットカード情報更新」ボタンの横にある **「📋 請求履歴を見る」リンク** から、直近 6 ヶ月の請求履歴を確認できます (= `/settings/tenant/billing`)。

## 6. 銀行振込に戻す方法

### Step 1: 「テナント設定」→「請求先情報」セクション

### Step 2: 「支払い方法」を「銀行振込」に変更 → 「請求先情報を更新」

ボタンを押すと:
- 自動的に Stripe の Subscription (月次引落契約) が解約されます
- 当月以降の請求は **請求書 PDF (運営側から送付)** に切り替わります

### Step 3: 確認

「支払い方法」セクションが **「🏦 銀行振込」** に切り替わっていれば完了です。

> **登録済カード情報について**: Stripe 側に登録したカード情報は履歴として保持されますが、再度カード払いに戻す際は **「クレジットカード情報更新」ボタンから新しいカード情報を入力** する流れとなります (= 過去カード一覧からの再選択 UI はありません、毎回入力)。

> **当月の請求について**: 月途中で「銀行振込」に戻した場合、その月の利用料は **すべて請求書払い** となります (= 自動引落とは二重請求にならない仕組み)。

> **画面表示について**: 銀行振込に戻した時点で、テナント設定画面のカード情報ボックスは **非表示** に切り替わります。Stripe Customer Portal にカード履歴が残っていても、 **「画面に表示されているカード = 請求カード」** という UX 一貫性を保つためです。**カードに請求が行くことはありません** (= Subscription が自動 cancel されており、Stripe 側の引落処理が停止されている状態)。

## 7. 請求のタイミング・領収書

### 請求サイクル

```
[月初]                              [月末]              [翌月初]
  │                                   │                    │
  │← 利用料を Stripe で自動集計中    │                    │
  │                                   │                    │
  └───────────────────────────────────┴────────────────────┘
                                       締日             自動引落
                                                          + 領収書 PDF メール
```

### 引落のタイミング

毎月 **翌月初の数営業日以内** に Stripe から自動で引落処理が走ります。
お使いのカード会社により、明細への記載は引落から **1〜3 営業日後** となります。

### 領収書

引落成功時に **「tasukiba Knowledge Relay」名義で Stripe から領収書 PDF メールが自動送信** されます。
過去分の請求履歴は **「テナント設定」→「支払い方法」セクション → 「📋 請求履歴を見る」リンク** からアクセスできます (= `/settings/tenant/billing`、直近 6 ヶ月)。

### 引落失敗時の挙動

カード期限切れ・残高不足等で引落に失敗した場合:

1. Stripe による自動再試行が走ります (**約 2 週間で最大 8 回**)
2. すべての再試行に失敗した場合、最終的にテナントが **読み取り専用モード** に切り替わります (支払い遅延時と同じ猶予の流れで対応します)
3. ご登録メールに警告が届きますので、新しいカードへの差替えをお早めにお願いします

## 8. よくあるご質問 (FAQ)

### Q1. 登録カード番号はたすきばに保存されますか?

**いいえ**。カード番号は **すべて Stripe で安全に保管** され、たすきば側には末尾 4 桁・ブランド・有効期限のみ表示用に保持しています。これは PCI DSS (カード業界のセキュリティ基準) を満たすための設計です。

### Q2. 複数のカードを登録できますか?

**いいえ、1 枚のみ管理しています**。本サービスは「請求カード = 1 枚」前提の運用です。「クレジットカード情報更新」ボタンから新しいカード情報を入力すると、自動的に **既存サブスクリプションの引落カードが新カードに置き換わります** (= 古いカードからの引落は停止)。

### Q3. デフォルトのカードを画面で確認できますか?

**はい**。テナント設定画面の「支払い方法」セクションに **常に最新の引落カードがリアルタイム表示** されます。「クレジットカード情報更新」で新カード登録すると、即時画面に反映 + 次回引落も新カードに置き換わります (= 3 点完全一致: 画面 = 引落カード = サブスクリプションの default_payment_method)。

### Q4. 銀行振込払いに戻したら、登録カードは削除されますか?

**Stripe 側には残りますが、実引落カードは無効化** されます (= サブスクリプション自動 cancel + DB クリア)。完全削除をご希望の場合は運営サポートまでご連絡ください。

### Q5. 月途中で銀行振込 → カード払いに切替えると、当月の請求はどうなりますか?

切替時点までの利用分は **請求書 PDF (運営側) で送付**、切替後は **カード自動引落** に分かれます。**二重請求にはなりません** (= 自動で重複防止される仕組み)。

### Q6. カードの有効期限が切れたらどうなりますか?

引落失敗時に Stripe から自動再試行が走り、最終的に失敗した場合はテナントが読み取り専用モードに切り替わります (上記 §7 「引落失敗時の挙動」参照)。
有効期限が近づいた段階で **「クレジットカード情報更新」ボタンから新しいカード情報を入力** していただくことを推奨します。

### Q7. 領収書の宛名を変更したいです

請求先情報の **「会社名 / 法人名」** または **「お名前」** を変更してください。次回の請求から新しい宛名で領収書が発行されます。

### Q8. クレジットカード払い時の手数料はかかりますか?

**かかりません**。利用料の全額がカードから引落されます (= 振込手数料も発生しません)。

### Q9. 海外発行カードでも使えますか?

**Visa / Mastercard / American Express の海外発行カードは利用可能** です。日本発行カード扱いでない場合、お使いのカード会社で海外決済 (米国ドル建て扱い) として認識されることがあります。詳細はカード会社にご確認ください。

### Q10. テスト環境 (Stripe サンドボックス) で動作確認できますか?

**はい**。開発・検証用の Deploy Preview 環境では Stripe Test mode が有効です。テストカード番号 `4242 4242 4242 4242` 等で動作確認できます。本番環境では実カードのみが利用可能です。

## 9. トラブル時のお問い合わせ

以下のようなトラブルが発生した場合、運営サポートまでお問い合わせください:

- 引落エラーが解消できない
- 領収書 PDF が届かない
- 「クレジットカード情報更新」ボタンでカード登録できない
- 二重請求が疑われる
- 不正利用の疑いがある
- 過去カード情報を完全に削除したい

**お問い合わせ窓口**: 運営側で別途案内するサポートメールアドレスまでご連絡ください。
お問い合わせの際は **テナント ID (組織 ID)** をあわせてお知らせください。
