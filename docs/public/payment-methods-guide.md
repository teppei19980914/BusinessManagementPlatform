## 1. 2 つの支払い方法

たすきばでは、以下の 2 種類からお支払い方法を選べます。テナント管理者がテナント設定画面でいつでも切り替えられます。

| 支払い方法 | 概要 |
|---|---|
| **銀行振込**(請求書払い、初期設定) | 月末締めで請求書をメールでお送りし、お振込みいただきます |
| **クレジットカード払い** | 月末締めで登録カードから自動で引き落とされます |

どちらの方法でも、料金体系・請求のタイミングは同じです。

> Beginner プラン(90 日無料試用)は無料のため、請求書の発行や引き落としは発生しません。お支払いが関係するのは Expert / Pro プランです。

## 2. 対応しているカードブランド

クレジットカード払いでは、以下の **4 つのカードブランド** に対応しています。

| ブランド | 対応 |
|---|---|
| **Visa** | ✅ |
| **Mastercard** | ✅ |
| **American Express** | ✅ |
| **JCB** | ✅ |

- 海外で発行された Visa / Mastercard / American Express のカードもご利用いただけます(お使いのカード会社によっては海外決済扱いになる場合があります)。
- 本人認証(3D セキュア)に対応しています。

> Diners Club / Discover / 銀聯(UnionPay)など、上記 4 ブランド以外のカードには現在対応していません。

## 3. カード情報の安全性

- クレジットカードの処理は、世界標準の決済サービス **Stripe** を通じて行われます。
- **カード番号はたすきば側のサーバに保存されません**(画面には末尾 4 桁・ブランド・有効期限のみ表示)。これはカード業界のセキュリティ基準(PCI DSS)に沿った仕組みです。
- カードの登録・変更は、Stripe の安全な画面で行います。

詳しい登録・変更・銀行振込への戻し方は [クレジットカード払い ご利用ガイド](./credit-card-payment-guide.md) を参照してください。

## 4. FAQ

### Q1. どのカードブランドが使えますか?

**A.** Visa / Mastercard / American Express / JCB の 4 ブランドです。Diners Club / Discover / 銀聯(UnionPay)には現在対応していません。

### Q2. 海外発行のカードは使えますか?

**A.** Visa / Mastercard / American Express の海外発行カードはご利用いただけます。お使いのカード会社によっては海外決済(外貨建て扱い)として処理されることがありますので、詳細はカード会社にご確認ください。

### Q3. 銀行振込とクレジットカード払いで料金は変わりますか?

**A.** 変わりません。どちらも同じ料金体系・同じ請求タイミングです。

### Q4. 支払い方法は後から変更できますか?

**A.** はい。テナント管理者がテナント設定画面からいつでも切り替えられます(切り替え時に二重請求は発生しません)。手順は [クレジットカード払い ご利用ガイド](./credit-card-payment-guide.md) を参照してください。
