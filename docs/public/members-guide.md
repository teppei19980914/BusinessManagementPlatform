# プロジェクトメンバー管理 ご利用ガイド

プロジェクトメンバー管理は、プロジェクトに参加するユーザと、その **プロジェクトロール (PM/TL・メンバー・閲覧者)** を管理する機能です。本ガイドでは、メンバーの追加・ロール変更・解除と、その権限ルールをご説明します。

> ロールごとにできることの全体像は [ロールと権限 ご利用ガイド](./roles-permissions-guide) を参照してください。組織へのユーザ招待 (アカウント発行) は [アカウント追加手順](./account-setup-guide) を参照してください。

## 1. プロジェクトメンバーとは

ユーザは組織 (テナント) に所属し、さらに **プロジェクトごとに** 参加メンバーとして登録されます。プロジェクトに参加していないユーザは、そのプロジェクトの情報にアクセスできません (テナント管理者を除く)。

同じ人が、あるプロジェクトでは PM/TL、別のプロジェクトではメンバー、という持ち方ができます。

---

## 2. 一覧の項目

プロジェクト詳細 →「メンバー」タブで、参加メンバーを一覧できます。

| 項目 | 内容 |
|---|---|
| ユーザ名 | 氏名 |
| メールアドレス | ログイン ID |
| プロジェクトロール | PM/TL / メンバー / 閲覧者 |
| 利用状態 | 有効 / 無効 |
| 設定者 | 変更を行った人 |
| 更新日時 | 最終更新 |

## 3. メンバーの追加・解除・ロール変更

- **追加**: 「ユーザを追加」から、組織内の (まだ参加していない) ユーザを選び、プロジェクトロールを指定して追加します。
- **ロール変更**: メンバー ↔ 閲覧者 のロールを変更できます。
- **解除**: プロジェクトから外します。外したユーザが作成したデータ (タスク・ナレッジ等) は残ります。

> 追加できるのは、組織にすでに登録済み (招待・有効化済み) のユーザです。新しい人を組織に呼ぶには、先に [アカウント追加手順](./account-setup-guide) でユーザ招待を行います。

---

## 4. PM/TL ロールを扱う操作は管理者のみ

メンバー管理には、安全のための線引きがあります。

| 操作 | PM/TL | テナント管理者 |
|---|:--:|:--:|
| メンバー / 閲覧者 の追加・解除 | ○ | ○ |
| メンバー ↔ 閲覧者 のロール変更 | ○ | ○ |
| **PM/TL の追加・解除** | × | ○ |
| **PM/TL への昇格 / PM/TL からの降格** | × | ○ |

- PM/TL は、自分のプロジェクト内で メンバー / 閲覧者 を自律的に管理できます。
- ただし「**PM/TL ロールそのもの**」を扱う操作 (追加・削除・昇格・降格) は **テナント管理者のみ** です。PM/TL が自分の上位権限を勝手に増減できないようにするためです。
- **自分自身のロールは変更できません** (管理者でも不可)。

---

## 5. 権限

| 操作 | 管理者 | PM/TL | メンバー | 閲覧者 |
|---|:--:|:--:|:--:|:--:|
| メンバー一覧を見る | ○ | ○ | × | × |
| メンバー / 閲覧者 の追加・解除・ロール変更 | ○ | ○ | × | × |
| PM/TL の追加・解除・昇格・降格 | ○ | × | × | × |

> ロールを変更すると、対象ユーザの全セッションが即時無効化され、次回ログインから新しい権限が適用されます。

## 6. FAQ

### Q1. PM/TL ですが、メンバーを PM/TL に昇格できません。

**A.** PM/TL ロールを扱う操作 (昇格・降格・追加・削除) はテナント管理者のみが行えます。PM/TL は メンバー / 閲覧者 の管理までができます。

### Q2. 追加したい人が候補に出てきません。

**A.** プロジェクトに追加できるのは、組織にすでに登録済みのユーザです。未登録の人は、先にユーザ招待 ([アカウント追加手順](./account-setup-guide)) を行ってください。

### Q3. メンバーを解除すると、その人のデータは消えますか?

**A.** いいえ。解除されたメンバーが作成したタスク・ナレッジ等のデータはプロジェクトに残り、他のメンバーが引き続き利用できます。
