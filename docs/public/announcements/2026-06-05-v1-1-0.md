## アップデートのお知らせ (v1.1.0)

平素より大変お世話になっております。たすきば運営です。

このたび、**たすきば Knowledge Relay v1.1.0** をリリースいたしましたので、主な変更点をご案内いたします。今回は、はじめてお使いになる方がスムーズに業務を始められるよう、**既存データの取り込み** と **画面の見やすさ**、そして **AI ヘルプ** を中心に改善しました。

詳しくは、[バージョンアップ情報](/changelog)を参照してください。

## 主なアップデート

### 📥 既存データを CSV でまとめて取り込めるようになりました

他のツールや Excel に蓄積した既存データを、たすきばに **一括で取り込める** ようになりました (テナント設定画面 →「データインポート」)。

- 対象は **顧客・プロジェクト・WBS (タスク)・リスク・課題・ナレッジ・振り返り** の 7 種類です
- 種類ごとの **テンプレート CSV** をダウンロードして埋め、「ダウンロード → 列の割り当て → プレビュー → 取り込み」の 4 ステップで完了します
- **日付は `2026-06-04` でも `2026/06/04` でも OK** です。Excel が日付を自動でスラッシュ区切りにしても、設定を変えずそのまま取り込めます
- 入力チェックを充実させ、選択肢以外の値や不正な日付は **取り込み前のプレビューで分かりやすくお知らせ** します。取り込んでも一覧に表示されない状態 (どのプロジェクトにも紐づかない下書き) も事前に防げます

※ はじめての移行に便利な機能です。すべて新規作成として取り込まれます (既存データの一括更新は各「○○一覧」から行ってください)。今後は、他サービスの API と直接つないで自動取り込みする「API 連携」の提供も予定しています。

### 🖥️ 一覧画面が見やすく・操作しやすくなりました

メモ一覧・全メモ・マイタスクなどの一覧画面を見直し、**列の構成や操作ボタンの配置を他の画面とそろえました**。外部リンクとファイル添付を別の列に分けるなど、ひと目で内容を把握しやすくしています。

### 🦉 AI ヘルプ「たすきフクロウ」がさらに賢くなりました

マイタスク・メモ・個人設定・セキュリティ・データの取り込みなど、これまで答えられなかった範囲まで **よくある質問と使い方ガイドを大幅に追加** しました。困ったときは画面右下のフクロウに気軽にご質問ください。

### 🔒 セキュリティを強化しました

- **他の端末からログアウト** (設定画面) を新設しました。いま使っている端末はそのままに、**他のすべての端末・ブラウザを一括でログアウト** できます。端末の紛失や共用 PC への置き忘れが心配なときの自己防衛にお使いください
- 提案機能と AI チャット検索が **各テナント (組織) 自身のデータのみ** を参照するようになり、組織間のデータ分離をさらに強化しました

### ✨ その他の改善

- **メモにもファイルを添付** できるようになりました (1 ファイル 50MB)
- **スターターデータ (見本データ) の取り込み・削除** を新設。データが無い状態でも、提案機能や AI チャットの便利さを 1 クリックでお試しいただけます
- **無料の Beginner プランでのテナント開設フォームを簡素化** し、住所などの請求先情報の入力を不要にしました
- 同じ名前のタスクや件数の多い WBS でも安定して取り込めるよう、**WBS の上書きインポートを改善** しました
