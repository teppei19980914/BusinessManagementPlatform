## アップデートのお知らせ (v1.4.0)

平素より大変お世話になっております。たすきば運営です。

このたび、**たすきば Knowledge Relay v1.4.0** をリリースいたしましたので、主な変更点をご案内いたします。今回は、ご要望の多かった **WBS タスク管理のカンバンビュー** を追加しました。

詳しくは、[バージョンアップ情報](/changelog)を参照してください。

## 主なアップデート

### 📋 WBS タスク管理にカンバンビューを追加しました

従来の階層ツリー表示に加えて、**カンバンビュー** を選択できるようになりました。タスクの担当者別・日程別の工数配分をひと目で確認できます。

#### 切替方法

WBS / タスク画面のフィルターエリア右端に **「ツリービュー / カンバンビュー」** のトグルボタンが追加されました。クリックするだけで切り替えられます。選択したビューはブラウザのセッション中に記憶されます（ページを更新しても維持されます）。

> **対応環境**: パソコン（PC）のみです。スマートフォン・タブレットでは従来のカード表示が継続されます。

#### カンバンビューの見方

| 軸 | 内容 |
|---|---|
| 横軸（列） | **全暦日（土日・祝日を含む）** ガントチャートと同じカレンダーです |
| 縦軸（行） | 担当者（担当なしは最下部） |
| 各マス | その担当者がその日に担当するタスクが付箋で積み上げ表示 |

**列の色分け（ガントチャートと共通）**

| 列 | 色 |
|---|---|
| 土曜日 | 青い背景 |
| 日曜日・祝日 | 赤い背景（列見出しに祝日名も表示） |
| 今日 | 強調表示（青緑系）。ページ表示時に今日の列が自動的に左端に揃います |

**付箋の高さ = 日次工数の目安**

付箋の縦の長さは、その日に割り振られた予定工数に比例します（8 時間分が最大の高さです）。縦に長い付箋ほど、その日の工数が多いことを示しています。

日次工数は「**総予定工数 ÷ 全暦日数（土日・祝日を含む）**」で計算されます。例えば 4 時間のタスクが金〜月（4 日間）なら 1h/日として土日にも付箋が表示されます。

**セルの色で過負荷を把握**

| 背景色 | 意味 |
|---|---|
| 黄色 | 1 日の工数合計が 7 時間以上（注意） |
| 赤 | 1 日の工数合計が 8 時間以上（過負荷の可能性） |

#### ホバーで詳細確認 / クリックで編集

付箋にマウスカーソルを合わせると、以下の詳細がポップアップで確認できます。

- ワークパッケージ名（WP）
- 担当者・ステータス
- 期間（予定開始〜予定終了）
- **総予定工数**（タスク全体の合計）
- **日次工数（推定）**（全暦日で均等割り）

付箋をクリックすると編集ダイアログが開きます（ツリービューと同じダイアログです）。また、付箋右上のチェックボックスで複数選択して一括編集・一括実績更新も行えます。

**開始予定日または終了予定日が設定されていないタスクは「未スケジュール」行**に表示されます。編集ダイアログで日程を設定するとグリッドに移動します。

#### 付箋のドラッグ&ドロップで日程・担当者を変更（管理者・PM/TL のみ）

付箋をドラッグして別の日付列や別の担当者行へ落とすだけで、開始予定日・終了予定日・担当者をその場で変更できます。

- **別の日付列へドロップ**: 開始・終了予定日が移動分だけシフトします（期間を保ったまま移動）。複数日にまたがるタスクは全付箋が連動して移動します。
- **別の担当者行へドロップ**: 担当者が変更されます（日付の移動と同時も可）。
- 未スケジュール行の付箋はドラッグできません。先に編集ダイアログで日程を入力してください。

### 🔍 タスク作成・編集時の親ワークパッケージ選択に検索機能を追加しました

WBS のタスク数が増えると、「どの WP の下に置くか」を選ぶのが大変になります。今回のアップデートで、タスクの作成・編集・一括複製ダイアログの**「親ワークパッケージ」欄に検索機能が追加**されました。

#### 使い方

1. タスクの作成ダイアログ（または編集・一括複製ダイアログ）を開く
2. 「親ワークパッケージ」欄をクリックする
3. WP 名の一部を入力すると、一致する候補だけに絞り込まれる
4. 目的の WP を選択する

> **WP 数が少ない場合は従来どおりのリスト表示**になります。WP 数が画面の高さに収まらなくなると自動的に検索機能が現れます。

### 💬 コメント・備考欄での Markdown 書式対応

コメント欄（各詳細ダイアログ）、顧客の備考欄、画面上部のシステムお知らせ帯で **Markdown 書式** が使えるようになりました。

#### 使える書式の例

| 書き方 | 表示 |
|---|---|
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `## 見出し` | 大きな見出し |
| `- 項目` | 箇条書き |
| `1. 項目` | 番号付きリスト |
| `` `コード` `` | インラインコード |
| `[リンク](URL)` | クリックできるリンク |
| `---` | 区切り線 |

URL をそのまま貼り付けても自動でリンクになります（これまでどおり）。

#### コメント入力欄の「プレビュー」ボタン

コメント入力フォームに **「プレビュー」ボタン** が追加されました。押すと入力中のテキストが Markdown 書式で実際にどう表示されるかを、入力欄の隣で確認できます。もう一度押すとプレビューが閉じます。

**@メンションとの併用も可能です。** コメント欄で `@` を入力してメンション候補を選択した後も、本文に Markdown 書式を混在させられます。

### 🗑️ インポートの「削除候補」表示を改善しました

WBS・リスク/課題・ナレッジ・振り返り・メモの各インポートプレビュー画面で、削除候補一覧の表示方法を改善しました。

**変更前**: 削除候補がある場合は常に一覧が表示されていたため、タスクのように件数が多い場合に画面が見づらくなることがありました。

**変更後**: 「削除候補の扱い」で **「削除」を選択した場合のみ**、その選択肢の直下にアコーディオン形式（折りたたみ）で一覧が表示されるようになりました。最初は折りたたまれており、クリックして展開できます。「保持」や「警告のみ」では一覧は表示されません。
