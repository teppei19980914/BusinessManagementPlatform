## サービス公開のお知らせ

平素より大変お世話になっております。たすきば運営です。

このたび、**たすきば Knowledge Relay v1.0** を一般提供 (GA) として公開いたしましたので、お知らせいたします。

たすきば Knowledge Relay は、**プロジェクトの知見を蓄積し、次の判断を強くする運営プラットフォーム** です。プロジェクトの企画から完了・振り返りまでを一気通貫で支援する基盤に加え、**過去資産を意味検索で再利用する提案エンジン** を核心機能として提供します。

## 主な機能

- **提案エンジン (意味検索)** — 過去のナレッジ・リスク・課題・振り返り・メモを 5 資産横断で意味検索し、スコア順に段階表示します
- **チャットボット意味検索** — 自然文で質問するだけで関連情報を取得できます
- **プロジェクト運営の一気通貫** — 企画 → 見積 → 計画 → 実行 → 完了 → 振り返り → クローズの 7 状態モデル
- **使った分だけの透明な課金** — 月額固定なし。プロジェクト作成/更新・「なぜ?」機能 (Pro 限定) は per-call 課金、資産入力・チャット検索などの Embedding 機能は **Beginner は月 100 件まで無料 / Expert・Pro は ¥5 / 業務操作**。Beginner プランはプロジェクト作成/更新 月 50 回まで無料

## 運営体制について

開発者 1 名 + Claude Code 中心の少人数体制で運営しています。明示的な SLA はまだ提示しておりませんが、**データの保護と継続運営は最優先** で取り組んでおります。

ご意見・ご要望はサービス内フッタの「お問い合わせ」または Discord コミュニティまでお寄せください。今後もアップデート情報はこちらのお知らせページでご案内いたします。
