# 周知バナー（画面上部のお知らせ帯）ご利用ガイド

たすきば運営から全利用者へ大切な連絡を届けるための、**画面上部に表示されるお知らせ帯（周知バナー）** について説明します。前半は **すべての利用者様向け（帯の見方）**、後半は **たすきば運営（システム管理者）向け（帯の出し方）** です。

> この帯は、個別の通知（ベルのマーク）や「[お知らせ](./service-info-guide.md)」一覧とは別物です。全利用者に同じ内容を確実に届けるための仕組みで、**緊急メンテナンスや障害などの突発的なお知らせ、バージョンアップデート（新機能・改善）のご案内、イベントやキャンペーン情報など、さまざまな用途**で活用します。

## 1. すべての利用者様へ — お知らせ帯の見方

### いつ表示されますか?

運営から全利用者にお届けしたいお知らせがあるときに、画面の一番上に色付きの帯が表示されます。用途はさまざまで、たとえば次のようなお知らせに活用します。

- **突発的なお知らせ**: 緊急メンテナンス・障害・一時的な利用制限など
- **バージョンアップデートのご案内**: 新機能・改善のリリース告知など
- **イベント・キャンペーン情報**: 各種イベントのご案内、期間限定のお知らせなど

**決められた期間のあいだだけ表示され、期間が終わると自動的に消えます。** ログイン後のすべての画面（ダッシュボード）で共通に表示されます。

### 色の意味（重要度）

| 色 | 重要度 | 例 |
| --- | --- | --- |
| 🔴 赤 | 高 | 障害発生中・緊急メンテナンス |
| 🟡 黄 | 中 | 予定メンテナンスの事前案内 |
| 🔵 青 | 低 | 軽微な変更のご案内 |

### 閉じ方と再表示

- 帯の右端の「**✕**」を押すと閉じられます。
- 閉じた状態は **いまログインしている間だけ** 保持されます。
- いったんログアウトして再びログインすると、**その連絡の表示期間内であればもう一度表示されます**（大切な連絡を見落とさないための仕組みです）。表示期間が終わっていれば、再ログインしても表示されません。

> この帯の内容を作成・編集できるのは、たすきば運営（システム管理者）のみです。各組織の管理者・メンバーが内容を変更することはありません。

## 2. 運営者（システム管理者）向け — お知らせ帯の出し方

> 本セクションの操作は **システム管理者（たすきば運営者）専用** です。各組織のテナント管理者・一般メンバーには表示されません。

### 開き方

画面上部のナビゲーション「システム管理者領域」→「**周知バナー**」（`/admin/super/banners`）を開きます。

### 一覧（履歴）画面

過去に作成したものも含め、すべての周知バナーが新しい順で一覧表示されます。各行に状態バッジが付きます。

| 状態 | 意味 |
| --- | --- |
| 表示中 | 有効かつ現在が表示期間内（利用者に出ている） |
| 予約 | 有効だが表示開始前 |
| 終了 | 表示期間が過ぎた |
| 停止 | 取り下げ（無効化）済み |

各行から **編集 / 複製 / 取り下げ・再開 / 削除** ができます。

### 新規作成

「**+ 新規バナー**」から作成します。入力項目は次のとおりです。

- **メッセージ**（最大 500 文字）: 帯に表示する本文。
- **緊急度**: 高（赤）/ 中（黄）/ 低（青）。
- **表示開始日時 / 表示終了日時**（JST）: この期間のあいだだけ表示されます。
- **このバナーを有効にする**: チェックを外すと「取り下げ（停止）」状態で保存され、期間内でも表示されません。

> **同時に表示できる帯は 1 本まで** です。すでに有効なバナーと表示期間が重なる場合は作成・保存できません（エラーで案内されます）。期間をずらすか、重なっているバナーを先に取り下げてください。

### 取り下げ・再開

- **取り下げ**: 表示中の帯を即時に止めます。**履歴には残ります**（あとから複製して再利用できます）。
- **再開**: 取り下げた帯を再び有効にします（他の有効なバナーと期間が重なる場合は再開できません）。

### 複製

過去のバナーの「**複製**」を押すと、メッセージと緊急度・期間をコピーした新規作成画面が開きます。複製は新しい帯として作成されるため、過去にその帯を「✕」で閉じた利用者にも改めて表示されます。

### 削除

誤って作成した帯は「**削除**」で履歴ごと完全に削除できます（通常は履歴を残す「取り下げ」を使い、削除は作成ミスの後始末に使ってください）。

## 3. FAQ

**Q. 帯が表示されません。**
A. 「有効」かつ「現在が表示開始〜終了の期間内」のバナーだけが表示されます。状態が「予約」「終了」「停止」のものは表示されません。また、同時に表示される帯は 1 本までです。

**Q. 利用者が「✕」で閉じた帯を、もう一度全員に見せたい。**
A. 同じ内容で「複製」して新しい帯を作成してください。複製は別の帯として扱われるため、以前閉じた利用者にも再表示されます。

**Q. 表示期間を間違えました。**
A. 一覧の「編集」から表示開始・終了日時を修正できます。他の有効なバナーと期間が重なると保存できないため、その場合は重なる側を取り下げてから調整してください。

**Q. この帯はメールでも届きますか?**
A. いいえ。画面上部の帯としてのみ表示されます。メール通知や通知ベルとは別の仕組みです。
