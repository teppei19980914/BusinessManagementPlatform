# 外部データ CSV 取込手順（テナント管理者向け）

テナント管理者が **初回ログイン後** に、社内 wiki / Excel / 旧プロジェクト管理ツール等で蓄積していた既存データを **CSV ファイルでまとめて取り込む** ための手順書です。エンジニアの方でなくてもお読みいただけるよう、専門用語をできるだけ避けて記載しています。

> **📌 CSV からの一括取込は「① CSVファイルをインポート」に一本化されています**
>
> **顧客・プロジェクト・WBS（タスク）・リスク・課題・ナレッジ・振り返り の 7 種類**を、1 つの画面でまとめて取り込めます（以前あった「ナレッジ・課題のみ」の専用ウィザードは廃止し、本画面に統合しました）。
>
> - 画面: テナント設定 →「データインポート」→「**① CSVファイルをインポートしたい方へ**」（`/settings/tenant/migration-import`）
> - 取り込みルールは取込画面の **「CSVインポートルール」** にも要約されています（本書はその完全版です）。
> - CSV を使わず外部サービス（Notion / Backlog / kintone / Pleasanter / Google スプレッドシート）に直接つなぐ場合は「② 外部データを直接インポート（API 連携・ベータ）」（`/settings/tenant/api-import`）をご利用ください。取り込みルール（選択肢・日付・上限・料金・新規作成のみ）は本書の CSV 経路と共通です。

> **💰 プラン別のインポート時の容量制御**（ADR-0020 §11）
>
> ご利用プランによって、CSV インポート時の容量制御が異なります:
>
> | 取込後の予測使用量 | Beginner | Expert / Pro |
> |---|---|---|
> | < 50 MB（無料枠内） | ✅ 取込可 | ✅ 取込可 |
> | 50 MB - 1 GB | **⛔ 取込ブロック** | ✅ 取込可（¥0〜¥50/月の従量課金） |
> | 1 GB - 10 GB | **⛔ 取込ブロック** | ⚠ **警告表示**（取込可、¥50〜¥500/月） |
> | 10 GB - 50 GB | **⛔ 取込ブロック** | ⚠ **警告表示**（取込可、¥500〜¥2,500/月） |
> | ≥ 50 GB | **⛔ 取込ブロック** | ✅ 取込可（従量課金が継続、累積上限なし） |
>
> **Beginner プランの方**: 50 MB 無料枠を超える取込は **取込前に自動でブロック** されます（プレビューで警告表示 + 取込ボタンが無効化）。意図せず課金が発生することはありません。50 MB を超えるデータをまとめて取り込みたい場合は **Expert / Pro プランへのアップグレード** をご検討ください。
>
> **Expert / Pro プランの方**: 50 MB 超過分は **¥50/GB tier の従量課金** になります。**累積容量に上限はなく、蓄積したデータが増えたことを理由に取込が止まることはありません**（「データはたすきばの命」）。プレビュー画面で「取込後の予測使用量」「予測月次課金額」が表示されますので、内容を確認のうえ取込を実行してください。なお、1 ファイルあたりのサイズ上限（50 MB）と 1 回の取込上限（合計 5,000 件）は瞬間負荷を抑えるため別途存続します。
>
> 詳しくは [データ容量 ご利用ガイド](./db-capacity-billing-guide) を参照してください。

## 全体の流れ（4 ステップ）

```
[準備] 種類ごとに CSV (UTF-8) を用意
   ・取込画面でテンプレート CSV をダウンロード（日本語ヘッダ付き）
   ・Excel で編集 → 「名前を付けて保存」→「CSV UTF-8」
        ↓
[ステップ 1] テナント管理者でログイン → テナント設定を開く
        ↓
[ステップ 2] 「① CSVファイルをインポート」を開く（/settings/tenant/migration-import）
        ↓
[Step 1] CSV を選ぶ
   種類ごと（顧客 / プロジェクト / WBS / リスク・課題 / ナレッジ / 振り返り）に CSV を選択
        ↓
[Step 2] マッピング
   CSV の列 → 画面項目 を対応付け（割り当てない列は取り込まれない。既定値も設定可）
        ↓
[Step 3] プレビュー
   件数・エラー行・想定料金を確認（まだ取込はされない）
        ↓
[Step 4] 取り込み
   「この内容で取り込む」で新規作成。結果サマリが表示される
```

## 事前準備：CSV ファイルを用意する

### A. テンプレート CSV をダウンロードする（推奨）

取込画面で配布する **種類ごとのテンプレート CSV**（日本語ヘッダ付き・空ファイル）を起点に編集すると、列名がそのまま画面項目と一致するため、後のマッピング作業を「同名選択」だけで完了でき、エラーが起きにくくなります。

ダウンロード手順は本書の [ステップ 2](#ステップ-2-csvファイルをインポートを開く) で説明します。

### B. CSV ファイルのフォーマット要件

| 項目 | 仕様 | 備考 |
| --- | --- | --- |
| 文字コード | **UTF-8** | Excel の既定（Shift_JIS）では文字化けします。Excel から保存する場合は **「CSV UTF-8 (コンマ区切り)」** を選んでください |
| BOM | 付いていても付いていなくても可 | Excel が保存時に自動付与する BOM はサービス側で自動除去します |
| 改行コード | CRLF（`\r\n`）または LF（`\n`）どちらでも可 | RFC 4180 準拠 |
| 1 行目 | **ヘッダ行（列名）** | サービスはこの行を見てマッピング候補を提示します |
| 区切り文字 | **カンマ（`,`）** | タブ区切り（TSV）・セミコロン区切りは非対応 |
| カンマを含むセル | ダブルクォートで囲む（例: `"A, B, C"`） | RFC 4180 標準 |
| 改行を含むセル（長文列） | **ダブルクォートで囲む**（例: `"1 行目↵2 行目"`） | 目的・背景・内容・原因など長文を入れる列で重要。詳細は本書 [付録 A](#付録-a-改行を含むセルの書き方重要) を参照 |
| ダブルクォートを含むセル | `"` を `""` に二重化（例: `"彼は ""OK"" と言った"`） | RFC 4180 標準 |
| ファイルサイズ上限 | **50 MB** | 超過すると弾かれます |
| 1 回の取込件数 | **合計 5,000 件まで**（全種類の合計） | 超える場合は分割してください |

> **⚠ 改行を含む長文がある場合は必ず付録 A を確認してください**
>
> Excel での編集時にダブルクォート（`"`）が外れると、取込後に本文の 2 行目以降が欠落する事故が起こり得ます。

## ステップ 1：テナント管理者でログイン → テナント設定を開く

### 対象者
サインアップ済み、または「テナント管理者」ロールを与えられているメンバー。

> **テナント管理者でない方は本機能を利用できません。**
> 「一般メンバー」「PM/TL」のロールの方は、テナント管理者に取込を依頼してください（取込後のデータは公開範囲に応じて閲覧・編集できます）。

### 手順

1. **ログイン**: 組織 ID・メールアドレス・パスワードでログインします（手順は [`account-setup-guide.md`](./account-setup-guide)）。
2. **設定を開く**: ヘッダ右上の **アカウントアイコン → 設定**（`/settings`）。
3. **テナント設定へ**: `/settings` から **テナント設定（`/settings/tenant`）** に進みます。

> テナント設定画面は **テナント管理者にのみ表示** されます。表示されない場合は、ご自分のロールが「テナント管理者」になっているかをご確認ください（`/settings` 画面上部の「アカウント情報」でロールを確認できます）。

## ステップ 2：「① CSVファイルをインポート」を開く

`/settings/tenant`（テナント設定）画面を下にスクロールすると、**「データインポート」セクション** があります。ここには 3 つの入口があります。

| 入口 | 用途 | 対象 |
| --- | --- | --- |
| **① 📄 CSVファイルをインポート** ← ★本書 | 手元の CSV からの新規取込 | 顧客・プロジェクト・WBS・リスク・課題・ナレッジ・振り返り |
| ② 🔗 外部データを直接インポート（API 連携・ベータ） | 外部サービスに直接つないで取込 | 上と同じ 7 種 |
| ③ 📦 ZIP をインポート | 本サービスで書き出した ZIP の復元・テナント間移行 | 全データ横断 |

**「① CSVファイルをインポートしたい方へ」のリンク** をクリックすると、取込画面（`/settings/tenant/migration-import`）に遷移します（アドレス欄に直接 `/settings/tenant/migration-import` と入力しても開けます）。

画面が開くと、上部にステップインジケータ（1. ファイル選択 / 2. マッピング / 3. プレビュー / 4. 結果）が表示されます。

### テンプレート CSV をダウンロードする

取込画面で、**種類ごとのテンプレート CSV** をダウンロードできます（顧客 / プロジェクト / WBS / リスク・課題 / ナレッジ / 振り返り）。日本語の列名と入力例が入った CSV が得られるので、Excel で開き、サンプルを上書きしてデータ行を追加していくのが最短経路です。

> **テンプレートを使う最大の利点**
> テンプレートの列名は **画面項目名と一致** しているため、後の「マッピング」ステップで **自動的に同名マッピング** が当たり、手作業がほぼ不要になります。

## Step 1：CSV を選ぶ

取り込む **種類ごとに CSV ファイルを選択** します（リスクと課題は 1 つの「リスク・課題」CSV にまとめます）。1 回の取込で複数種類を同時に取り込めます（顧客 → プロジェクト → WBS → リスク・課題 → ナレッジ → 振り返り の順に処理されます）。

> **親子の紐づけは「名前」で行います**
> - プロジェクトには **顧客名** の列を入れ、同じ取込に含めた（または既存の）顧客名と一致させます。
> - WBS・リスク・課題・ナレッジ・振り返りには **プロジェクト名** の列を入れ、取込む（または既存の）プロジェクト名と一致させます。
> - プロジェクトは必ず顧客に、WBS は必ずプロジェクトに紐づきます。
>
> 1 件もプロジェクトを作っていない場合は、プロジェクト CSV を一緒に取り込むか、先に 1 件作成してください（[`project-creation-guide.md`](./project-creation-guide)）。

選択後、「次へ（マッピング）」へ進みます。

## Step 2：カラムマッピング

CSV の各列を、画面のどの項目に紐付けるかをプルダウンで設定します。

- **(取り込まない)** を選ぶと、その列は無視されます。
- 各項目に **「既定値」** を設定でき、列が空のときや一部の値が不正なときにその既定値で補われます。
- **テンプレート CSV からスタートした場合は、ほぼ全列が自動マッピング済み**（同名一致）になります。確認のみで通常は OK です。
- 親参照（顧客名・プロジェクト名）や名称など、各種類の必須項目は必ず割り当ててください。

> **「画面で設定できる項目」だけが取り込み対象です**
> 取り込めるのは、各画面で入力・選択できる項目だけです。画面に出ない補助項目や、自動で決まる値（優先度・結果・分類など）は CSV では取り込めません。

### 取り込める項目（種類別）

> **必須の考え方**: 顧客・プロジェクト・WBS は下記「必須」列が常に必要です。リスク・課題／ナレッジ／振り返りは、名称（件名・タイトル）が空の行は取り込まれません（スキップされます）。
> **「公開」で取り込む行の本文** (2026-06-19 v1.3.0「軽量入力」): 本文がまったく入っていない（ナレッジ＝背景・内容・結果がすべて空／リスク・課題＝発生事象・原因・対応策・メモがすべて空／振り返り＝5 セクションがすべて空）行は、「公開」と指定しても自動的に「下書き」として取り込まれます（中身のない資産が公開されて提案の精度が下がるのを防ぐためです）。本文が 1 つでも入っていれば「公開」のまま取り込まれます。「下書き」なら空でも取り込めますが、プロジェクトに紐づかない下書きはどの一覧にも表示されません（後述）。

#### 顧客

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| 顧客名 | ✅ | 100 文字以内 |
| 部門 | 任意 | 100 文字以内 |
| 担当者 | 任意 | 100 文字以内 |
| 担当者メール | 任意 | メール形式（255 文字以内） |
| 備考 | 任意 | ─ |

#### プロジェクト

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| プロジェクト名 | ✅ | 100 文字以内 |
| 顧客名 | ✅ | 取り込む（または既存の）顧客名と一致させます |
| 目的 | ✅ | 複数行可 |
| 背景 | ✅ | 複数行可 |
| スコープ | ✅ | 複数行可 |
| 開発方式 | 任意 | スクラッチ開発 / ローコード・ノーコード開発 / パッケージ開発 / そのほか |
| 契約形態 | 任意 | 準委任 / 請負 / SES / そのほか |
| ステータス | 任意 | 企画中 / 見積中 / 計画中 / 実行中 / クローズ（既定: 企画中） |
| 開始予定日 | ✅ | `YYYY-MM-DD` または `YYYY/MM/DD` |
| 終了予定日 | ✅ | `YYYY-MM-DD` または `YYYY/MM/DD` |

#### WBS（タスク）

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| プロジェクト名 | ✅ | 取り込む（または既存の）プロジェクト名と一致させます |
| レベル | ✅ | 階層の深さ（半角数字。1=最上位、2=その子…）。子を持つ行は自動でワークパッケージ、末端は作業（ACT） |
| 名称 | ✅ | 100 文字以内 |
| 開始予定日 | 任意 | 作業（ACT）のみ。`YYYY-MM-DD` / `YYYY/MM/DD` |
| 終了予定日 | 任意 | 作業（ACT）のみ |
| 予定工数(人時) | 任意 | 作業（ACT）のみ。0 以上・小数第一位まで（例: `8` / `8.5`）。ワークパッケージの工数は子から自動集計のため未入力で OK |

#### リスク・課題（1 つの CSV にまとめます）

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| プロジェクト名 | 任意 | 紐づけるプロジェクト名（空なら紐づけなし） |
| 種別 | 任意 | リスク / 課題（空欄は「課題」扱い）。この値で行がリスクか課題か決まります |
| 件名 | （公開時 ✅）| 100 文字以内 |
| 発生事象 | 任意 | ─ |
| メモ | 任意 | 本文。複数行可 |
| 原因 | 任意 | 複数行可 |
| 影響度 | 任意 | **種別=リスクの行**・高 / 中 / 低 |
| 重要度 | 任意 | **種別=課題の行**・高 / 中 / 低 |
| 発生可能性 | 任意 | **種別=リスクの行**・高 / 中 / 低 |
| 緊急度 | 任意 | **種別=課題の行**・高 / 中 / 低 |
| 対応方針 | 任意 | 複数行可 |
| 期限 | 任意 | `YYYY-MM-DD` / `YYYY/MM/DD` |
| 脅威/好機 | 任意 | **種別=リスクのみ**・脅威 / 好機 |
| 公開範囲 | 任意 | 下書き / 公開（既定: 下書き） |

> **優先度の列はありません**。優先度は「影響度 × 発生可能性」（課題は「重要度 × 緊急度」）から自動で決まり、手入力・CSV 列ともにありません。リスクの行では重要度・緊急度の列は空に、課題の行では影響度・発生可能性・脅威/好機の列は空にしておけば問題ありません。

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| プロジェクト名 | 任意 | 紐づけるプロジェクト名（空なら紐づけなし） |
| タイトル | （公開時 ✅）| 150 文字以内 |
| 種別 | 任意 | 調査 / 検証 / 障害対応 / 意思決定 / 教訓 / ベストプラクティス / その他（空欄は「その他」） |

| 次回改善事項 | （公開時 ✅）| 複数行可 |
| 公開範囲 | 任意 | 下書き / 公開（既定: 下書き） |

> 見積差分要因・スケジュール差分要因・品質面課題・リスク対応評価・横展開したい知見は画面の取込対象に含まれないため、CSV では取り込めません（取込後に各振り返りの画面で入力できます）。

### プルダウン項目に入れる値（共通）

選択項目には **画面と同じ日本語** を入れます（内部の英語コードでも可）。空欄は「既定値」で補われ、**選択肢に無い値はプレビューでエラー**になります（黙って既定値に置き換えたりはしません）。

| 項目 | 値（日本語） | 英語コード |
| --- | --- | --- |
| 公開範囲 | 下書き / 公開 | `draft` / `public` |
| ステータス（プロジェクト） | 企画中 / 見積中 / 計画中 / 実行中 / クローズ | ─ |
| 開発方式 | スクラッチ開発 / ローコード・ノーコード開発 / パッケージ開発 / そのほか | ─ |
| 契約形態 | 準委任 / 請負 / SES / そのほか | ─ |
| 種別（ナレッジ） | 調査 / 検証 / 障害対応 / 意思決定 / 教訓 / ベストプラクティス / その他 | ─ |
| 種別（リスク・課題） | リスク / 課題 | `risk` / `issue` |
| 影響度 / 重要度 / 発生可能性 / 緊急度 | 高 / 中 / 低 | `high` / `medium` / `low` |
| 脅威 / 好機 | 脅威 / 好機 | `threat` / `opportunity` |

> **日付**は `YYYY-MM-DD`（例: `2026-12-31`）と `YYYY/MM/DD`（例: `2026/12/31`）のどちらでも可。Excel のスラッシュ表示のまま取り込め、内部で `YYYY-MM-DD` に統一されます。`12/31/2026` のように月・日が先頭の表記や、`2026-02-30` のような実在しない日付はエラーになります。

設定が終わったら「プレビューを表示」へ進みます。

---

## Step 3：プレビュー（取込前確認）

プレビュー画面では、**まだ取込は実行されていません**。

- 種類ごとの **件数**（合計 / 取込可能 / エラー）
- **想定料金**（Beginner は月 100 件まで無料、Expert / Pro は 1 取込 ¥5。下書きは索引化・課金の対象外）
- **エラー詳細**（行番号・対象・問題の項目・理由）

**エラー（赤）が残っている間は取り込みボタンを押せません。** よくあるエラーと対処は [トラブルシューティング](#トラブルシューティングよくあるエラーと対処) を参照してください。

> **「どのプロジェクトにも紐づかない下書き」はエラーになります**
> リスク・課題／ナレッジ／振り返りを「プロジェクト名なし」かつ「公開範囲＝下書き」で取り込むと、横断一覧にもプロジェクト個別画面にも表示されず参照できなくなるため、プレビューでエラーになります。対処は、(1) プロジェクト名を入れて紐づける、または (2) 公開範囲を「公開」にする、のどちらかです。

---

## Step 4：取り込み

エラーが無くなったら **「この内容で取り込む」** で確定します。

- 件数によっては数十秒〜数分かかります（公開データの索引化のため）。画面を閉じずにお待ちください。
- 取り込まれたデータはすべて **新規作成** されます（既存データの上書きはしません）。
- **担当者は取り込まれません**（空）。必要に応じて取込後に各画面で割り当ててください。
- 完了すると、種類ごとの作成件数と失敗件数が表示されます。

> **索引化（embedding）の失敗について**
> 索引化は提案エンジン・意味検索用のデータです。失敗してもデータ自体は **正常に作成されています**。提案エンジンの候補に並ばないだけで、後から編集・再保存、または月初の自動処理で再生成されます。

## トラブルシューティング：よくあるエラーと対処

### 1. 「CSV として読み込めませんでした」「ヘッダ行を検出できませんでした」

**原因**: ファイルが UTF-8 でない（Shift_JIS など）、または壊れている / 空。

**対処**: Excel で開き直し、「名前を付けて保存」→ **「CSV UTF-8 (コンマ区切り)」** で再保存してください。

### 2. 「ファイルサイズが上限 (50 MB) を超えています」「件数が 5,000 件を超えています」

**対処**: 種類や期間で分割し、複数回に分けて取り込んでください。

### 3. プレビューで「エラー N 行」が表示される

代表的な原因と対処:

| エラー内容例 | 原因 | 対処 |
| --- | --- | --- |
| 必須項目が空（顧客名・プロジェクト名・目的・開始予定日 など） | 必須フィールドが空 | Excel で該当行に値を入力 |
| 親が見つからない（顧客がいないプロジェクト、プロジェクトがいない WBS 等） | 名前が一致していない | 親を同じ取込に含めるか、マッピングの「既定値」に既存の名前を設定 |
| 選択肢に無い値（例: 影響度に「とても高い」） | プルダウン項目の値違反 | 正しい選択肢（高/中/低 など）に修正 |
| 日付の書式エラー | `2026/13/01` 等、月日先頭・実在しない日付 | `YYYY-MM-DD` / `YYYY/MM/DD` に修正 |
| 予定工数が不正 | 0 未満・小数第二位以降・数値以外 | 0 以上・小数第一位までの数値に修正 |
| 「紐づかない下書き」エラー | プロジェクト名なし かつ 下書き | プロジェクト名を入れる、または公開範囲を「公開」に |
| 同一親配下に同名のタスク（WBS） | 1 回の取込に同じ親×同名が 2 つ | どちらかの名称を変更 |

### 4. 取込後に本文の「2 行目以降」が消えている

**原因**: 改行を含むセルがダブルクォートで囲まれていなかった（Excel 保存時にクォートが外れた）。

**対処**: 本書 [付録 A](#付録-a-改行を含むセルの書き方重要) を参照し、CSV をテキストエディタ（メモ帳・VS Code 等）で開いて長文セルが `"..."` で囲まれているか確認してください。

### 5.「取り込めるデータがありません」と表示される

**原因**: データ行が無い（ヘッダのみ）、または必須列のマッピング漏れ。

**対処**: テンプレ CSV の 2 行目以降にデータが入っているか、マッピングで必須項目に正しい列が割り当たっているかを確認してください。この状態でも「プレビュー」へ進めば理由が表示されます。

### 6. 取込実行ボタンが押せない

**原因**: 取込可能件数が 0、エラー行が残っている、または Beginner プランの容量上限警告。

**対処**: エラー行を解消して再プレビュー。容量警告の場合はプラン・席数をご確認ください。

## 付録 A：改行を含むセルの書き方（重要）

**目的・背景・内容・原因・対応方針・計画総括** など、複数行になり得る項目を CSV に含める場合、**そのセル全体を必ずダブルクォート（`"`）で囲んでください**。

### 正しい例（CSV を直接編集する場合）

```csv
プロジェクト名,種別,件名,メモ
"基幹刷新","課題","テスト DB 消失","リリース前検証中、
複数チームが共有する DB を
意図せず truncate した"
```

### Excel で編集する場合のコツ

1. **セル内改行**: `Alt + Enter`（Windows）/ `Option + 改行`（macOS）でセル内に改行を入れる
2. **保存形式**: 「CSV UTF-8 (コンマ区切り)」を選ぶ
3. **保存後の確認**: 念のため、保存後に CSV ファイルを **メモ帳や VS Code** で開いて、改行を含むセルが `"..."` で囲まれているか目視確認すると安心です

### よくある誤り

| 誤った書き方 | 結果 |
| --- | --- |
| `テスト,本文に,カンマがある` | カンマで列が分割されてしまう（→ `"テスト,本文に,カンマがある"` と囲む） |
| `本文に "引用符" がある` | 引用符がエスケープされず壊れる（→ `"本文に ""引用符"" がある"`） |
| 改行を含むセルをクォートで囲まずに保存 | **2 行目以降が別レコードと解釈されて取込結果が壊れる** |

## 補足: メモの取込について

メモ（プロジェクトに紐付かない個人の覚え書き）は本経路の対象外です。メモの取込は、**画面上部メニュー →「メモ」→「インポート」ボタン** から行います（メモ一覧の CSV をエクスポート → 編集 → 再取込する「上書きインポート」型です）。

なお、振り返り・WBS・リスク・課題・ナレッジは本経路（① CSVファイルをインポート）で初回一括取込できるほか、各一覧画面の「インポート」からエクスポート → 編集 → 再取込（上書き）することもできます。

## 補足: 各一覧画面の「上書きインポート」で削除候補を確認する方法

WBS・リスク/課題・ナレッジ・振り返り・メモの各一覧画面にある「**インポート**」ボタンから行う「上書きインポート」では、プレビュー画面で **「削除候補の扱い」** を選択できます。

| 選択肢 | 動作 |
|---|---|
| **保持** (デフォルト) | CSV にないデータはそのまま残す |
| **警告のみ** | 削除候補の件数を警告するが、本実行では削除しない |
| **削除** | CSV にないデータを論理削除する |

「**削除**」を選択した場合のみ、その直下に **「削除候補 (N 件)」** という折りたたみ欄が表示されます。クリックすると対象の一覧が展開されます（デフォルトは閉じた状態）。内容を確認してから「確定実行」してください。

> **ご注意**: 進捗のある WBS タスクや「公開中」のナレッジなど、削除できない条件のデータが削除候補に含まれる場合は赤いエラーが表示され、実行がブロックされます。
