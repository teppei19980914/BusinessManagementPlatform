# 画面一覧リファレンス

たすきば Knowledge Relay の **利用者が触れる全画面** を、役割・アクセス動線・閲覧できるロールとともに一覧化したリファレンスです。各画面の詳しい使い方は、リンク先の個別ガイドを参照してください。

> 表記: 管理者 = テナント管理者 (admin) / PM = PM/TL / メンバー / 閲覧者。○ = 利用可 / △ = 条件付き / × = 不可。
> サービス運営者 (super_admin) 専用の管理画面は、一般のお客様には表示されないため本一覧から除外しています。

---

## 1. ログイン前の画面

| 画面 | 役割 | 関連ガイド |
|---|---|---|
| ログイン | 組織 ID + メール + パスワードで認証 | [アカウント追加手順](./account-setup-guide) |
| MFA 検証 | 二段階認証の 6 桁コード入力 | 同上 |
| サインアップ | 新しい組織 (テナント) を作成 | 同上 |
| パスワード再設定 | リカバリーコードでパスワードを再設定 | 同上 |
| 初期パスワード設定 | 招待メールから初回パスワードを設定 | 同上 |
